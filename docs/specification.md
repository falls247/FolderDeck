## 1. データの置き場所

`%LOCALAPPDATA%\FolderDeck\`（`--data-dir <フォルダ>` で起動したときはそのフォルダ。[開発ガイド](development.md#31-開発用オプションデータの置き場所を差し替える)）

| ファイル | 内容 |
|---|---|
| `registered_folders.json` | 登録フォルダ（imgtool と同じ形式）。`folders` 配列の順番がサイドバーの並び（[3](#3-ほかのデータファイル)） |
| `history.json` | 利用記録（最近の履歴・よく使う項目の元データ） |
| `pins.json` | ピン留め |
| `excluded.json` | 最近の履歴から外した項目 |
| `card_order.json` | 最近の履歴・よく使う項目をドラッグで並べた順（各 1000 件まで） |
| `settings.json` | 設定、ウィンドウ位置、開いているタブと表示していたタブ、サイドバーの幅と折りたたみ、タブごとの表示（カードの形・詳細表示）と並び方、列の幅、表示する項目など。全キーは [2. settings.json](#2-settingsjson) |
| `thumbs\` | 画像サムネイルのキャッシュ（一度表示した画像の縮小版。JPEG、透過のある画像は PNG）。上限は設定の「画像サムネイルのキャッシュ上限」（既定 512 MB）で、超えたら使っていない順に消します。フォルダごと消してもかまいません（次に表示するとき作り直します） |
| `logs\app.log` | ログ（5 MB で `app.log.1` に切り替え） |
| `logs\session.json` | 起動中だけある記録（1 分ごとに更新）。次の起動時に残っていれば「前回は正常に終わらなかった」と判断する |

- 書き込みは一時ファイル経由で置き換えます。壊れた JSON は `<名前>.broken-<UNIX秒>.json` に退避し、空のデータで続けます（メッセージ行に警告が出ます。直し方は [開発ガイドの 7.8](development.md#78-データファイルが-broken-json-になった)）。
- このアプリがファイルやフォルダを消すのは、右クリックの「削除（ごみ箱へ移動）」か Delete キー（選択した項目）を確認ダイアログで承認したときだけです（ごみ箱へ移すだけで、完全には削除しません。[7. 削除（ごみ箱へ移動）](#7-削除ごみ箱へ移動)）。それ以外でファイルの削除・移動・上書きはしません（アプリ自身のデータである `thumbs\` の古いキャッシュを除く）。ファイルのコピー・移動は「貼り付け」と、フォルダへのドラッグ＆ドロップだけです（[9. 選択と切り取り・コピー・貼り付け](#9-選択と切り取りコピー貼り付け)、[13. ドラッグで移動・コピー・ほかのアプリへ渡す](#13-ドラッグで移動コピーほかのアプリへ渡す)）。「その他のメニュー（Windows）」で選んだ項目（設定「Windows のメニュー」で出したエクスプローラーの項目も同じ）は、Windows やその項目を追加したアプリ（7-Zip など）が実行します（[10. エクスプローラーのメニュー](#10-エクスプローラーのメニューその他のメニューwindows)）。

## 2. settings.json

- 文字コードは UTF-8（読むときは BOM があってもよい）。キーは snake_case で、インデントつきで書きます。読むときは下の表のキー（プロパティ名）の大文字・小文字を区別せず、コメント（`//`、`/* */`）と末尾のカンマを許します。`sort_modes` / `filter_modes` の中のキー（`recent` など）は小文字で完全一致です（`details_columns` の中のキーだけは大文字・小文字と前後の空白を区別しません）。
- ないキーは既定値で読みます。読み込んだときと、アプリが設定を変えるたびに、範囲外の値は範囲に収め、知らない値は既定値に直してから保存します（文字列の値は大文字・小文字と前後の空白を区別しません。ただし `filter_modes` の値は小文字で完全一致）。
- 数値のキーに文字列や `null` を書くと（`null` を許すと書いたキーを除く）、ファイル全体が壊れた扱いになり、`settings.broken-<UNIX秒>.json` に退避して既定値で始めます（[開発ガイドの 7.8](development.md#78-データファイルが-broken-json-になった)）。`window` と `details_columns` は、キーごと `null` にしてもかまいません（既定値で読みます）。
- ウィンドウの位置と大きさは、ウィンドウを閉じるときに保存します。
- 時刻は UTC の ISO 8601（秒まで。例：`2026-11-21T01:23:45+00:00`）で書きます。読めない時刻は `null` として扱います（ファイル全体は壊れた扱いにしません）。

| キー | 型 | 既定値 | 範囲・値 | 内容 |
|---|---|---|---|---|
| `version` | 整数 | `2` | いつも `2` で書く | ファイルの形式の版。`2` 未満のファイル、または `last_tab` があるファイルは、読み込むときに今の形式へ移す（[2.2](#22-版と以前の形式からの移行)）。キーがなければ `2` として読む |
| `window` | オブジェクト | 下の 5 つ | — | ウィンドウの位置と大きさ（DIP）。ないとき・`null` のときは既定値 |
| `window.left` / `window.top` | 数値または `null` | `null` | — | 左上の位置。`null` のとき、またはタイトルバーの帯がどのモニターにも載らない位置のときは、メインのモニターの作業領域の中央に出す（大きさは作業領域に収める） |
| `window.width` / `window.height` | 数値 | `1280` / `800` | 幅 200 未満・高さ 150 未満は既定値に戻す | ウィンドウの大きさ。最大化しているときは、元に戻したときの位置と大きさを保存する |
| `window.maximized` | 真偽 | `false` | — | 最大化していたか |
| `open_tabs` | 配列 | キーがなければ `[{"kind": "recent", …}]`（初回起動：最近の履歴だけ） | 要素の形は [2.1](#21-open_tabs-の形) | 開いているタブ（左から順）。空の配列は「全部閉じた」で、空のまま始まる |
| `selected_tab` | 整数 | `0` | `-1`（タブなし）、`0`〜タブの数 − 1 | 表示していたタブの `open_tabs` の中の位置。範囲外は範囲に収める。正規化で落としたタブを指していたときは、その次のタブ |
| `sidebar_width` | 数値 | `220` | 140〜480（整数に丸める） | サイドバーの幅（DIP）。サイドバーを隠している間も覚えておく |
| `sidebar_collapsed` | 真偽 | `false` | — | サイドバー全体を隠しているか（タブ列の左端のボタン） |
| `sidebar_collapsed_sections` | 文字列の配列 | `[]` | `quick`（クイック アクセス）／`registered`（登録フォルダ）／`pc`（PC） | 見出しだけに折りたたんでいる節。知らない値と重複は捨て、節の順に並べ直す。載っていない節は開いている（あとから増えた節は開いた状態で始まる） |
| `card_size` | 整数 | `200` | 120〜400、20 刻み（いちばん近い刻みに丸める） | カードの大きさ（Ctrl + ホイール・スライダー）。詳細表示の間も値は残る |
| `card_shape` | 文字列 | `portrait` | `portrait`（縦長のカード、サムネイル 3:4）／`square`（正方形のカード、1:1）／`details`（詳細表示） | 最後に使ったタブ（表示中のタブ。タブを全部閉じているときは最後に表示していたタブ）の表示。表示はタブごとに `open_tabs` の要素の `card_shape` に持ち（[2.1](#21-open_tabs-の形)）、新しく開くタブはこの表示で始まる（[5](#5-タブとサイドバー登録フォルダ)）。`card_shape` のない `open_tabs` の要素（以前の版のファイル）もこれを使う。知らない値は `portrait` |
| `details_columns` | オブジェクト（キー → 数値） | `name` 360、`modified` 150、`type` 170、`size` 96 | `name` 120〜2000、`modified`／`type`／`size` 48〜600（小数 2 桁に丸める） | 詳細表示の列（名前・更新日時・種類・サイズと追加の列：`date_taken`・`authors`・`dimensions`・`camera_maker`・`camera_model`・`created`・`title`・`tags`・`duration`・`rating`）の幅（DIP）。いつもこの 14 個のキーだけを書く（隠している追加の列の幅も覚えておく。追加の列の既定は 80〜150、範囲は 48〜600）。ないキーは既定値（`name` のない以前のファイルは 360）、知らないキーは捨てる。キーの大文字・小文字と前後の空白は区別せず、同じキーが 2 つあれば最初のもの |
| `details_extra_columns` | 文字列の配列 | `[]` | 上の追加の列のキー（不明なキーは捨て、重複は 1 つ、並びは決まった順） | 詳細表示で表示する追加の列（見出しの右クリックで選ぶ）。既定は表示しない |
| `theme` | 文字列 | `system` | `system`／`light`／`dark` | テーマ（配色）。知らない値は `system` |
| `text_scale` | 整数 | `100` | 100〜150、10 刻み（範囲外は範囲に収め、刻みから外れた値はいちばん近い刻みに丸める。ちょうど中間は偶数側：105 → 100、115 → 120） | 文字の大きさ（%）。サイドバー・カード・詳細表示・中身の一覧（オーバーレイ・フライアウト）の文字と行の高さ（[15](#15-設定)） |
| `sort_modes` | オブジェクト（キー → 文字列） | 3 つとも `manual` | キー：`recent`／`frequent`／`folder`。値：`manual`、`name_asc`、`name_desc`、`modified_asc`、`modified_desc`、`size_asc`、`size_desc`、`type_asc`、`type_desc` | 種類ごとの並び方（以前の版の形式）。今の版は並び方をタブごとに `open_tabs` の要素の `sort_mode` に持ち（[2.1](#21-open_tabs-の形)、[11](#11-並べ替えとピン留め)）、このキーを読むのは `sort_mode` のない要素（以前の版のファイル）を移すときだけ。以前の版の exe のために、その種類のタブで最後に選んだ並び方を書き続ける。知らない値は `manual`。以前の `registered`（登録フォルダのタブ）の値は、`folder` がなければ `folder` に移し、キーは消す |
| `last_sort_mode` | 文字列 | 表示していたタブ（`selected_tab`）の `sort_mode`。タブがなければ `sort_modes` の `folder` | 値は `sort_modes` と同じ | 最後に使ったタブ（表示中のタブ。タブを全部閉じているときは最後に表示していたタブ）の並び方。新しく開くタブはこの並び方（と `card_shape` の表示）で始まる（[5](#5-タブとサイドバー登録フォルダ)）。知らない値は `manual` |
| `filter_modes` | オブジェクト（キー → 文字列） | 2 つとも `all` | キー：`recent`／`frequent`。値：`all`／`folders`／`files` | 最近の履歴・よく使う項目の一覧で表示する項目（[6](#6-表示する項目の切り替え)）。知らない値は `all` |
| `show_hidden` | 真偽 | `false` | — | 隠しファイル・フォルダ（隠し属性・システム属性の付いた項目）を表示する。変えるとすべてのタブを読み直す |
| `show_dot_items` | 真偽 | `false` | — | 名前が「.」で始まるファイル・フォルダ（`.vscode`、`.gitignore` など）を表示する。`show_hidden` とは別に効く：隠し属性も付いている項目（Git for Windows が隠し属性を付ける `.git` など）は両方を `true` にしたときだけ出る。変えるとすべてのタブを読み直す |
| `confirm_executables` | 真偽 | `true` | — | 実行形式（`.exe .bat .ps1` など）を開く前に確認する（`open_on_double_click` がオンのとき、カード・詳細表示の行のダブルクリックでは確認しない） |
| `include_windows_recent` | 真偽 | `true` | — | 最近の履歴に Windows の最近使った項目を含める |
| `recent_limit` | 整数 | `100` | 10〜500 | 最近の履歴の表示件数 |
| `frequent_limit` | 整数 | `50` | 10〜200 | よく使う項目の表示件数 |
| `recent_cleared_at` | 時刻または `null` | `null` | — | 最近の履歴の一覧の「履歴をクリア」を押した時刻。これより前に使った項目は最近の履歴に出さない（ファイルや Windows の履歴は消さない） |
| `add_to_windows_recent` | 真偽 | `false` | — | 開いたファイルを Windows の最近使った項目にも追加する |
| `open_explorer_in_new_tab` | 真偽 | `false` | — | 「エクスプローラーで表示」を、開いているエクスプローラーの新しいタブで開く（Windows 11。[15](#15-設定)） |

| `auto_refresh` | 真偽 | `true` | `true`（一定の間隔で更新）／`false`（自動更新なし） | フォルダの自動更新。設定の OK で再起動なしに効く。キーがなければ `true`（以前の版で保存した `false` はそのまま） |
| `auto_refresh_seconds` | 整数 | `5` | 2〜3600（範囲外は範囲に収める） | 自動更新の間隔（秒）。`auto_refresh` が `false` の間も値を覚えておく |
| `start_at_login` | 真偽 | `false` | | 常駐モード：Windows のログオン時に `--background` で起動する。設定の OK で `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` の値 `FolderDeck`（今の exe のパス + `--background`）を登録・解除する。起動時は Run キーの実際の登録を正としてこのキーを合わせる（値がない・ほかの exe を指す・`--background` がないときは `false`）。`--data-dir` 付きの起動では Run キーを読み書きせず、このキーだけを保存する |
| `keep_running_on_close` | 真偽 | `false` | | 常駐モード：ウィンドウを閉じても終了せず、隠して通知領域に残る |
| `search_scope` | 文字列 | `"folder"` | `"folder"`（表示中のフォルダだけ）／`"recursive"`（サブフォルダも。不明な値は `folder`） | 名前で検索（Ctrl + F）の範囲。設定の OK で検索中のタブにも効く |
| `last_tab` / `locations` / `selected_folder_tab` | — | 書き出さない | — | version 1 のキー（表示していたタブ、固定タブの場所、表示していたフォルダのタブ）。読み込むときに `open_tabs` / `selected_tab` へ移し、その後は書かない（[2.2](#22-版と以前の形式からの移行)） |

### 2.1 open_tabs の形

```json
"open_tabs": [
  { "kind": "recent",   "root": "", "path": "", "card_shape": "portrait", "sort_mode": "manual" },
  { "kind": "frequent", "root": "C:\\Users\\me\\Documents", "path": "Reports", "card_shape": "square", "sort_mode": "name_asc" },
  { "kind": "folder",   "root": "E:\\Dev", "path": "", "file_id": "v1:…", "card_shape": "details", "sort_mode": "modified_desc" }
],
"selected_tab": 2
```

| キー | 内容 |
|---|---|
| `kind` | タブの種類：`recent`（最近の履歴）／`frequent`（よく使う項目）／`folder`（フォルダのタブ）。ない・知らない値は `folder` |
| `root` | タブの起点のフォルダ（正規化したパス）。`recent` / `frequent` の一覧（タブの最上位）にいたときは空。フォルダのタブでは、開いたフォルダ（登録フォルダ・ドライブ・一覧からたどったフォルダ） |
| `path` | `root` の下で表示していたフォルダ（`root` からの相対パス。`root` そのものなら空） |
| `file_id` | 表示していたフォルダの識別子（[5.2](#52-名前の変わったフォルダへの追従)）。分からないとき・一覧にいたときは書かない。アプリを閉じている間に名前が変わったフォルダを、次の起動で探すのに使う |
| `card_shape` | そのタブの表示。値と既定は `settings.json` の `card_shape` と同じ。ない・空のとき（以前の版のファイル）は、ルートの `card_shape`。知らない値は `portrait` |
| `sort_mode` | そのタブの並び方（[11](#11-並べ替えとピン留め)）。値は `sort_modes` と同じ。ないとき（以前の版のファイル）は、そのタブの種類の `sort_modes` の値。知らない値は `manual` |

- `recent` と `frequent` は 1 つずつまで（2 つ目からは捨てる）。`root` のないフォルダのタブと、51 個目からのフォルダのタブ（フォルダのタブは 50 個まで）も捨てる。
- 起動すると、この並びと場所でタブを開き直します（[5](#5-タブとサイドバー登録フォルダ)）。

### 2.2 版と以前の形式からの移行

- version 1 は「最近の履歴」「よく使う項目」が常設で、フォルダのタブだけが `open_tabs` に入る形式でした（表示していたタブ `last_tab`、2 つの固定タブの場所 `locations`、表示していたフォルダのタブ `selected_folder_tab`）。
- `version` が 2 未満、または `last_tab` があるファイルを読むと、「最近の履歴」「よく使う項目」（それぞれの保存場所で）、フォルダのタブの順に `open_tabs` を作り、表示していたタブを選びます。以前の版の exe は version 2 のファイルを読むと自分のキーを書き戻すので、そのあと新しい版で開いたときにもう一度移します（[5](#5-タブとサイドバー登録フォルダ) の以前の版の説明）。
- version 1 のキーは、移したあと書き出しません（以前の版が `null` の `selected_folder_tab` を読めず、ファイル全体を壊れた扱いにするため）。
- 表示と並び方がタブごとになる前のファイル（`open_tabs` の要素に `card_shape` / `sort_mode` がない）は、読み込むときに、どのタブもルートの `card_shape` の表示と、その種類の `sort_modes` の並び方で始めます（以前の版と同じ見た目）。`last_sort_mode` がなければ、表示していたタブの並び方にします。`version` は 2 のままです。以前の版の exe はこれらのキーを落として書き戻すので、そのあと新しい版で開くと、もう一度この移し方をします（タブごとの表示と並び方は失われますが、タブは失われません）。

## 3. ほかのデータファイル

どれも UTF-8 の JSON で、書き方・読み方は `settings.json` と同じです（[2](#2-settingsjson)）。パスは正規化したパスで、時刻は UTC の ISO 8601 です。

| ファイル | 形 | 補足 |
|---|---|---|
| `registered_folders.json` | `{ "version": 1, "folders": [ { "id": …, "path": …, "added_at": …, "file_id": … } ] }` | imgtool と同じ形式（`file_id` だけ FolderDeck が足す。分かるまでは書かない）。`folders` の順番がサイドバーの並び（ドラッグで並べ替え）。`file_id` はフォルダの識別子で、名前の変わったフォルダを探すのに使う（[5.2](#52-名前の変わったフォルダへの追従)） |
| `history.json` | `{ "version": 1, "items": [ { "path": …, "kind": "file" \| "folder", "open_count": …, "last_opened_at": …, "recent_opens": [時刻…] } ] }` | `recent_opens` は新しい順に 10 件まで。項目は 2000 件までで、超えたら最後に開いた時刻の古いものから捨てる。設定の「よく使う項目の統計をリセット」で全部消える（ピン留めは残る） |
| `pins.json` | `{ "version": 1, "pins": [ { "path": …, "kind": "file" \| "folder", "pinned_at": … } ] }` | ピン留め |
| `excluded.json` | `{ "version": 1, "excluded": [ { "path": …, "excluded_at": … } ] }` | 最近の履歴から外した項目 |
| `card_order.json` | `{ "version": 1, "recent": [パス…], "frequent": [パス…] }` | 最近の履歴・よく使う項目をドラッグで並べた順。重複なし、各 1000 件まで。並べ替えメニューの「手動の並びをリセット」でそのタブの並びを消す（[11](#11-並べ替えとピン留め)） |

## 5. タブとサイドバー（登録フォルダ）

- サイドバーは上から「クイック アクセス」（「最近の履歴」「よく使う項目」の行）、「登録フォルダ」、「PC」（ドライブ）の 3 つの節に分かれます。見出しをクリックすると、その節は見出しだけに折りたたまれます（もう一度クリックで開く）。「登録フォルダ」の見出しには件数と登録のボタンが付き、折りたたんでいても使えます。
- タブ列の左端のボタンで、サイドバー全体を隠して一覧を広く使えます（もう一度押すと元の幅で戻ります）。節の折りたたみとサイドバーの表示・非表示は `settings.json` に保存し、次の起動でも同じ状態で始まります。
- 「クイック アクセス」の行は、そのタブを表示している間は色が付き、タブ列に開いている間は右端に点が付きます。
- 登録フォルダはウィンドウ左のサイドバーに、フォルダ名だけを 1 行ずつ並べます（パスはツールチップ）。見つからないフォルダ・応答がない（2 秒）フォルダは取り消し線と ⚠ で示し、一覧もタブも開きません（右クリックの「登録を解除」とドラッグでの並べ替えはできます）。F5 で確認し直します。名前を変えた・移動したフォルダは、確認のときに新しい場所を探して登録を書き換えます（[5.2](#52-名前の変わったフォルダへの追従)）。
- 「PC」にはドライブを 1 行ずつ、エクスプローラーと同じ名前（`ラベル (C:)`。ネットワーク ドライブは `共有名 (\\サーバー) (Z:)`）でドライブ文字の順に並べます。登録フォルダの行と同じように、止まると中身の一覧、クリックでドライブの最上位を新しいタブで開きます（タブの名前は `C:\`）。
  - 出るのは固定ディスク、ネットワーク ドライブ、メディアが入っているリムーバブル ディスク（USB メモリー、カード）と光学ドライブです。空のカード リーダーや、ディスクの入っていないドライブは出ません。
  - 接続されていないネットワーク ドライブと、応答がない（2 秒）ドライブは、取り消し線と ⚠ で示し、一覧もタブも開きません。右クリックの「エクスプローラーで表示」は使えます（エクスプローラーが再接続を案内します）。応答を待っている間も、ほかの行と画面は止まりません。
  - 一覧は、起動したとき、USB メモリーやカード・ディスクを抜き差ししたとき、F5 を押したとき、FolderDeck のウィンドウに戻ってきたとき（5 秒に 1 回まで）に読み直します。ネットワーク ドライブの割り当て・切断は、ウィンドウに戻ったときか F5 で反映されます。
  - ドライブの行の右クリックは「開く」「エクスプローラーで表示」「パスをコピー」「貼り付け」「ターミナルで開く」などの「…で開く」（接続されているとき）「登録フォルダに追加」です（ピン留め・削除はありません。設定の「右クリックのメニュー」が「Windows のメニュー」でも、このアプリのメニューです）。「PC」の見出しを右クリックすると「エクスプローラーで開く」が出て、エクスプローラーで PC を開きます（設定の「新しいタブで開く」がオンなら新しいタブ。利用記録には残しません）。ドライブの行はドラッグできず、クリックで開いても「最近の履歴」「よく使う項目」には記録しません（一覧からたどって開いたフォルダは記録します）。「PC」の節は登録フォルダの下にあり、ドライブが多いときはサイドバーの高さの 4 割までで、その中をスクロールします（登録フォルダを折りたたむと、残りの高さを全部使います）。
  - アイコンはドライブの種類ごとの簡単な記号で、エクスプローラーのドライブのアイコンではありません。
- 行に 0.3 秒止まると、行の右に中身の一覧（フライアウト）が出ます。開いている間にほかの行を横切っても、そこで止まらなければ一覧は切り替わりません（一覧へ斜めに移動できるようにするため）。
- 一覧（カードのオーバーレイも同じ）は、FolderDeck のウィンドウが前面でなくても開きます（ほかのアプリで作業中に、横に並べた FolderDeck へポインターだけ動かしたとき）。このときは通過しただけで開かないよう、待ち時間が 0.5 秒になります。前面のウィンドウが替わると閉じ、一覧の中をクリックすると FolderDeck が前面になります。
- タブ列は 1 本で、開いた順に左から並びます。「最近の履歴」「よく使う項目」はサイドバーの「クイック アクセス」の行から開きます（タブ列の右端に追加。すでに開いていればそのタブに切り替わり、表示中でフォルダの中にいるときは一覧に戻ります）。
- 登録フォルダから開いた画面は、カード一覧の上のタブ列に新しいタブとして追加されます。タブの名前は表示中のフォルダ名です。最近の履歴・よく使う項目の一覧でフォルダのカードを開いたときも、新しいタブになります（一覧のタブはそのまま）。フォルダのタブの中でフォルダのカードをクリックすると、そのタブの中で移動します（戻る・進むの履歴とスクロール位置はタブごと）。
- フォルダのタブは「最近の履歴」「よく使う項目」と色が違います（緑系。「最近の履歴」「よく使う項目」は青系で、それぞれのアイコンが付きます）。どのタブも × ・中クリック・Ctrl + W で閉じ、左右にドラッグして順番を入れ替えられます。
- 「最近の履歴」「よく使う項目」のタブを閉じてからサイドバーで開き直すと、一覧から始まります（閉じる前にいたフォルダと、戻る・進むの履歴は残りません）。下の「閉じたタブを開き直す」では、閉じる前の場所と履歴に戻ります。
- **閉じたタブを開き直す**（Ctrl + Shift + T、タブの右クリック）：最後に閉じたタブを、閉じる前の位置・場所・表示・並び方・戻る / 進むの履歴・スクロール位置で開き直します。続けて押すと、その前に閉じたタブが順に戻ります（「ほかのタブを閉じる」で閉じた分も、元の並びに戻ります）。覚えているのは最後の 25 個で、アプリを終了すると消えます（保存しません。常駐モードで隠している間は残ります）。同じフォルダのタブが開いていても、新しいタブとして開きます。「最近の履歴」「よく使う項目」がすでに開いているときは、その記録は飛ばして、その前に閉じたタブを開き直します。一覧を表示したまま閉じた「最近の履歴」「よく使う項目」（履歴なし）は覚えません。閉じたあとにフォルダの名前が変わったり移動したりしても、新しい場所で開きます。タブがないときも使えます。
- **タブを複製**（タブの右クリック。エクスプローラーの「タブの複製」）：そのタブの右に、同じフォルダ・表示・並び方・戻る / 進むの履歴・スクロール位置の新しいフォルダのタブを開いて表示します。「最近の履歴」「よく使う項目」の中のフォルダにいるときは、そのフォルダのフォルダのタブになります（履歴は写しません）。一覧を表示している「最近の履歴」「よく使う項目」は複製できません。
- 表示していないタブに 0.3 秒止まると（ウィンドウが前面でないときは 0.5 秒）、タブの下にそのタブが表示しているフォルダの中身の一覧（フォルダとファイル）が出ます。タブを切り替えずに中をのぞけます。待ち時間・行をたどる操作・ファイルの行のプレビューは、サイドバーの一覧と同じです（設定はありません）。
  - 一覧のフォルダをクリックすると、新しいフォルダのタブで開きます（同じフォルダを表示しているフォルダのタブがあれば、そのタブに切り替えます）。新しいタブの表示と並び方は、止まったタブではなく、表示中のタブのものを引き継ぎます。一覧の見出しをクリックすると、そのタブに切り替わります（「最近の履歴」「よく使う項目」のタブでは、同じフォルダを新しいフォルダのタブで開きます）。
  - 表示中のタブ、「最近の履歴」「よく使う項目」の一覧（フォルダの中にいないとき）を表示しているタブ、フォルダが見つからない・読み込めなかったタブでは出ません。「最近の履歴」「よく使う項目」のタブでも、フォルダの中にいるときは出ます。
  - タブを押す・閉じる・並べ替える・右クリックすると閉じ、そのあとはポインターを少し動かすまで隣のタブの一覧も出ません。タブ列がスクロールしたとき（「◀」「▶」・ホイール）、タブが増えた・減ったとき、表示中のタブの名前が変わってタブの幅が変わったときも閉じます（サイドバーやアドレス欄の一覧は閉じません）。
  - 一覧が出ている間は、そのタブのツールチップ（フォルダのパス）を出しません。
- タブはそれぞれ表示（縦長のカード・正方形のカード・詳細表示）と並び方を覚えます。タブを切り替えると、ツールバーの表示と並び方もそのタブのものに替わります。タブの中でフォルダを移動しても（戻る・進むも）変わりません。
  - 新しく開いたタブ（登録フォルダ・ドライブ・一覧のフォルダから開いたフォルダのタブ、閉じていた「最近の履歴」「よく使う項目」を開き直したとき）は、直前に表示していたタブの表示と並び方で始まります。直前のタブが「最近の履歴」「よく使う項目」でも同じです（たとえば「最近の履歴」の「手動」の並びから開いたフォルダのタブは「手動」で始まります）。
  - タブを全部閉じたあとに開いたタブは、最後に表示していたタブの表示と並び方で始まります。これは再起動しても残ります（`settings.json` の `card_shape` と `last_sort_mode`）。
- タブを全部閉じると、カード一覧の場所に「開いているタブはありません。左のメニューから項目を選んでください。」と「最近の履歴を開く」「よく使う項目を開く」のボタンが出ます。この状態も保存され、次の起動もタブなしで始まります。
- 開いているタブ（並び順と、それぞれが表示していた場所・表示・並び方）と選んでいたタブは `settings.json` に保存し（[2.1](#21-open_tabs-の形)）、次の起動で元に戻します（フォルダが無くなっていたフォルダのタブは「フォルダが見つかりません」と出るので、「タブを閉じる」で閉じます。「最近の履歴」「よく使う項目」は一覧に戻ります。名前が変わった・移動したフォルダは、先に新しい場所を探して開きます：[5.2](#52-名前の変わったフォルダへの追従)）。登録を解除しても、開いているタブは閉じません。
- 以前の版の `settings.json`（「最近の履歴」「よく使う項目」が常設だった形式）は、最初の起動で新しい形式に変わります（2 つのタブとフォルダのタブを同じ並びで開き、表示していたタブを選びます。[2.2](#22-版と以前の形式からの移行)）。新しい形式のファイルを以前の版で開くと、フォルダの中にいた「最近の履歴」「よく使う項目」はフォルダのタブとして開き、次に新しい版で開いたときに改めて変換されます。
- 以前の「登録フォルダ」タブ（登録フォルダのカード一覧）はなくなりました。登録フォルダの並べ替えは「ドラッグで並べた順」だけです（名前順・更新日順はフォルダのタブの中で使えます）。

### 5.1 アドレス欄

- ツールバーの ↑ の右はアドレス欄です。表示中のフォルダのパスを、ドライブ（共有）から全部表示します（`E:\仕事\案件` のように `\` で区切る。最近の履歴・よく使う項目の中では、一覧の名前のあとに `›` を挟んで続けます。一覧そのものでは一覧の名前だけ）。フォルダ名をクリックするとそこへ移動します。タブの起点（開いたフォルダ）より上のフォルダをクリックしたときは、そのフォルダがタブの起点になります（フォルダのタブで ↑ を押したときと同じ。最近の履歴・よく使う項目の中でも、一覧には戻らずそのフォルダを表示します。↑ は今までどおり一覧に戻ります）。幅が足りないときは、先頭のフォルダから「…」にまとめて、パスの終わりのほうを見せます（「…」に止まるとパス全体が出ます）。
- フォルダ名に止まると（300 ms。ウィンドウが前面でないときは 500 ms）、その下にそのフォルダのサブフォルダの一覧が出ます（フォルダだけ。ファイルは出しません。見出しの件数はフォルダ全体のもので、ファイルしかないフォルダでは「サブフォルダはありません」と出ます）。一覧のフォルダをクリックすると、表示中のタブの中でそこへ移動します（戻るで戻れます）。タブの起点より上のフォルダ名の一覧から選んだときは、フォルダ名をクリックしたときと同じく、そのフォルダ名のフォルダがタブの起点になります。一覧の中のフォルダに止まると、次の階層が右に出ます。フォルダだけに絞るのは最初の一覧だけで、次の階層からはほかの一覧と同じくファイルも出します（ファイルに止まるとプレビュー、クリックで開く）。一覧の見出しのクリックはそのフォルダへの移動です（表示中のフォルダなら何もしません）。
  - 最近の履歴・よく使う項目の名前と「（不明）」には出ません。「…」にまとめたフォルダにも出ません。一覧を開いている間に隣のフォルダ名へ移ったときは、そこで止まったときだけ切り替わります（サイドバーの行と同じ）。
  - フォルダ名をクリックした直後は、ポインターがフォルダ名から出るまで一覧を出しません。タブの読み込みが終わる・自動更新しても一覧は閉じません。移動・タブの切り替え・入力欄を開いたときは閉じます。
- ファイル・フォルダ（アプリの中の項目でも、エクスプローラーからでも。いくつでも）をフォルダ名の上に落とすと、そのフォルダへ移動・コピーします。規則・強調・案内はフォルダのカードに落としたときと同じです（[13. ドラッグで移動・コピー・ほかのアプリへ渡す](#13-ドラッグで移動コピーほかのアプリへ渡す)）。タブの起点より上のフォルダ名（`E:\` など）にも落とせます。
  - 表示中のフォルダ（最後のフォルダ名）、最近の履歴・よく使う項目の名前、「（不明）」、区切り（`\` `›`）、「…」、空いているところでは受け付けません。エクスプローラーからフォルダを落としても、アドレス欄の上では登録になりません。入力欄を開いている間も受け付けません。
  - 落としたあとは、ポインターがフォルダ名から出るまでサブフォルダの一覧を出しません。ドラッグの途中で止まっても一覧は出ません。
- 空いているところをクリックするか、Ctrl + L・Alt + D・F4 を押すと入力欄になり、表示中のフォルダのパスが全部選ばれた状態で始まります。そのまま Ctrl + C（または右クリックの「コピー」）でパスをコピーでき、入力すると置き換わります。
- 入力欄で Ctrl + Shift + C を押すと、入力欄のパス全体を WSL から見たパスに変換し、クリップボードにコピーします（入力欄は変換したパスを全部選んだ状態。メッセージ行に「WSL のパスに変換してコピーしました。」）。`C:\temp` → `/mnt/c/temp`（ドライブ文字は小文字、`\` は `/`、空白は引用符もエスケープも付けない）、`C:\` → `/mnt/c`、WSL のフォルダ（`\\wsl.localhost\Ubuntu\home\me`・`\\wsl$\…`）→ `/home/me`。`/mnt/c/temp` の形のときに押すと `C:\temp` に戻し、戻したパスをコピーします。ほかの共有（`\\server\share`）や `/home/…` など変換できないときは、メッセージ行に出して入力欄とクリップボードはそのままです。ディスクは見ないので、無いパスも変換します。
- Enter で、入力したものをエクスプローラーのアドレス欄と同じように扱います：
  - フォルダのパス（`E:\Dev`、`"E:\Dev\"` のような引用符付き、`%USERPROFILE%` のような環境変数、`E:` はドライブの最上位）：表示中のタブの中でそこへ移動します（戻るで戻れます。タブの起点のフォルダの中なら、起点はそのまま）。表示中のフォルダからの相対パス（`..`、`sub\dir`、`\Windows`）と、表示中のフォルダにある項目の名前も使えます。`\\?\` で始まる長いパスの形は、普通の形（`\\?\UNC\server\share` → `\\server\share`）にして開きます。
  - ファイルのパス・名前：既定のアプリで開きます（実行形式の確認あり。「ダブルクリックで開く」の設定に関係なく出ます）。
  - それ以外はコマンドとして、表示中のフォルダを現在のフォルダにして実行します（エクスプローラーと同じく、ShellExecute で起動します）。`cmd`・`powershell`・`pwsh`・`wsl`・`wt`（Windows ターミナル）は、表示中のフォルダで開きます。同じ名前のフォルダが表示中のフォルダにあっても、これらの名前はターミナルとして開きます。`code .` のような引数も付けられます。表示中のフォルダの下のプログラムは、相対パスに引数を付けて実行できます（`bin\tool.exe --version`）。相対パスに見える入力で、最初の区切りまでが表示中のフォルダの中のフォルダ名に当たるもの（`setup files\readme.txt`）は、打ち間違えたパスとして「見つかりません」にします（`setup` を実行しない）。
    - ターミナルは表示中のフォルダから探しません（同じ名前の exe がフォルダに置かれていても使わない）：`cmd`・`powershell`・`wsl` は System32 のもの、`pwsh` は App Paths の登録か PATH で見つけたもの、`wt` は System32 を作業フォルダにして `-d` でフォルダを渡します。それ以外のコマンド（`code .` など）はエクスプローラーと同じ探し方です。
    - `cmd`：ネットワーク上のフォルダ（`\\server\share\…`）では `pushd` でドライブを割り当てて開きます（cmd は UNC のパスを現在のフォルダにできないため）。ネットワーク上のフォルダで引数を付けた `cmd`（`cmd /c …`）と、名前に `%` を含むネットワーク上のフォルダでの `cmd` は、Windows のフォルダで動いてしまうため実行せず、理由をメッセージ行に出します。割り当てたドライブ（`Z:` など）は、その cmd を閉じると外れます。
    - `wsl`：WSL のフォルダ（`\\wsl.localhost\Ubuntu\home\…`）は、そのディストリビューションの Linux のパス（`-d Ubuntu --cd /home/…`）で開きます。ほかのネットワーク上のフォルダはホーム ディレクトリで開きます（メッセージ行に理由が出ます）。
    - 最近の履歴・よく使う項目の一覧と、見つからないフォルダを表示しているときは、ユーザーのフォルダ（`%USERPROFILE%`）で実行します。
  - パスに何もないとき（「見つかりません」）とプログラムが起動できなかったときは、理由をメッセージ行に出し、入力欄はそのまま残ります。
- Esc、入力欄の外のクリック、ほかのタブへの切り替えで入力をやめます（入力した文字は捨てます。Enter のあとパスの確認を待っている間に Esc を押したときも、その入力は実行しません）。入力中は、カードやサイドバーに止まっても一覧・プレビューは出ません。ほかのアプリに切り替えても入力欄はそのままです（そのアプリからパスをコピーして貼り付けられます）。入力中は Backspace・Delete・Ctrl + A / C / V・Alt + ↑ ↓ などのキーは入力欄に効き、一覧には効きません。F5 は入力をやめてから読み直します。入力中は自動更新も待ちます。
- ↑（1 つ上へ）：フォルダのタブは、開いたフォルダ（登録フォルダ・ドライブ・一覧からたどったフォルダ）の上へも行けます。開いたフォルダで ↑ を押すと、その親のフォルダがタブの起点になります。ドライブの最上位（`C:\`）と共有の最上位（`\\server\share`）では押せません。「最近の履歴」「よく使う項目」の中では、開いたフォルダで ↑ を押すと一覧に戻ります（今までどおり）。
- サイドバーの登録フォルダをクリックしたとき、同じフォルダを表示しているフォルダのタブがあればそのタブに切り替えます。↑ や移動で起点の違うタブが同じフォルダを表示しているときも同じタブとして扱います。

### 5.2 名前の変わったフォルダへの追従

- 登録フォルダと開いているタブは、フォルダの名前を変えたり、同じドライブの中で移動したりしても、同じフォルダを指し続けます。
  - **このアプリで名前を変えたとき**（F2・「名前の変更」）：そのフォルダとその中を指す登録フォルダ・タブ（戻る・進むの履歴も）を、すぐ新しいパスに書き換えます。
  - **エクスプローラーなど、ほかのアプリで変えたとき**：フォルダの識別子（ボリュームのシリアル番号・ファイル ID・作成日時。名前の変更と同じドライブの中の移動では変わらない）を覚えておき、フォルダが見つからなかったときにその識別子で探します。探すのは、登録フォルダの確認（起動したとき・F5）、見つからない登録フォルダのクリック、タブの読み込み（タブの切り替え・F5・自動更新で 2 回続けて見つからなかったとき・次の起動）です。先に元の親フォルダの中を探し（2,000 個まで）、無ければドライブ全体からファイル ID で探します（5 秒まで）。見つかると、登録フォルダの行とタブを新しい場所に替えて、メッセージ行に新しいパスを出します。
  - 上のフォルダの名前が変わったとき（`E:\A\B` の `A` を `A2` にした）は、`A` そのものの識別子を覚えていて（`A` が登録フォルダか、`A` を表示しているタブがある）、元の `A` が無く `A2` がその識別子のフォルダだと確かめられたときだけ、`A` の下を指していたほかの登録フォルダ・タブもまとめて書き換えます（名前だけでは、既にあったフォルダへ移してから元の親を消した場合と区別できないため）。確かめられないときは、見つかったフォルダとその中だけを書き換え、ほかはそれぞれの識別子で探します。
  - 登録フォルダの中のフォルダ（識別子を覚えていないもの）が見つからないときは、その登録フォルダ自体も元の場所から無くなっているときに限り、登録フォルダの識別子で探します（登録フォルダが元の場所にあるなら、名前の変更では説明できないため）。
- 識別子は、登録フォルダは確認でフォルダが見つかったときに `registered_folders.json` の `file_id` に、タブは表示したときに覚えて終了時に `settings.json` の `open_tabs` の `file_id` に保存します（[2.1](#21-open_tabs-の形)、[3](#3-ほかのデータファイル)）。アプリを閉じている間に名前が変わっても、次の起動で追従します。
- 追従しないもの：ごみ箱に入ったフォルダ（削除は移動とみなさない）、別のドライブへの移動（コピーして元を消すため、別のフォルダになる）、削除して同じ名前で作り直したフォルダ、識別子を覚える前（この版で初めて見る前）に名前が変わったフォルダ、ファイル ID を持たないファイル システム（FAT32 / exFAT の USB メモリーなど）。ネットワーク上のフォルダは、元の親フォルダの中での名前の変更だけ追従します（ドライブ全体の検索はできないことが多い）。
- ピン留め・利用記録（最近の履歴・よく使う項目）・手動の並び順は、古いパスのまま残ります（見つからない項目として扱われます）。

## 6. 表示する項目の切り替え

- 最近の履歴・よく使う項目の一覧（タブの最上位）では、ツールバーの並べ替えボタンの左のボタンで「すべて表示」「フォルダのみ表示」「ファイルのみ表示」を選べます。タブごとに `settings.json` に保存します（`filter_modes`）。
- 絞り込み中は件数が「履歴 2 / 4」（表示中 / 全体）のように出ます。
- 絞り込み中にドラッグで並べ替えると、隠れている項目の位置はそのままで、表示中の項目だけが入れ替わります。
- 一覧からフォルダの中へ移動したあと（フォルダの中）と、フォルダのタブでは絞り込みません（ボタンも出ません）。

### 6.1 名前で検索（Ctrl + F）

- Ctrl + F（または Ctrl + E・F3）で、ツールバーの件数の右に検索欄が開きます。入力すると、表示中の一覧（フォルダの中・最近の履歴・よく使う項目。カードでも詳細表示でも）が、名前に入力した文字を含む項目だけになります（入力を止めて 0.2 秒後に反映）。
- 空白（全角の空白も）で区切った語は、全部を含む項目だけ残します（順番は問いません）。大文字・小文字、全角・半角、ひらがな・カタカナは区別しません（「ｒｅａｄｍｅ」で README が、「かいぎ」で「カイギ」が見つかります）。探すのは名前だけで、ファイルの中身は探しません。既定ではサブフォルダの中も探しません（設定で「サブフォルダも検索」にできます。下の「サブフォルダも検索するとき」）。
- 検索中は件数が「一致 3 / 120」（一致した数 / 全体）になり、一致する項目がなければ「「…」に一致する項目はありません。」と出ます。
- Enter・↓ で一覧に戻ります（検索は続き、件数の右に検索語が出ます。クリックか Ctrl + F で編集、× で解除）。Esc は検索を解除して一覧に戻ります。
- 検索はタブごとで、保存しません。別のフォルダへ移動すると解除されます（表示中のフォルダの名前が変わって追従したときは続きます）。
- 「表示する項目の切り替え」と同時に使えます。検索中のドラッグでの並べ替えは、隠れている項目の位置をそのままにします（上の絞り込みと同じ）。
- **サブフォルダも検索するとき**（設定「名前で検索」が「サブフォルダも検索」）：フォルダの中（フォルダのタブ、最近の履歴・よく使う項目から開いたフォルダ）での検索は、表示中のフォルダの一致のあとに、その下のすべてのフォルダの一致を、ある場所（表示中のフォルダからの相対パス）を添えて並べます（場所 → 名前の順）。
  - 2 つの方法を同時に使い、重ならないようにまとめます：Windows Search のインデックス（インデックスにある場所はすぐ見つかる）と、フォルダを順にたどる検索（インデックスにない場所も見つかる）。インデックスの結果はディスクで確かめ、なくなった項目や「表示する項目」の設定で隠れる項目は出しません。Windows Search が使えないときは、たどる検索だけで続けます。
  - 見つかった順に一覧に増えます（スクロール位置は残ります）。探している間は件数が「一致 120（サブフォルダを含む・検索中…）」、終わると「一致 120（サブフォルダを含む）」、最大の 5,000 件に届くと「・上限 5,000 件」が付きます。
  - ジャンクション・シンボリック リンクの先はたどりません（循環しないため）。読めないフォルダは飛ばします。名前の比べ方（大文字・小文字、全角・半角、ひらがな・カタカナを区別しない）はフォルダの中の検索と同じです。
  - 見つかった項目は、開く・選択・右クリック・ドラッグ・名前の変更・削除など、フォルダの中の項目と同じに使えます。ファイルの操作のあとや F5 では検索し直します。別のフォルダへ移ると検索は解除され、裏の検索も止まります。
  - 最近の履歴・よく使う項目の一覧そのものでは、設定にかかわらず一覧の中だけを検索します。

## 7. 削除（ごみ箱へ移動）

- 右クリックメニューの「削除（ごみ箱へ移動）」は、フォルダの中の項目にだけ出ます：フォルダの中のカード、オーバーレイ・フライアウトの行、行のプレビュー。最近の履歴・よく使う項目の一覧のカード、サイドバーの登録フォルダ、フライアウトの見出しには出ません。見つからない・応答がない項目では選べません。
- 選択した項目の上で右クリックすると、選択全部を対象に「削除（ごみ箱へ移動）」が出ます（選択の全部が削除できる項目のときだけ）。
- **Delete キー**（または Ctrl + D）でも、選択した項目をごみ箱へ移します。選択がないときは何もしません（ポインターの下の項目は使いません）。押し続けても確認は 1 回だけで、文字の入力欄の中では効きません。Shift + Delete（エクスプローラーの完全削除）はありません。
- 選ぶと必ず確認ダイアログが出ます（既定のボタンは「キャンセル」で、Enter だけでは削除されません）。複数でも確認は 1 回で、件数と先頭の 5 件のパスが出ます。フォルダは中のファイル・フォルダごとごみ箱へ移します。
- エクスプローラーの Delete と同じ仕組み（`IFileOperation`）でごみ箱へ移すので、ごみ箱から元に戻せます。Ctrl + Z でも元の場所に戻せます（[18](#18-元に戻すやり直し)）。複数の項目も 1 つの操作として移すので、進行状況の画面は 1 つです。大きなフォルダでは Windows の進行状況の画面が、使用中のファイルなどでは Windows のダイアログが出ます。
- **完全な削除はしません**。ごみ箱に入れられない項目（ネットワーク上のフォルダ、WSL のフォルダなど、Windows がごみ箱に入れずに完全に削除しようとする項目）は、何も消さずに中止し、「ごみ箱に移動できない場所にあるため、削除しませんでした。」と表示します。複数のときは、その項目と残りの項目は消さず、それまでに移した件数と残りの件数を表示します（例：「3 個をごみ箱に移動しました。残りの 2 個はごみ箱に移動できないため、削除しませんでした。」）。Windows のダイアログで中止・スキップした項目も消しません。
- 終わったら、表示中の一覧を読み直します（スクロール位置はそのまま。消えた項目は選択から外れ、残った項目は選択のままです）。削除中にもう一度削除・貼り付けをすると「前の操作が終わってから実行してください」と出ます。ほかのタブは次に開いたときに読み直します。ピン留めや利用記録は消しません（存在しない項目として扱われ、同じ場所にまた現れれば再び表示されます）。

## 8. 名前の変更と新しいフォルダー

- **名前の変更**：フォルダの中のカード・詳細表示の行を 1 つ選んで（Ctrl + クリック。設定の「ダブルクリックで開く」がオンなら普通のクリック）F2 を押すか、右クリックの「名前の変更」を選ぶと、名前の上に入力欄が出ます。ファイルは拡張子の前まで、フォルダは名前全体が選ばれた状態で始まります。
  - Enter で確定、Esc で取り消し。入力欄の外をクリックしても確定します（エクスプローラーと同じ）。ほかのアプリに切り替えても入力欄はそのままで、戻ると続きを入力できます。入力中は F5・Ctrl + W などのキーは効きません。
  - 名前に使えない文字（`\ / : * ? " < > |`）は入力できません（理由がメッセージ行に出ます）。CON・NUL・COM1 などの Windows が予約している名前と、255 文字以上の名前も使えません（Enter では入力欄が残り、外をクリックしたときは元の名前のままです）。前後の空白と末尾のピリオドは取り除きます。名前を空にすると元の名前のままです。
  - 拡張子が変わるときは確認が出ます（「キャンセル」で入力欄に戻ります）。同じ名前の項目（大文字・小文字の違いだけのものを含む）がすでにあるときは「同じ名前の項目がすでにあります」と出て、入力欄に戻ります（上書き・フォルダの統合はしません）。大文字・小文字だけの変更はできます。
  - 名前を変えると一覧を読み直し、その項目を選んだ状態にします（入力欄の外をクリックして確定し、そのクリックで別の項目を選んだときは、その選択のまま）。エクスプローラーの名前の変更と同じ仕組み（`IFileOperation`）です。Ctrl + Z で元の名前に戻せます（[18](#18-元に戻すやり直し)）。
  - 最近の履歴・よく使う項目の一覧のカード、サイドバーの行、オーバーレイ・フライアウトの行と見出し、見つからない・応答がない項目、ドライブそのものは変更できません。
  - フォルダの名前を変えると、そのフォルダとその中を指す登録フォルダ・タブ（戻る・進むの履歴も）は新しい名前に合わせて書き換えます（[5.2](#52-名前の変わったフォルダへの追従)）。ピン留め・利用記録は古い名前のまま残ります（見つからない項目として扱われます）。
- **複数をまとめて変更**（エクスプローラーと同じ）：同じフォルダの中の項目を複数選んで F2 を押すと、最後にクリックした項目（なければ表示順の先頭）の名前に入力欄が出ます（メッセージ行に「選択した n 個の項目の名前を…」と出ます）。確定すると、選んだ項目すべてを表示順に「名前 (1)」「名前 (2)」…に変えます。
  - ファイルはそれぞれの拡張子を保ち、フォルダには拡張子を付けません（例：「旅行」と入力すると「旅行 (1).jpg」「旅行 (2).png」「旅行 (3)」）。入力した名前が、入力欄を出したファイルの拡張子で終わっていれば、その拡張子は外します（「旅行.jpg」も「旅行」と同じ）。拡張子の確認は出ません。
  - 番号はすべての項目で通しです。フォルダの中にすでにある名前（隠しファイルを含む。大文字・小文字の違いは問わない）と、選んだほかの項目の今の名前になる番号は飛ばします。新しい名前が 254 文字を超える項目はそのままです。
  - Esc、名前を変えずに確定、名前を空にしたときは何もしません。使えない名前の扱いは 1 つのときと同じです。
  - 1 つの操作として変えるので、Ctrl + Z 1 回でまとめて元の名前に戻せます（[18](#18-元に戻すやり直し)）。途中で失敗した項目は、エクスプローラーと同じ画面で再試行・スキップ・キャンセルを選べます。変えた数（変えられなかった数、中止したこと）がメッセージ行に出ます。
  - 終わると一覧を読み直し、選んでいた項目を選んだままにします。
  - 最近の履歴・よく使う項目の一覧のカード、見つからない・応答がない項目、ドライブそのものを含む選択では何もしません（メッセージ行に出ます）。右クリックの「名前の変更」は 1 項目のメニューにだけ出ます。
- **新しいフォルダー**：Ctrl + Shift + N か、一覧の空いているところの右クリックの「新しいフォルダー」で、表示中のフォルダに「新しいフォルダー」を作り、そのまま名前の入力欄を出します（Esc で抜けると「新しいフォルダー」のまま残ります）。Ctrl + Shift + N のすぐ後に打ち始めた文字は、入力欄が出たときにそのまま入ります。同じ名前があるときは「新しいフォルダー (2)」「新しいフォルダー (3)」…になります。最近の履歴・よく使う項目の一覧、読み込み中・読み込めなかったフォルダでは作れません。
- エクスプローラーのメニューの「新規作成」で作った項目は、名前の入力欄にはなりません（作ったあと F2 で変更してください）。

## 9. 選択と切り取り・コピー・貼り付け

- **選択**：カード・詳細表示の行を Ctrl + クリックすると選択に加わり（もう一度で外れる）、Shift + クリックで最後に Ctrl + クリックした項目からの範囲、Ctrl + Shift + クリックでその範囲を足します。選んだ項目はアクセント色の枠と塗りで表示され、ツールバーの件数の右に「n 個を選択」と、選んだファイルの合計サイズが出ます（下の「選択の表示」）。Ctrl + A で表示中の一覧の項目を全部、Esc・普通のクリック・一覧の空いているところのクリックで選択を外します。設定の「ダブルクリックで開く」がオンのときは、普通のクリックでその項目だけを選び（Shift + クリックの範囲もそこから始まります）、ダブルクリックで開きます（開いたファイルは選んだまま）。見つからない・応答がない項目は選べません。選択はタブごとで、別のフォルダへ移動すると外れます。選択した項目は Enter で開けます（1 つならクリックと同じ、複数ならファイルを全部開いてフォルダはそれぞれ新しいタブ。[4. 操作](#4-操作)）。
  - **範囲選択**：一覧の空いているところ（カードの間・最後の行の右や下、詳細表示では最後の行より下）でボタンを押し、システムのドラッグ距離より動かすと枠が出て、枠に少しでも触れた項目を選びます（エクスプローラーと同じ。カードの間の隙間だけを囲んでも何も選ばれません）。修飾キーは押したときのものを使います：なしは枠の項目だけ（押したときに選択は外れています）、Ctrl は押したときの選択に対して枠の項目を反転、Shift は押したときの選択に足します。Esc で押したときの選択に戻ります。枠を一覧の上下の端の外へ出すと自動でスクロールし（外へ出すほど速い）、ホイールでもスクロールできます。見えなくなった項目も選択に残ります。読み込み中・名前の入力中・「応答がありません」の表示の上からは始まりません。ドラッグの間はほかのキー（F5・Delete・Ctrl + A など）は効かず、オーバーレイ・フライアウトも開きません。
  - **キーボードでの選択**：矢印・Home / End・PageUp / PageDown で現在の項目（カーソル）を動かすと、その項目だけが選ばれます。Shift を足すと起点からの範囲、Ctrl を足すと選択はそのままでカーソルだけが動き、Ctrl + Shift は範囲を選択に足します。Space でカーソルの項目だけを選び、Ctrl + Space で選択を切り替えます。起点はクリックと共通です（Shift + クリックのあとの Shift + ↓ は、同じ起点から範囲を広げます）。詳しくは [19. キーボード操作](#19-キーボード操作)。
  - **選択の表示**：ツールバーの件数の右に「3 個を選択　12.4 MB」のように、選んだ数と、選んだ**ファイル**の合計サイズを出します。フォルダも選んでいるときは「3 個を選択　12.4 MB（フォルダを除く）」（フォルダの中身は数えません）、フォルダだけのときはサイズを出しません。サイズが分からないファイル（サイズを読み込む前の最近の履歴・よく使う項目のカードなど。あとでサイズが分かっても、選択か一覧が変わるまで合計に入りません）は合計に入れず、サイズの分かるファイルが 1 つもなければ「n 個を選択」だけです。合計は一覧が読み込んだサイズから計算するので、ディスクには触りません。自動更新でファイルのサイズが変わると、合計も変わります。
  - **ファイル種別選択**：項目・選択・一覧の空いているところの右クリックの「ファイル種別選択」▶ に、表示中の一覧にある種類（「フォルダ」、拡張子ごと、「拡張子なし」）と件数が並び、選ぶとその種類の項目だけを選択します（それまでの選択は置き換え）。拡張子は大文字・小文字を区別せず（`.JPG` と `.jpg` は同じ）、それ以外はそのまま比べます（`.jpg` と `.jpeg` は別）。対象は今の一覧に出ている項目だけ（検索・表示する項目の絞り込みのあと）で、使えない項目（見つからない・応答がない）は含めません。
- Ctrl か Shift を押すと、カードのオーバーレイと詳細表示の行の一覧・プレビューは閉じ、押している間は開きません（隣の項目を選ぶときに一覧が重ならないため）。サイドバーから出した一覧はそのままです。
- **切り取り・コピー**：Ctrl + X / Ctrl + C は選択した項目に効きます（選択がなければ何もしません。ポインターの下の項目は使いません）。右クリックの「切り取り」「コピー」は、選択した項目の上なら選択全部、そうでなければその項目に効きます（選択の外を右クリックすると選択は外れます）。複数を選んでいるときのメニューは「切り取り」「コピー」「パスをコピー」（1 行に 1 つ）と「削除（ごみ箱へ移動）」です。
  - 切り取れるのはフォルダの中の項目だけです（「削除（ごみ箱へ移動）」と同じ範囲）。最近の履歴・よく使う項目の一覧のカード、サイドバーの行、フライアウトの見出しは切り取れません（コピーはできます。Ctrl + X では「この一覧の項目は切り取れません（コピーはできます）」と出ます）。ドライブそのものは切り取りもコピーもできません。
  - クリップボードにはエクスプローラーと同じ形式で入るので、エクスプローラーやほかのアプリに貼り付けられます。切り取った項目は薄く表示され、貼り付けが済む・クリップボードがほかの内容に替わる・エクスプローラーで貼り付けて項目が移動した（ウィンドウに戻ったときに確かめます）と、元に戻ります。
- **貼り付け**：Ctrl + V は表示中のフォルダへ、右クリックの「貼り付け」はそのフォルダ（フォルダのカード・行・見出し、登録フォルダ、ドライブ）へ、一覧の空いているところの右クリックの「貼り付け」は表示中のフォルダへ貼り付けます。最近の履歴・よく使う項目の一覧と、タブがないときは貼り付けできません。エクスプローラーで切り取り・コピーした項目も貼り付けられます。
  - 切り取った項目は移動、コピーした項目はコピーします（ネットワーク上の項目の切り取りも移動です。エクスプローラーと同じ）。削除できない場所（読み取り専用のメディアなど）の項目は、切り取りでもコピーします。同じフォルダへのコピーは「x - コピー」の名前で複製し、同じフォルダへの切り取り・フォルダをそのフォルダ自身の中へ・ドライブそのものは貼り付けません。
  - 同じ名前の項目があるときや大きなコピーでは、Windows のダイアログ・進行状況の画面が出ます（エクスプローラーと同じ仕組み `IFileOperation`）。FolderDeck 自身の確認ダイアログは出ません。終わったら結果（貼り付け先、移動できずにコピーした数）を表示して一覧を読み直し、表示中のフォルダへ貼り付けたときは届いた項目を選択します。
  - 切り取りは、移動が全部済んだときだけクリップボードから消えます。同じ名前のダイアログでスキップした項目などがあると、切り取りは残り（薄いまま）、もう一度貼り付けられます。
  - 貼り付けは一度に 1 つです（実行中にもう一度貼り付けると「前の操作が終わってから実行してください」）。Ctrl + V を押し続けても 1 回だけです。実行中にウィンドウを閉じようとすると「ファイルの移動・コピー・削除が実行中です。終了すると途中で中断されます。」と確認します（既定は「キャンセル」）。
  - FolderDeck の中のコピー・移動は、貼り付けとフォルダへのドラッグ＆ドロップです（[13. ドラッグで移動・コピー・ほかのアプリへ渡す](#13-ドラッグで移動コピーほかのアプリへ渡す)。同じ名前のダイアログ・結果の表示・一度に 1 つは貼り付けと同じ）。Ctrl + Z で元に戻せます（コピーした項目はごみ箱へ、移動した項目は元のフォルダへ。[18](#18-元に戻すやり直し)）。移動した項目のピン留め・利用記録・登録フォルダは元の場所のままで、見つからない項目として表示されます。

## 10. エクスプローラーのメニュー（その他のメニュー（Windows））

- 右クリックメニューのいちばん下の「その他のメニュー（Windows）」を選ぶと、同じ場所にエクスプローラーの右クリックメニューが出ます。インストールしたアプリが追加した項目（7-Zip の圧縮・展開など）、「送る」「プログラムから開く」「プロパティ」などが使えます。Shift を押しながら右クリックしてアプリのメニューを開くと、エクスプローラーで Shift + 右クリックしたときの項目も出ます（カードに重なった一覧と詳細表示の行の横の一覧は、Shift を押すと閉じるため、その中の行では使えません）。
- 出るのは、カード、詳細表示の行、オーバーレイ・フライアウトの行と見出し、行のプレビュー、サイドバーの登録フォルダと、一覧の空いているところ（この節の「一覧の空いているところ」）です。選択した項目の上では、選択全部のメニューになります（別々のフォルダの項目をまとめたとき、たとえば最近の履歴の一覧でも）。見つからない・応答がない項目とドライブそのもの（`C:\` など）では選べません。PC の節のドライブの行には出ません（「フォーマット」などドライブの操作が並ぶため）。
- 設定の「右クリックのメニュー」を「Windows のメニュー」にすると、上の項目を右クリックしたとき、アプリのメニューを経由せずにエクスプローラーのメニューが出ます。いちばん上にアプリの項目（1 項目なら「開く」「エクスプローラーで表示」「パスをコピー」「切り取り」「コピー」「貼り付け」「ターミナルで開く」などの「…で開く」「ピン留めする」「削除（ごみ箱へ移動）」など、アプリのメニューと同じもの。選択全部なら「切り取り」「コピー」「パスをコピー」「…で開く」（全部が同じフォルダにあるとき）「削除（ごみ箱へ移動）」）、区切り線の下にエクスプローラーの項目が並びます。
  - 1 項目のメニューでは、アプリの「開く」が太字の既定の項目になり、エクスプローラーの「開く」は出しません（フォルダはアプリの中で開くため）。エクスプローラーの「パスとしてコピー」も、アプリの「パスをコピー」と重なるので出しません。選択全部のメニューでは、エクスプローラーの「開く」が残ります。
  - アプリの「ターミナルで開く」「PowerShell で開く」は、項目のメニューでも Windows 標準の子メニュー（▶）になります（一覧の空いているところと同じ。この節の「一覧の空いているところ」）。フォルダの項目のメニューでは、エクスプローラー自身の「ターミナルで開く」「Code で開く」「Linux シェルをここに開く」なども下に並び、同じ名前が 2 つずつに見えることがあります（取り除いていません）。ファイルの項目のメニューでも、VS Code を「エクスプローラーのファイル コンテキスト メニューに [Code で開く] アクションを追加する」の設定で入れていると、エクスプローラー自身の「Code で開く」が下に出ます（そちらはファイルそのものを開き、アプリの「Code で開く」はファイルがあるフォルダを開きます）。
  - アプリの項目は文字だけで、アイコンは付きません。メニューの見た目は Windows 標準の（明るい）メニューで、アプリのテーマ（ダーク）には合わせません。
  - Shift を押しながら右クリックすると、エクスプローラーの拡張メニューの項目も出ます（上と同じく、カードに重なった一覧と詳細表示の行の横の一覧の中では使えません）。Shift + F10 で開いたメニューは拡張メニューになりません（Shift はキーの一部のため）。
  - Shift + F10・アプリケーション キーでも、同じ設定に従ってアプリのメニューかエクスプローラーのメニューが出ます（[19. キーボード操作](#19-キーボード操作)）。
  - 次のときは、設定に関係なくアプリのメニューが出ます：ドライブの行、「PC」の見出し、表示中のフォルダがない一覧の空いているところ（最近の履歴・よく使う項目の一覧、読み込み中）、見つからない・応答がない項目とドライブそのもの。エクスプローラーのメニューが出せなかったとき（取れない、表示する前のエラー）も、同じ位置にアプリのメニューを出します（「その他のメニュー（Windows）」は付きません）。
  - エクスプローラーのメニューを 8 秒以内に用意できなかったときは、「エクスプローラーのメニューが時間内に準備できなかったため、アプリのメニューを出しました。」と表示してアプリのメニューを出します。その項目は 5 分間、右クリックで最初からアプリのメニューになります（毎回 8 秒待たされないため。5 分たつと、もう一度エクスプローラーのメニューを試します）。
  - 右クリックしてからメニューが出るまで、エクスプローラーのメニューの用意にかかる時間だけ待ちます（拡張機能が多いと、アプリのメニューより遅れて出ます）。その間にもう一度右クリックしても、メニューは重ねて出しません。
- **一覧の空いているところ**：フォルダの中（フォルダのタブ、最近の履歴・よく使う項目から開いたフォルダ、ドライブの最上位）で空いているところを右クリックすると、表示中のフォルダのメニューが出ます。アプリの項目は「貼り付け」「新しいフォルダー」（作って名前の入力欄を出す）「並べ替え」（▶。表示中のタブの並び方）「最新の情報に更新」「エクスプローラーで表示」（そのフォルダを開く）「パスをコピー」「登録フォルダに追加」（登録していないときだけ）「ターミナルで開く」「PowerShell で開く」「Code で開く」「WSL で開く」（[4. 操作](#4-操作)）で、エクスプローラーの項目は、エクスプローラーで空いているところを右クリックしたときのもの（「新規作成」「プロパティ」、アプリが追加した項目など）です。「アプリのメニュー」ではいちばん下の「その他のメニュー（Windows）」から、「Windows のメニュー」では最初からエクスプローラーのメニューの上にアプリの項目が並びます。
  - 詳細表示では、行の右の空き（最後の列より右）も行の一部です（そこでの右クリックはその行のメニュー）。空いているところのメニューは、最後の行より下で右クリックしたときに出ます。
  - エクスプローラーの「表示」「並べ替え」「最新の情報に更新」は出ません（アプリの中にエクスプローラーの一覧がないため。並べ替えと読み直しは、アプリの「並べ替え」「最新の情報に更新」で行います）。「新規作成」で作った項目は、実行後の一覧の読み直しで出ますが、名前を入力する状態にはなりません（名前は「新しいフォルダー」などのまま。F2 で変更できます。フォルダはアプリの「新しいフォルダー」・Ctrl + Shift + N なら名前の入力欄が出ます）。エクスプローラーの一覧を前提にした項目（「ターミナルで開く」など）は動かないことがあります。
  - 「Windows のメニュー」では、アプリの「ターミナルで開く」「PowerShell で開く」は Windows 標準の子メニュー（▶）になり、その中で「開く」「管理者として開く」を選びます（子メニューの中の項目は太字の既定にはなりません）。アプリの「並べ替え」も子メニュー（▶）になり、今の並び方にチェック（✓）が付きます。エクスプローラー自身の「ターミナルで開く」「Code で開く」「Linux シェルをここに開く」なども、区切り線の下に並ぶことがあります（取り除いていません。項目のメニューの「Code で開く」まで消えるため）。アプリの項目のほうは、空いているところでは表示中のフォルダで、項目のメニューではそのフォルダ（ファイルならそれがあるフォルダ）で開きます（例外は §4 の表の「…で開く」の行）。
- エクスプローラーのメニューから、**「削除」「名前の変更」「切り取り」「コピー」「貼り付け」「元に戻す」「やり直し」は取り除いて**あります。
  - 削除：エクスプローラーの削除は、ごみ箱に入らない場所では完全に削除します。FolderDeck は完全な削除をしないため、アプリの「削除（ごみ箱へ移動）」だけを使います。
  - 切り取り・コピー・貼り付け：アプリ自身の操作（[9. 選択と切り取り・コピー・貼り付け](#9-選択と切り取りコピー貼り付け)）にそろえるためです（切り取った項目の薄い表示、貼り付け先の決め方、結果の表示）。「ショートカットの貼り付け」は残しています。
  - 名前の変更：アプリ自身の「名前の変更」（F2。[8. 名前の変更と新しいフォルダー](#8-名前の変更と新しいフォルダー)）にそろえるためです（エクスプローラーのメニューの「名前の変更」は、アプリの中にエクスプローラーの一覧がないので入力欄が出ません）。
  - 元に戻す・やり直し（空いているところのメニュー）：エクスプローラーの「元に戻す」は、表示中のフォルダと関係なく、エクスプローラーで最後に行ったコピー・移動・新規作成などを取り消します（作った項目を消すこともあります）。思わぬ項目を消さないため出しません。FolderDeck で行った操作は、アプリ自身の「元に戻す」（Ctrl + Z。[18](#18-元に戻すやり直し)）で戻せます。
  - 取り除けずに残った項目（拡張機能がサブメニューの中に置いたなど）も、選んだときに動作の名前（verb）が分かれば実行せずに閉じます。
- メニューを出している間、カスケードの一覧は開いたままで、ポインターがほかのカードに載っても開閉しません。メニューを閉じると一覧はふだんどおりに戻ります（ポインターが一覧の外なら少し待って閉じます）。ほかのウィンドウをクリックしてメニューを閉じたときは、一覧も閉じます。
- 項目を選んで実行したときは、表示中の一覧を読み直し、ウィンドウに戻ったときにもう一度読み直します（7-Zip の展開のように、メニューを閉じた後に別のプログラムが続きを行うことがあるため）。何も選ばずに閉じたときは読み直しません。
- 「その他のメニュー（Windows）」から開いたメニューを 8 秒以内に用意できないとき（応答しない拡張機能など）や、メニューが取れないときは何も出さず、「このメニューは表示できませんでした」と表示します（「Windows のメニュー」の設定では、代わりにアプリのメニューを出します。上の説明）。時間切れのメニューが後から出ることはありません。
- **制約**：Windows 11 の新しい右クリックメニューにだけ出る項目（ストアのアプリなどが追加するもの）は出ません（エクスプローラーの「その他のオプションを確認」で出るメニューと同じ内容です）。拡張機能が応答しなくなってもアプリは止まりませんが、拡張機能が異常終了したときは FolderDeck も一緒に終了することがあります（エクスプローラーと同じ仕組みで、拡張機能をアプリの中で動かすため）。

## 11. 並べ替えとピン留め

- ピン留めした項目のカードには、どのタブでも（フォルダの中のカードも）左下に 📌 が出ます。サムネイルに重なる一覧（オーバーレイ）とは重ならないので、ホバー中も表示されたままです。詳細表示では名前の右に出ます。📌 をクリックするとピン留めを外せます（右クリックの「ピン留めを外す」と同じ。見つからない・応答がない項目は除く）。
- ツールバーの並べ替えボタン（カードの形・詳細表示のボタンの左）で、「手動（ドラッグで並べた順）」と、名前・更新日・サイズ・種類のそれぞれ昇順・降順を選べます。カード表示でも詳細表示でも同じ並び方が効きます。一覧の空いているところ（カード表示でも詳細表示でも。最近の履歴・よく使う項目の一覧と読み込み中も）の右クリックの「並べ替え」（▶）でも同じものを選べ、今の並び方にチェックが付きます（右クリックしたときに表示中のタブだけが替わります）。
  - 並び方はタブごとに保存され、そのタブの一覧と、そのタブで開いたフォルダの中の両方に効きます。1 つのタブで変えても、ほかのタブ（ほかのフォルダのタブも）は変わりません（以前の版では、フォルダのタブは全部で 1 つの並び方を共有していました）。新しく開いたタブは、直前に表示していたタブの並び方で始まります（[5](#5-タブとサイドバー登録フォルダ)）。保存先は `settings.json` の `open_tabs` の各要素の `sort_mode` です（[2.1](#21-open_tabs-の形)）。
  - 名前はエクスプローラーと同じ自然順（2 が 10 より前）。更新日が分からない項目（応答がないものなど）は、どちらの向きでも最後です。
  - サイズ順では、フォルダ（サイズを数えません）とサイズの分からないファイルは、どちらの向きでも最後です。同じサイズの項目は名前順で、降順のときは名前も降順です（フォルダの中では、フォルダどうしも名前の順が逆になります）。フォルダの中では、昇順ならフォルダが先、降順ならフォルダがファイルの後ろです（エクスプローラーと同じ）。
  - 種類順は**拡張子の順**です（詳細表示の「種類」の列に出る名前の順ではありません。たとえば `.docx` は「Microsoft Word 文書」と出ますが、d の位置に並びます）。拡張子の大文字・小文字は区別せず、同じ拡張子の項目（フォルダどうしも）は名前順で、降順のときは名前も降順です。最近の履歴・よく使う項目の一覧では、フォルダは拡張子なしのファイルと同じ扱いで、昇順なら先頭に来ます。
  - 「手動」のとき、最近の履歴・よく使う項目の一覧はドラッグで並べた順、フォルダの中は既定の順（フォルダ→ファイル、名前順）です。フォルダの中では、名前・サイズ・種類の順のとき、エクスプローラーと同じく昇順ならフォルダがファイルより先、降順ならファイルより後ろに来ます（フォルダどうし・ファイルどうしはそれぞれ選んだ向きで並びます）。
  - 更新日順では、フォルダの中でもフォルダとファイルを分けず、フォルダ自身の更新日時（エクスプローラーの「更新日時」と同じ。中の項目の追加・削除・名前の変更で変わり、さらに下の階層の変更では変わりません）で混ぜて並べます。同じ日時ならフォルダが先です。最近の履歴・よく使う項目の一覧は、どの並び方でももともと混ざっています。
- **ピン留めした項目は位置が動きません**。名前順・更新日順などにしても、ピン留めしたカードは「手動」の並び（フォルダの中では既定の並び）での位置にとどまり、ピン留めしていないカードだけが空いている位置に順に入ります。
  - 例：手動の並びが [A, B📌, C, D📌, E] のとき「名前（降順）」にすると [E, B📌, C, D📌, A]。
  - 「手動」以外の並び方の一覧（最近の履歴・よく使う項目）でピン留めすると、カードは表示中の位置のまま固定されます（「手動」の並びの中でそのカードだけを表示中の位置へ移し、ほかのピン留めカードの位置やほかのカードの順は変えません）。この移動は、ドラッグで並べたことがある（`card_order.json` に並びがある）ときだけ保存し、そうでなければ次に読み込み直したとき（タブの切り替え、F5 など）にそのカードは元の並びでの位置（よく使う項目では先頭のピン留めの並び）へ移ります。
  - ピン留めを外すと、そのカードは並べ替えた位置へ移ります。
- **ドラッグで並べ替え**：最近の履歴・よく使う項目の一覧でだけ、カードをドラッグして順番を入れ替えられます（フォルダの中と読み込み中はできません。サイドバーの登録フォルダは行のドラッグで入れ替えます）。
  - 入る位置にアクセント色の縦線が出ます（カードの左半分＝その前、右半分＝その後ろ、カードの間の隙間＝縦線の位置、最後のカードより後ろの空き＝末尾）。詳細表示では、行と行の間に横線が出ます（ポインターにいちばん近い境目）。上端・下端に近づけると自動でスクロールします。Esc か、ウィンドウの中の一覧の外（ツールバーなど）で離すと取り消しです。
  - 同じドラッグでウィンドウの外（エクスプローラー、PowerPoint、デスクトップなど）まで運んで離すと、並びは変わらず、そのアプリにファイル・フォルダを渡します（[13. ドラッグで移動・コピー・ほかのアプリへ渡す](#13-ドラッグで移動コピーほかのアプリへ渡す)）。
  - 「手動」以外の並び方のときにドラッグすると、その時点の表示順のまま「手動」に切り替わり、「並び順を「手動」に切り替えました。」と表示されます。
  - 最近の履歴・よく使う項目で並べたあとに新しく加わった項目は、元の並び（新しい順・よく使う順）で直前にある項目のすぐ後ろに入ります（前に何もなければ先頭）。並べた項目は、開き直しても先頭には移りません。
  - 元の並び（新しい順・よく使う順）に戻したいときは、ツールバーの並べ替えメニューか、一覧の空いているところの右クリックの「並べ替え」の最後の「手動の並びをリセット」を選びます（最近の履歴・よく使う項目だけ。ドラッグで並べたことがあるときに選べます。確認なしで `card_order.json` からそのタブの並びを消します）。フォルダのタブには出ません（ドラッグで並べる一覧がないため）。

## 12. 詳細表示

ツールバーの並べ替えボタンの右にある 3 つのボタンの右端（横線 3 本）で、カードの代わりに 1 項目 1 行の一覧にできます。表示はタブごとに覚え、`settings.json` に保存します（`open_tabs` の要素の `card_shape` が `details`）。新しく開いたタブは、直前に表示していたタブの表示で始まります（[5](#5-タブとサイドバー登録フォルダ)）。

- 列は「名前」（アイコンつき。ピン留めした項目は名前の右に 📌）「更新日時」「種類」「サイズ」です。サイズはファイルだけに出て、エクスプローラーと同じく KB 単位の切り上げです。最近の履歴・よく使う項目の一覧では、名前の右に補足（いつ使ったか、どこにあるか）が、行の右端に ×（ポインターを乗せている間）が出ます。
- サムネイルも、フォルダの中身の件数も読み込みません。項目の多いフォルダでも軽く開けます（下の追加の列を表示したときだけ、表示している行のファイルのプロパティを読みます）。
- **追加の列**（エクスプローラーの列の選択と同じ）：列の見出し（見出しの行の空いているところを含む）を右クリックすると、表示する列を選ぶメニューが出ます。「名前」「更新日時」「種類」「サイズ」はいつも表示します。追加できるのは「撮影日時」「作成者」「大きさ」「カメラの製造元」「カメラのモデル」「作成日時」「タイトル」「タグ」「長さ」「評価」で、サイズの右に決まった順で並びます（見出しの名前は Windows の名前を使います）。既定はどれも表示しません。選んだ列は全部のタブで共通で、すぐ保存します（`details_extra_columns`）。
  - 値は Windows のプロパティ（エクスプローラーと同じ書式）で、表示している行の分だけ裏で読み、読めたものから出ます。値のない項目（写真でないファイルの撮影日時など）は空です。OneDrive の「オンラインのみ」のファイルはダウンロードせず、ファイルを開かずに分かる値だけを出します。
  - 追加の列では並べ替えできません（見出しのクリックは何もしません）。値はあとから届くので、届くたびに行が動いてしまうためです。
  - 幅は基本の列と同じく、見出しの右の境界線のドラッグで変え、隠しても覚えておきます。ウィンドウが狭いときは、名前の次に、更新日時・種類・サイズと一緒に縮めて表示します。
- **列の見出しをクリックすると、その列で並べ替えます**（もう一度クリックで逆順。名前・種類は昇順から、更新日時・サイズは新しい順・大きい順から）。並び方はツールバーの並べ替えボタンと同じもので、「手動」に戻すときは並べ替えボタンか、空いているところの右クリックの「並べ替え」から選びます。「種類」は拡張子の順です（[11. 並べ替えとピン留め](#11-並べ替えとピン留め)）。
- **列の幅**：エクスプローラーと同じく、どの列（名前・更新日時・種類・サイズ）も見出しの**右の境界線**をドラッグして幅を変えられます（名前は 120〜2000、ほかは 48〜600。既定は名前 360・更新日時 150・種類 170・サイズ 96。`settings.json` の `details_columns` に保存）。
  - 境界線はポインターに付いていき、左にある列は動きません。最後の列より右は空きのままです（ウィンドウが広いと右に余白が残ります）。
  - 列を広げられるのは右の空きの分までです（ほかの列を押し出しません）。空きがないときは、先にほかの列（名前など）を狭めてください。横スクロールはありません。
  - ウィンドウが狭くて保存した幅が収まらないときは、まず名前の列を（120 まで）、それでも足りなければほかの列を一時的に縮めて表示します。保存した幅は変わらず、ウィンドウを広げると戻ります。このとき名前の列は縮んで見えているので、ほかの列を狭めると空いた分はまず名前の列に戻り、名前が保存した幅に戻るまで境界線はその場に留まります。
- **フォルダの名前（アイコン・名前・📌 の部分）にポインターを止めると**、名前のすぐ右にそのフォルダの中身の一覧が出ます（カードのオーバーレイに当たるもの。そこから先のフライアウト・プレビュー・クリック・右クリックは同じです）。名前の右の余白・補足（最近の履歴の日時と場所）・更新日時・種類・サイズの列では出ません（一覧はそこに重なって出るので、そこで止まるとポインターの真下に開いてしまうため）。
- **プレビューできるファイル（画像・Office・テキストなど。[14. プレビューできるファイル](#14-プレビューできるファイル)）の名前にポインターを止めると**（0.3 秒。FolderDeck が前面でないときは 0.5 秒）、名前のすぐ右にそのファイルのプレビューが出ます。フォルダの一覧と同じく、名前の右の余白やほかの列では出ません。
  - プレビューにポインターを移しても、行は強調されたままです。プレビューのクリックでファイルを開き（行のクリックと同じ。実行形式の確認なども同じ。1 回のクリックで開くので、「ダブルクリックで開く」がオンでも確認は出ます）、右クリックでそのファイルのメニュー（選択中でも、そのファイル 1 つのメニュー）、ドラッグでほかのアプリへ渡せます。Esc、Ctrl / Shift、名前とプレビューの外へ出ると閉じます。
  - サイズの列が空のファイル（サイズが分からないもの）、見つからない・応答がない項目では出ません。
- クリック（開く・移動）、右クリックのメニュー、ほかのアプリへのドラッグ、一覧での並べ替えドラッグ、右ボタンを押したままの左クリック（エクスプローラーで表示）は、行のどこでもカードと同じです。
- カードの大きさのスライダーと Ctrl + ホイールは詳細表示では使いません（大きさの設定はそのまま残ります）。
- カード表示と詳細表示を切り替えると、一覧は先頭から表示されます。戻る・進むで前の場所へ戻ったときも、切り替える前のスクロール位置には戻りません（2 つの表示では位置の数え方が違うため）。

## 13. ドラッグで移動・コピー・ほかのアプリへ渡す

カード、一覧（オーバーレイ・フライアウト）の行、プレビュー、サイドバーの登録フォルダをドラッグして、アプリの中のフォルダやほかのアプリに落とせます。エクスプローラーからドラッグしたときと同じ形式（ファイルのパスの一覧）で渡します。

**アプリの中のフォルダへ落とす（移動・コピー）**

- フォルダのカード、詳細表示のフォルダの行、サイドバーの登録フォルダ・ドライブの行、アドレス欄のフォルダ名（表示中のフォルダを除く。[5.1 アドレス欄](#51-アドレス欄)）の上で離すと、そのフォルダへ移動またはコピーします。落とす先のフォルダは強調表示され、サイドバーの上端に「「フォルダ名」へ移動」「「フォルダ名」へコピー」と出ます。
- **表示中のフォルダへ**：フォルダを表示しているタブの一覧の、フォルダのカード・行以外のところ（カードの間、最後のカード・行の後ろ、詳細表示の最後の行より下、列の見出し、スクロール バー、ファイルのカード・行の上）で離すと、表示中のフォルダへ移動またはコピーします。エクスプローラーと同じく、ファイルの上に落とすとそのファイルのあるフォルダ（表示中のフォルダ）に入ります（ショートカット `.lnk` や実行ファイルの上でも、リンク先やプログラムには渡しません）。強調表示はなく、サイドバーの上端に「「表示中のフォルダ名」へ移動」「「表示中のフォルダ名」へコピー」と出ます。
- 移動かコピーかはエクスプローラーと同じです：

| 押しているキー | 同じドライブ | 別のドライブ・ネットワーク |
|---|---|---|
| なし | 移動 | コピー |
| Shift | 移動 | 移動 |
| Ctrl | コピー | コピー |
| Alt | ショートカットを作成 | ショートカットを作成 |
| Ctrl + Shift、右ボタンのドラッグ | 受け付けない | 受け付けない |

- 同じドライブかは表記で判断します（ドライブ文字か `\\server\share`）。割り当てたネットワーク ドライブ（Z: など）と、その共有の `\\server\share` 表記は別のドライブとして扱います。読み取り専用のメディアや削除できない場所の項目は、移動のときもコピーします。
- **Alt を押しながらのドロップ**（エクスプローラーと同じ）：落とした先のフォルダに、項目ごとにショートカット（「名前 - ショートカット.lnk」。同じ名前があれば「名前 - ショートカット (2).lnk」…）を作ります。元の項目はそのままです。フォルダのカード・行、サイドバーの登録フォルダ・ドライブの行、アドレス欄のフォルダ名、表示中のフォルダの一覧のどれにも落とせ、エクスプローラーからのドラッグでも作れます。同じフォルダの項目（表示中のフォルダの一覧に落としたとき）やフォルダの中へも作れます。ショートカットをショートカットにしたときは、元のショートカットを複製します。ドラッグ元がショートカットの作成を許さないとき、ごみ箱の項目、項目そのものの上では受け付けません。ポインターの近くに「「X」にショートカットを作成」と出ます。作ったショートカットは選択され、Ctrl + Z で元に戻せます（ごみ箱へ移します）。既存のファイルは上書きしません。
- 移動できるのはフォルダの中の項目だけです（切り取りと同じ範囲）。最近の履歴・よく使う項目の一覧のカード、フライアウトの見出しはコピーだけです（Shift では受け付けません）。登録フォルダの行のドラッグは並べ替えだけで、フォルダの上に落としても中には入りません。
- 選択した項目の 1 つをドラッグすると、選択した項目をまとめて移動・コピーします。選択に含まれるフォルダ・自分自身の中・すでにあるフォルダ（元のフォルダ）の上では受け付けません（一部だけがすでにあるときは、残りを移動・コピーして「除きました」と出ます）。
- 表示中のフォルダへ落とすときの例外（すでにそのフォルダにある項目）：
  - 全部がすでにあるとき（表示中のフォルダの項目をその一覧に落としたときなど）は、**Ctrl だけ**を押しているときに複製します（同じ名前は「名前 - コピー」。貼り付けと同じ名前の変更。Ctrl + Z で複製を取り消せ、複製した項目を選択します）。キーなし・Shift では受け付けません（Alt・Ctrl + Shift・右ボタンは表のとおり受け付けません）。
  - 一部だけがすでにあるとき：Ctrl なしは残りを移動・コピーし、すでにある項目は除いて「除きました」と出ます。Ctrl では全部をコピーし、すでにある項目は名前を変えて複製します。キーなしで別のドライブの項目を含むためコピーになるときも、複製はしません（Ctrl のときだけ）。
  - ドラッグしている項目そのもの（ドラッグしたファイルのカード・行）の上で離しても何も起きません（Ctrl でも。エクスプローラーと同じ）。
  - フォルダのカード・行、サイドバーの行、アドレス欄のフォルダ名へ落とすときは今までどおりです（項目の元のフォルダへは Ctrl でも受け付けません）。
- 表示中のフォルダへ落とせないところ：
  - 最近の履歴・よく使う項目・PC の一覧は今までどおりです（表示中のフォルダへは入りません。エクスプローラーからのフォルダは登録）。
  - フォルダを表示しているタブでも、読み込み中・読み込めなかったとき、処理中・見つからない・応答がないフォルダのカード・行の上では受け付けません。エクスプローラーからドラッグしたときも登録にはなりません（一覧の中の「登録」になる穴をなくすため）。
- 同じ名前の項目があるときや大きなコピーでは、Windows のダイアログ・進行状況の画面が出ます（貼り付けと同じ `IFileOperation`）。終わったら結果を表示して一覧を読み直し、表示中のフォルダに届いたときは届いた項目を選択します。ファイルの操作は一度に 1 つで、実行中・名前の入力中はドロップを受け付けません。
- 最近の履歴・よく使う項目の一覧のカードを 1 つだけドラッグしたときは、一覧の中で離すと並べ替えになります（一覧の中のフォルダのカードには入りません）。
- **エクスプローラーから**ファイル・フォルダを、アプリの中のフォルダの上、またはフォルダを表示しているタブの一覧（上の「表示中のフォルダへ」のところ）に落としても同じように移動・コピーします。それ以外（サイドバーの空き・タブ列・ツールバー・メッセージの行、最近の履歴・よく使う項目・PC の一覧のフォルダ以外のところなど）に落としたときは今までどおりフォルダの登録です（アドレス欄の上と、上の受け付けないところを除く）。
- 未決の点：カスケード（オーバーレイ・フライアウト）の行をドラッグすると一覧が消えるため、フォルダを表示しているタブでそのまま離すと、その項目を表示中のフォルダへ移動します（Ctrl + Z で戻せます）。カスケードの行のドラッグを除くか、ポインターが一覧から出てから先にするかは未定です。

**ほかのアプリへ渡す**

- 例：PowerPoint で編集中のスライドに画像のカードや行を落とすと、図として挿入されます。エクスプローラーのフォルダに落とすと、同じドライブなら移動、別のドライブならコピーです（Shift で移動、Ctrl でコピー、Alt でショートカット。エクスプローラーが決めます）。
- 移動になるのはフォルダの中の項目だけです。最近の履歴・よく使う項目の一覧のカード、フライアウトの見出し、サイドバーの登録フォルダは、コピーかショートカットだけです（Shift のときは受け付けられません）。
- 移動したかはアプリには伝わらないので、ドラッグのあと数秒の間と、次にウィンドウに戻ったときに項目が残っているかを確かめ、消えていれば一覧を読み直します。FolderDeck が元のファイルを消すことはありません（受け取る側がコピーだけして元の削除を求めても、コピーが残るだけです）。
- フォルダもドラッグできます。どう扱うか（コピーする、開く、受け付けない）は受け取る側しだいです。大きなフォルダをデスクトップなどに落とすとコピー・移動が始まります（エクスプローラーの画面で取り消せます）。

**共通**

- 選択の外の項目をドラッグすると、その項目だけです（選択はそのまま）。
- 見つからない・応答がない・処理中のカードはドラッグできません。
- ボタンを押したまま、システムのドラッグ距離（既定 4 ピクセル）より動かすとドラッグになります。ドラッグしたあとはクリックとして扱わない（ファイルを開かない・フォルダに移動しない）ので、手がぶれて少し動いたときはそのまま離しても何も起きません。
- ドラッグを始めると、開いていた一覧（オーバーレイ・フライアウト）とプレビューは消えます（落とす先を隠さないため）。
- FolderDeck のウィンドウの上で、フォルダと表示中のフォルダの一覧（上の「表示中のフォルダへ」）以外のところで離しても何も起きません（フォルダの登録にもなりません）。最近の履歴・よく使う項目の一覧のカードを一覧の中で離したとき、サイドバーの登録フォルダを登録フォルダの行の並びの中で離したときだけ並べ替えになります（見出しや「クイック アクセス」の行の上で離しても何も起きません）。

## 14. プレビューできるファイル

一覧（オーバーレイ・フライアウト）の行に 0.15 秒止まるか ↑ ↓ で選ぶと、横にプレビューが出ます。詳細表示では、ファイルの名前に 0.3 秒止まると名前のすぐ右に出ます（[12. 詳細表示](#12-詳細表示)）。クリックで開きます。

| 種類 | 表示 |
|---|---|
| 画像 | 画像そのもの（JPEG・PNG・BMP・GIF・TIFF・WebP はアプリが直接読みます。HEIC・AVIF などはシェルのサムネイル） |
| PowerPoint（.pptx .pptm .ppsx .ppsm .potx .potm） | 表紙（シェルのサムネイル、なければファイルに保存された縮小版） |
| Word（.docx .docm .dotx .dotm） | 本文の先頭（最大 40 段落・4,000 文字）。見出し・表題は太字。変更履歴で削除された文字、フィールドコード、テキストボックス、ヘッダー・フッター・脚注・コメントは出しません |
| Excel（.xlsx .xlsm .xltx .xltm） | ブックの並び順で最初の表示中のシートの、左上 30 行 × 12 列（列の A B C… と行番号つき）。数値は一般形式、日付・時刻の書式のセルは yyyy/MM/dd などで表示。通貨・桁区切り・色・罫線・セル結合は再現しません |
| テキスト（.txt .log .md .csv .json .xml .yaml .ini .cs .py .js .ts .ps1 .bat .sql .html .css .xaml など） | 先頭 60 行（最大 64 KB）を等幅フォントで。文字コードは BOM（UTF-8 / UTF-16）→ UTF-8 → Shift_JIS の順に判定。中身がバイナリなら文字では出しません |
| そのほか Windows がサムネイルを作れる形式 | シェルのサムネイル。動画（.mp4 .mov .wmv .avi .mkv .webm など）は常に対象。PDF・SVG・PSD・音楽ファイルなどは、サムネイルを作るアプリが入っていれば対象。画像を作れなかったとき（ジャケット画像のない音楽ファイルなど）は何も出しません |

- 続きがあるときや枠に入りきらないときは、下に「（以下省略）」が出ます。プレビューの中はスクロールしません。
- Word・Excel は本文を読めなかったとき（本文がない、パスワード付きなど）、シェルのサムネイルかファイルに保存された縮小版を出します。旧形式の .doc / .xls / .ppt と .xlsb は中身を読みません。
- 実行ファイル・ショートカット（.exe .dll .lnk .url .msi など）は対象外です。
- OneDrive の「オンラインのみ」のファイルなど、開くとダウンロードが始まるファイルは、Word・Excel・テキストの中身もファイルに保存された縮小版も読みません（ファイル属性だけで判定するので、これらのプレビューのためにダウンロードされることはありません）。ダウンロード済みのファイルは普通にプレビューされます。
- 画像だけは、「オンラインのみ」でもプレビューとカードのサムネイルのためにダウンロードします。どれを開けばいいか、絵がないと見分けられないためです。
  - 先にシェル（エクスプローラーと同じ仕組み）にサムネイルを求め、出てこないときだけダウンロードします。OneDrive が「サムネイルを作成中」と答えたときは、1.5 秒後にもう一度求めます。
  - 対象は、読むとデータを取りに行くファイル（OneDrive の「ファイル オンデマンド」など。ファイル属性の RECALL_ON_DATA_ACCESS で判定）の画像です。100 MB を超える画像と、フォルダのカードの表紙はダウンロードしません。
  - カードは、画面に見えているものと、その上下の先読み範囲（半ページずつ）のものがダウンロードされます。ダウンロード中のプレビューには「ダウンロード中…」と出て、カードにはアイコンが出ます。プレビューを閉じたとき、カードが先読み範囲からも外れたときは途中でやめます。カードは同時に 2 件まで、プレビューはカードの順番待ちとは別に 1 件で、どれも 1 件 2 分までです。
  - ダウンロードに失敗した・2 分で終わらなかったファイルは、更新（F5）するまでカードではダウンロードし直しません（プレビューでは、止まるたびに試します）。
  - HEIC・AVIF など、アプリが自分で読まない形式は、ダウンロードしても Windows に読む仕組み（拡張機能）がないとサムネイルが出ません。そうなったファイルが 2 件続き、その形式で 1 件も出ていなければ、その形式は終了するまでダウンロードしません。
  - ダウンロードしたファイルは、エクスプローラーで開いたときと同じくこの PC に置かれます（Windows が空き領域を作るとき、また「オンラインのみ」に戻ることがあります）。アプリが自分で読む形式（JPEG・PNG・BMP・GIF・TIFF・WebP）は、作ったサムネイルを画像サムネイルのキャッシュ（`thumbs\`）に必ず保存するので、「オンラインのみ」に戻っても、同じ大きさのサムネイルがキャッシュに残っている間はダウンロードし直さずに表示します（キャッシュ上限が 0 のときを除く）。HEIC・AVIF などは Windows のサムネイルキャッシュ任せなので、ダウンロードし直すことがあります。
  - オフラインのときや同期アプリが動いていないときは、2 分おいてからまたダウンロードを試します（その間のプレビューには「ダウンロードできません（オフライン、または同期アプリが動いていません）」と出ます）。
  - Windows は、アプリがクラウドのファイルをダウンロードすると「FolderDeck がダウンロードしています」という通知を出すことがあり、そこでアプリをブロックできます。ブロックされたとき、または通知でダウンロードを取り消したときは、FolderDeck を終了するまでダウンロードしません。ブロックの解除は、Windows の設定の「自動ファイル ダウンロード」（`ms-settings:privacy-automaticfiledownloads`）で「許可」を押してから FolderDeck を起動し直します。
  - プレビューには、取り消し・ブロックのあとは「ダウンロードが取り消されたかブロックされています（FolderDeck を起動し直すまでダウンロードしません）」、100 MB を超えるときは「大きいファイルのためダウンロードしません」、ダウンロードに失敗したときは「ダウンロードできませんでした」と出ます。
- カードのサムネイルも、Word・Excel は PowerPoint と同じく、シェルのサムネイルがなければファイルに保存された縮小版を使います（Word / Excel で「縮小版を保存する」をオンにして保存したファイルだけにあります）。

- 通知領域に FolderDeck のアイコンを出します。左クリックでウィンドウを表示、右クリックのメニューは「表示」「終了」。どちらの設定もオフで `--background` でもないときはアイコンを出しません。エクスプローラーが再起動したときはアイコンを出し直します。
- `--background` 付きの起動：ウィンドウを出さずに起動し、表示していたタブの読み込みまで済ませておきます（画面には出さずに 1 回描画しておくので、最初の表示も速くなります）。
- もう一度 FolderDeck を起動すると（スタートメニュー・ショートカットなど）、隠れているウィンドウを表示して前面に出します。2 つ目のプロセスは WPF を始める前に合図だけ送って終わります。
- 隠すときは開いているタブ・ウィンドウの位置などを保存します。隠れている間は自動更新などの画面のための確認を止め、表示したときに再開して、表示中のタブを更新します（フォルダは変わったところだけ更新し、スクロール位置は残します。最近の履歴・よく使う項目は読み直します。ほかのタブは表示したときに読み直します）。
- 本当に終了するのは、通知領域のメニューの「終了」、Windows のサインアウト・シャットダウン（正常終了として記録します）、ほかのプログラムからの終了の要求（ビルドのスクリプトなど）のときです。「閉じても終了せず」がオフなら、`--background` で起動していても、ウィンドウを閉じると終了します。
- 起動したときに Run キーの登録と設定が食い違っていれば（exe を移動した、手で消した）、Run キーの実際の状態を設定画面に出します。exe を移動したときは、もう一度オンにして OK を押すと今の場所で登録し直します。
- 常駐中はメモリを使い続けます（隠れている間の作業セットは 100〜140 MB ほど。表示したフォルダによって変わります）。

**フォルダの自動更新**（「一定の間隔で更新」のとき）

- 確認するのは表示中のフォルダだけです（フォルダのタブ、最近の履歴・よく使う項目から開いたフォルダ、ドライブの最上位）。最近の履歴・よく使う項目の一覧そのもの、オーバーレイ・フライアウトの中身は対象外です。隠れているタブは、表示したときに間隔が過ぎていればすぐ確認します。
- 間隔ごとにフォルダの中を読み直し、項目の追加・削除・名前の変更・書き換え（更新日時・サイズ）があったときだけ一覧を更新します。属性だけの変化（OneDrive のオンライン専用のファイルがダウンロードされたときなど）では更新しません。一覧は暗くならず、選択・スクロール位置・並び方は残ります。変わっていない項目のサムネイルは作り直しません。中身の変わったサブフォルダ（そのフォルダの更新日時が変わったもの）は、件数と表紙を取り直します。
- 次の間は待ち、終わってから確認します：名前の入力中、アドレス欄の入力中、範囲選択・ドラッグの最中、オーバーレイ・フライアウト・プレビュー・メニューの表示中（開く直前を含む）、ダイアログの表示中、ファイルの操作（貼り付け・ドロップ・削除）の実行中、マウスのボタンを押している間、キー・マウスの操作（ポインターの移動を含む）の直後（0.8 秒）、最小化中。ウィンドウが非アクティブなだけなら確認します（エクスプローラーと並べて使えるように）。
- 読み込み・F5・ファイルの操作の後の読み直しも「確認」として数えるので、その直後には重ねて読みません。F5 はこれまでどおりキャッシュ全体を読み直します。
- フォルダが応答しない・読めないときは一覧をそのまま残し、確認の間隔を延ばします（最大 5 分か設定の間隔の長い方）。同じフォルダが 2 回続けて見つからなければ「フォルダが見つかりません」と表示します（ネットワーク上のフォルダは、共有に届かないときも「見つからない」になるので、表示せずに間隔を延ばすだけです）。確認は一度に 1 つで、1 回 15 秒まで待ちます。
- ネットワーク上のフォルダでは、変更が届くまで Windows のキャッシュの分（10 秒ほど）遅れることがあります（推定）。

- 文字の大きさを上げても、詳細表示の列の幅とフライアウトの幅（280）は変わりません。130% 以上では、既定の幅の「更新日時」の列は時刻の末尾が「…」で省略されるので、必要なら列の境界線をドラッグして広げてください（広げた幅は保存されます）。サイドバーの名前も、同じ幅なら早めに省略されます。
- 画像サムネイルのキャッシュ上限を変えたときは、次回の起動から有効です。0 にすると新しく保存も読み出しもしません（すでにある `thumbs\` は消しません。不要なら「データフォルダを開く」から手で消してください）。
- 新しいタブを開くには、エクスプローラーの公開されていないコマンド（`WM_COMMAND 0xA21B`）を使っています。今後の Windows Update で動かなくなった場合は、約 2 秒待ってから新しいウィンドウで開く動作に戻ります。どちらで開いたかとその理由は `logs\app.log` に記録されます（[開発ガイドの 7.9](development.md#79-エクスプローラーの新しいタブで開かなくなった)）。
- 1 回のクリックでタブとウィンドウの両方が開くことはありません。新しいタブを頼んだのに確認できず、エクスプローラーが応答しない（あとから遅れてタブができるかもしれない）ときは、新しいウィンドウは開かずに「エクスプローラーの新しいタブでフォルダを開けませんでした。」と表示します（このときタブがホームのまま遅れて現れることがあります）。
- 「データフォルダを開く」は設定に関係なく新しいウィンドウで開きます。
- 以前あった「imgtool の登録フォルダを取り込む」は削除しました（`registered_folders.json` の形式は imgtool と同じままです）。

## 16. ホバーの待ち時間

ホバーの待ち時間は `src/FolderDeck.App/Views/HoverTimings.cs` にまとめてあります。

| 待ち時間 | 長さ |
|---|---|
| カードに止まってから一覧（オーバーレイ）が出るまで（サイドバーの行の一覧、詳細表示の名前の列の一覧・プレビュー、アドレス欄のフォルダ名の一覧、表示していないタブの一覧も同じ） | 300 ms（ウィンドウが前面でないときは 500 ms） |
| フォルダの行に止まってから次の階層（フライアウト）が出るまで | 150 ms |
| 画像・Office・テキストなどの行に止まってからプレビューが出るまで | 150 ms |
| ファイルの行・空いているところに移ってから、開いていた子の一覧が閉じるまで | 300 ms |
| カードとすべての一覧の外に出てから、全部が閉じるまで | 300 ms |

**子の一覧へ向かう間は待つ（メニュー エイム）**：開いている子の一覧（フライアウト）やプレビューへ向かってポインターを動かしている間は、途中で横切ったほかの行で子を開かず（フォルダの行）、子を閉じず（ファイルの行・空いているところ）、一覧と子の間の隙間に出ても閉じず、ほかのカード・サイドバーの行・詳細表示の行に入っても切り替えません。カードのオーバーレイの低い行から斜めに動いて、カードの下端から下のカードを通っても同じです。

- 「向かっている」とは、最後にポインターが動いてから 100 ms 以内で、少し前の位置から見て、子の一覧の手前の辺（上下に 4 DIP 広げる）の方へ動いていることです。
- 止まる（100 ms 動かない）か、向きを変えると、上の表のとおりに決まります（止まった行がフォルダならその子に替わり、ファイルの行なら子が閉じる）。このため、子へ向かって動いてから止まったときは、開く・閉じるが上の表より最大で 1 回分（150〜300 ms）遅れることがあります。
- 子の一覧はカード（または親の一覧・サイドバーの行・詳細表示の名前）の 4 DIP 横に出ます。アドレス欄のフォルダ名の一覧は、フォルダ名の 4 DIP 下に左端をそろえて出ます（画面の下に入らなければ上）。表示していないタブの一覧も同じく、タブの 4 DIP 下に左端をそろえて出ます。どちらも真下にあって途中でほかのフォルダ名・タブを横切らないので、この一覧へ向かう動きには待ちを使いません（その一覧から右に出る子の一覧には使います）。

## 17. 実装メモ

- **カードグリッド**：`VirtualizingWrapPanel`（MIT、net10.0-windows 対応を確認済み）は使わず、カードを「列数ぶんの行」にまとめて `VirtualizingStackPanel` で仮想化しています。列数（`max(1, floor((幅 + 12) / (サイズ + 12)))`）とカード幅（`(幅 − 12 × (列数 − 1)) / 列数`）の式をそのまま再現するためです。
- **詳細表示**：WPF の `ListView`（`GridView`）は使わず、見出しの行と、行を仮想化した素の一覧を自分で並べています。`ListView` の選択やマウスのつかみ方が、カードと共通にしているクリック・ドラッグの判定と食い違うためです。列の幅はエクスプローラーと同じく 4 列とも保存し、最後の列の右は空きにしています。横スクロールはないので、列を広げられるのは右の空きの分までで、ウィンドウが狭いときは名前の列から順に表示だけを縮めます（ドラッグ中も保存した幅から同じ計算で表示するので、ドラッグ中の見た目と離したあとの見た目は同じです）。種類の名前はエクスプローラーと同じもの（シェルの種類名）を拡張子ごとに 1 回だけ問い合わせ、届くまでは「JPG ファイル」のような仮の名前を出します。
- **フライアウトの位置**：WPF の `Popup` を使い、位置は行が載っているモニターの作業領域と拡大率から物理ピクセルで計算して、ウィンドウを直接その位置へ動かしています（拡大率の違うモニターでもずれないようにするため。`CustomPopupPlacementCallback` の代わり）。カードの横の第 2 階層は、以前はカードから 8 DIP 離していましたが、オーバーレイの行から子の一覧のファイルまでの距離を縮めるため 4 DIP にしました（ほかの階層と同じ）。
- **メニュー エイム（安全三角形）**：子の一覧はカード全体の横に出て、そのファイルの行は見出しと件数の下から始まるので、オーバーレイの行から斜めに動くと、途中でほかの行（先に並ぶフォルダの行が多い）を横切ります。以前は横切ったフォルダの行に 0.15 秒いると子がその行のものに替わり、ファイルの行では 0.3 秒で子が閉じたため、カードが大きいほど子の一覧のファイルを選べませんでした。今はポインターの移動を覚えておき（画面の物理ピクセル）、開く・閉じる・切り替えるタイマーが切れたときに「子へ向かって動いているか」を確かめ、向かっている間はタイマーをやり直します（[16. ホバーの待ち時間](#16-ホバーの待ち時間)）。判定の幾何は Core の `MenuAim` にあり、テストしています。
- **文字の大きさ**：大きさは、アプリのリソース（`Size.*`）に書いた値を各画面が `DynamicResource` で読む仕組みで、OK のあとすぐ全体に効きます。行の高さは余白を変えずに文字の分だけ伸ばし、整数の DIP に丸めています。
- **画像のサムネイル**：JPEG・PNG・BMP・GIF・TIFF・WebP は、シェル（エクスプローラーと同じ仕組み）を通さず、アプリが WIC（Windows Imaging Component）で直接サムネイルの大きさにデコードします。JPEG はデコードしながら 1/2・1/4・1/8 に縮小できるので元の大きさで展開するより数倍速く、CPU のコア数 − 1 本（2〜8 本）のスレッドで並行して作ります。向き（EXIF の Orientation）も反映します。作ったサムネイルはメモリと、データフォルダの `thumbs\` に保存し、次からは元の画像を読まずに表示します（保存するのは作るのに 4 ms 以上かかったものと、「オンラインのみ」からダウンロードしたものだけ。パス・更新日時・サイズ・要求サイズから名前を付けるので、画像を書き換えれば作り直します）。アプリが読めなかった画像、HEIC / AVIF・動画・Office・フォルダなどは、これまでどおりシェルのサムネイル（Windows のサムネイルキャッシュ）を使います。「オンラインのみ」の画像は、まずシェルのサムネイル（OneDrive が用意するもの）を使い、なければダウンロードしてから同じように作ります（[14. プレビューできるファイル](#14-プレビューできるファイル)の「オンラインのみ」の項）。
- **サムネイルの待ち時間**：1 件 5 秒の制限は、作り始めてから数えます。以前は順番待ちの時間も含めていたため、大きな画像の多いフォルダでは後ろのカードが時間切れになり、サムネイルの代わりにアイコンが出ることがありました。
- **メモリ**：タブを切り替えたりウィンドウの幅を変えたりするたびに、表示から外れたカードの部品がメモリに残り続けていた問題を直しました（カードは表示されている間だけ項目の変化を受け取ります）。フォルダの中身の一覧のキャッシュ（60 秒）は、一覧の数（1,500）に加えて項目の合計（20 万件）にも上限を付け、期限の切れた一覧は 60 秒に 1 回まとめて捨てます。シェル（動画・Office・フォルダなど）のサムネイルは、Windows のキャッシュから要求より大きいものが返ってきたとき、カードに要る大きさまで縮めて持ちます。メモリの使い方は `app.log` の `memory:` の行で確かめられます（F5 のたびと、使用量が 64 MB 以上変わったとき）。
- **フォルダのサムネイル**：シェルのフォルダサムネイルの一部は「非乗算済みアルファ」の画像として返るため、色とアルファから判定して正しく透過表示しています。四隅が不透明な（四角い背景つきの）画像はアイコン表示に切り替えます。
- **シェル画像の上下**：シェルが返すビットマップは、サムネイルは上から、アイコンは下から並んでいるのに、どちらも「下から」と報告されます。そのため `GetDIBits` に上から並べ直させて読みます（報告を信じて反転すると、サムネイルが上下逆になる）。
- **PowerPoint の表紙**：シェルのサムネイル（Office が入っていれば出る）がなければ、ファイルの中に保存されている表紙のサムネイル（`docProps/thumbnail.jpeg`、PowerPoint は既定で保存する）を使います。これがないファイル（ほかのツールで作ったものなど）はアイコンのままです。横長なので、カードでは切り抜かずに全体を収めます。
- **メッセージ行**：壊れたデータファイルを退避したときの通知用に「警告」（エラーと同じく次の操作まで残る）を追加しました。
- **画面構成の変化**：HDMI の差し替え・Win + P・解像度の変更などで画面構成が変わると、カスケードを閉じ、タイトルバーがどのモニターにも載らなくなった通常の状態のウィンドウ（確認ダイアログ・設定画面を含む）をモニターの作業領域の中央へ戻し、描画先を作り直させます。変化から 2 分以内にアプリがアクティブになったときは、ウィンドウを z-order の一番上へ戻します（前面を奪う操作はしません）。そのたびに `logs\app.log` に `display:` の行を記録します（原因の調査用。[開発ガイド](development.md) の 7.15）。
- **長いパス**：シェル API で開けないときは 8.3 形式の短いパスでも試します。
- **キーボード**：カード・詳細表示の行はフォーカスを持ちません（UI オートメーションの負荷と、ホバーで開くカスケードとの競合を避けるため）。代わりにタブごとに「現在の項目」（カーソル）をパスで持ち、キーはウィンドウでまとめて受けます。仮想化で項目の部品が作り直されてもカーソルは消えません。そのため、スクリーン リーダーはカーソルの移動を読み上げません（未対応）。キーでの操作は [19. キーボード操作](#19-キーボード操作)。
- **Office・テキストのプレビュー**：Office をインストールしていなくても読めるよう、ファイル（zip）の中の XML を必要な部分だけ読んで文字や表にしています。共有モードで開くので Office で編集中でも読めます。展開は 1 回 32 MB まで（zip 爆弾対策）、DTD は禁止、シートは 30 行目を読んだら止め、共有文字列は必要な番号までしか読みません。読み取りは裏のスレッドで行い 5 秒で打ち切り、直近 32 件は覚えておきます。「Windows がサムネイルを作れるか」は拡張子ごとに一度だけ問い合わせます（`AssocQueryString` で IThumbnailProvider の登録を確認）。
- **並べ替え**：「ピン留めは位置を固定」「新しく加わった項目は元の並びで直前の項目の後ろ」の規則は Core（`Ordering/`）の純粋な関数にしてテストしています。最上位の更新日とファイルのサイズは、存在確認と同じ 1 回の呼び出しで取得しています（タイムアウトも同じ）。種類順のキーを拡張子にしたのは、種類の名前がシェルから後で届くためです（名前で並べると、読み込みの途中で行が動きます）。更新日順だけフォルダを先にしないのは、新しく触った項目を種類に関係なく上に集めるためです（サイズ順・種類順ではフォルダにキーがないので 1 か所に固め、エクスプローラーと同じく昇順は先、降順は後ろに置きます。名前順も同じです）。
- **ほかのアプリへのドラッグ**：`DragDrop.DoDragDrop` で `DataFormats.FileDrop`（パスの配列。エクスプローラーと同じ CF_HDROP）を渡します。許可する効果は Copy | Link と、渡す項目が全部切り取れる（フォルダの中の項目）ときは Move も（`FileDragOut.EffectsFor`）。移動するのは受け取る側で、アプリは `DoDragDrop` の戻り値が何でも元を消しません（エクスプローラーの最適化された移動は None か Copy を返すので、移動したかは 0.5 / 2 / 5 秒後と次にウィンドウに戻ったときの存在確認で知り、一覧を読み直します）。「Preferred DropEffect」は載せません。260 文字以上のパスは 8.3 形式の短いパスにして渡します（短いパスが作れないボリュームでは長いまま）。
  - 最上位のカードは、1 回のドラッグに並べ替え用の内部形式（`FolderDeck.CardReorder`）と FileDrop の両方を載せます。グリッドの上では並べ替えとして Copy を返し、カーソルは普通の矢印に差し替えます（コピーの「＋」を出さないため）。
  - アプリ自身が始めたドラッグには内部形式 `FolderDeck.DragSource` を載せ、ドラッグ中のフラグも立てます。ウィンドウのフォルダ登録（`MainViewModel.RegisterDroppedAsync`）はそのどちらかがあれば受け付けません。
  - **フォルダへのドロップ**：ウィンドウの DragOver / Drop が、ポインターの下の要素から親をたどってフォルダのカード・行・サイドバーの行・アドレス欄のフォルダ名（パスはパンくずが持つ文字列。存在は転送の前に確かめる）を探し（`MainWindow.FolderDropOf`）、効果を Core の `FileDrag.DropEffectFor`（文字列だけの判定。ボリュームはドライブ文字か `\\server\share` の比較）で決めます。フォルダを表示しているタブの一覧（`ContentHost` の中のフォルダのカード・行以外）は表示中のフォルダが先で（貼り付けと同じ `TabViewModel.TransferTargetPath`。読み込み中・読み込めなかったときは null）、効果は `FileDrag.DropEffectForShownFolder`（Ctrl だけのときは元のフォルダへの複製を許す `FileDrag.CopiesInPlace`）。複製するかの印は DragOver / Drop のキーから `MainViewModel.DropAsync` の `copyInPlace` まで運び、`TransferOptions.Drop(kind, copyInPlace)` が貼り付けと同じ名前の変更（`FOF_RENAMEONCOLLISION`）にします。自アプリ由来のドラッグも受けます（登録フォルダの行のドラッグを除く）。Drop が返す効果は、移動でも **Copy**（`FileDrag.DropResult`。Move を返すと、元のアプリが「最適化されていない移動」として元を消すおそれがあり、こちらの転送はまだ始まっていないため）。アプリ内のドラッグは Drop では記録だけして、`DoDragDrop` が戻ってから `MainViewModel.DropAsync` を始め、エクスプローラーからのドラッグは `Dispatcher.BeginInvoke` で Drop から戻ってから始めます。転送は貼り付けと同じ `FileTransfer` です。
  - クリックとの区別は `SystemParameters.MinimumHorizontalDragDistance` / `MinimumVerticalDragDistance` を「超えたら」ドラッグ（カード・行・プレビュー共通、Core の `FileDrag.IsDragGesture`）。ドラッグを始めたら押下の記録を消すので、離してもクリックになりません。ダブルクリックの 2 回目の押下を無視する既存の処理はそのままです。
  - **カスケードは「開始時に消す」**：開いていた一覧とプレビューはドラッグ開始と同時に見えなくし、ホバーのタイマー（open / exit / grace / preview など）はすべて止めます。理由は、(1) フライアウトとプレビューは最前面のポップアップなので、残すと落とす先（スライドやフォルダ）を隠す、(2) タイマーは DoDragDrop のモーダルループの中でも動くのに、判定に使うポインター位置（IsMouseOver、ホバー中の行）は更新されないため、ドラッグ中に勝手に開閉してしまう、の 2 点です。ただしポップアップのウィンドウは中身を非表示にする（透明になり、ポインターもドロップも通り抜ける）だけで、破棄はドラッグが終わってからです。ボタンを押したポップアップをボタンを押したまま破棄すると、DoDragDrop がボタンを離したことに気づかず、次にクリックするまでドラッグが続いてしまうことを実機で確認したためです。同じ理由で、ドラッグ中に届いた「全部閉じる」（ウィンドウの非アクティブ化、自動スクロールなど）は無視し、終わったときにまとめて閉じます。ドラッグ元（DoDragDrop に渡す要素）はメインウィンドウか、並べ替えのときはカードグリッドで、どちらもドラッグ中に破棄されません。渡すパスは開始前に取り出しておきます。
  - ドラッグ中のサムネイル表示（`IDragSourceHelper`）は見送りました。ドラッグ画像はヘルパーがデータオブジェクトに独自の形式を書き込む（COM の `SetData`）仕組みで、アプリが作った WPF の `DataObject` はこれを受け付けない見込みのため（未検証）、独自の COM `IDataObject` の実装（HGLOBAL の複製・解放の管理を含む）が必要になり、受け渡しの形式や自分のウィンドウでの判定（並べ替え・登録の除外）も作り直しになるためです。今はシステムの標準カーソル（コピー・リンク・禁止）だけが出ます。
  - **既知の制約**：権限レベルが違うアプリの間（UIPI。例：管理者として実行したアプリと通常の FolderDeck）ではドロップできません。画像以外のファイルを PowerPoint などに落としたときの扱い（オブジェクトとして埋め込む、リンクする、受け付けないなど）は受け取る側しだいです。
  - ドラッグの結果は `logs\app.log` に `drag-out: <ドラッグ元>, effect <効果>, move offered|not offered, into app <Move|Copy>|out (<ミリ秒> ms)`、フォルダへのドロップは `drop: app|other app, <Move|Copy>, <n> items` として記録します（パスは書きません）。
- **未対応（P2・任意）**：フォルダの中でのドラッグによる並べ替え、フォルダへのショートカットの展開、Recent フォルダの監視。「プログラムから開く」は「その他のメニュー（Windows）」から使えます。

## 18. 元に戻す・やり直し

- **Ctrl + Z** で、FolderDeck で行った最後のファイル操作を元に戻します。**Ctrl + Y**（Ctrl + Shift + Z）で、元に戻した操作をやり直します。一覧の空いているところの右クリックにも「元に戻す（操作の名前）」「やり直し（操作の名前）」が出ます（戻せる・やり直せる操作があるときだけ。表示中のフォルダがない一覧でも出ます）。
- **対象の操作**：名前の変更（F2。複数をまとめて変えたときは 1 回で全部）、新しいフォルダー（Ctrl + Shift + N・空いているところのメニュー）、コピー・移動（貼り付け、フォルダへのドラッグ＆ドロップ（表示中のフォルダの一覧へのドロップと Ctrl での複製を含む）、エクスプローラーからのドロップ）、ごみ箱への削除、ショートカットの作成（Alt + ドロップ。元に戻すとごみ箱へ移します）。エクスプローラーのメニューの項目で行った操作、ほかのアプリへドラッグして移動された項目、エクスプローラーやほかのアプリで行った操作は対象外です。
- **戻し方**：
  - 名前の変更：元の名前に戻します。
  - 新しいフォルダー・コピー：作った項目をごみ箱へ移します（確認は出ません。何をごみ箱へ移したかはメッセージ行に出ます）。やり直すと、ごみ箱から元の場所へ戻します（コピーし直しはしません）。新しいフォルダーは空のときだけ戻します（隠しファイル・`.` で始まる名前も数えます。中に何かあれば「「N」は空ではありません」と出して戻しません）。
  - 移動：元のフォルダへ戻します。
  - ごみ箱への削除：ごみ箱から元の場所へ戻します（エクスプローラーのごみ箱の「元に戻す」と同じ結果）。やり直すと、もう一度ごみ箱へ移します。
  - コピー・移動で、同じ名前のフォルダに統合した項目・置き換えたファイルは戻しません（もとからあった中身まで動かしたり消したりしないため）。「両方を残す」で別の名前になった項目は戻します。統合・置き換えになった場所（その中・それを含むフォルダも）を記録した前の操作は、元に戻す・やり直しの両方の履歴から外します。統合がスキップ・失敗・中止で途中までしか済まなかったときも同じです（戻すと、統合で入った項目までごみ箱へ移したり動かしたりするため）。
- **履歴**：アプリ全体で 1 つ（タブごとではありません）、起動している間だけ、元に戻す・やり直しそれぞれ 30 個までです。新しく操作すると、やり直しの履歴は消えます。元に戻す・やり直し自身は新しい操作として数えず、エクスプローラーの「元に戻す」の履歴にも載せません。
- **戻せないとき**：項目が記録した場所にない（ほかで名前を変えた・移動した・消した）、戻す先に同じ名前の項目がある、戻す先のフォルダがない、新しいフォルダーが空でないときは、何もせずに理由をメッセージ行に出し、その操作を履歴から外します。そのとき、同じ場所（その中・それを含むフォルダも）を記録したほかの操作も履歴から外します。ネットワーク上・WSL のフォルダなど、ごみ箱に入らない場所のコピー・新しいフォルダーは戻せません（何も消しません）。何もできずに失敗したとき、Windows のダイアログで中止して何も変わっていないときは、その操作は履歴に残ります。
- **一部だけ戻ったとき**（途中で中止した、スキップした、失敗した）：件数を出し、戻った分だけをやり直しの側へ移します。戻らなかった分は同じ場所（履歴の一番上）に残り、もう一度 Ctrl + Z（Ctrl + Y）を押すとその残りに対して実行します（その下の古い操作には進みません）。
- 戻す途中で、戻す先に同じ名前の項目がほかから現れ、Windows のダイアログで「両方を残す」・統合・置き換えを選んだ項目は、戻ったものとして記録しません（やり直しがほかの項目を動かさないため）。その項目は残りとして履歴に残り、次に実行すると「見つかりません」などで断って履歴から外します。
- 右クリックのメニューの「元に戻す（…）」「やり直し（…）」は、メニューを開いたときの操作を指します。開いてから選ぶまでに履歴が変わっていたときは「履歴が変わりました。もう一度選んでください。」と出して何もしません。
- 実行中にほかのファイル操作（貼り付け・削除・名前の変更など）をしていると「前の操作が終わってから実行してください」と出ます。
- **戻したあと**：一覧を読み直し、表示中のフォルダに戻った項目を選びます。フォルダの名前・場所を戻したときは、そのフォルダとその中を指す登録フォルダ・タブも合わせて書き換えます（[5.2](#52-名前の変わったフォルダへの追従)）。
- ごみ箱から戻すと、ごみ箱の中に小さな管理用のファイル（`$I…`）が残ることがあります（エクスプローラーのごみ箱の「元に戻す」と同じです）。
- 設定（`settings.json`）とデータファイルは変わりません（履歴は保存しません）。

## 19. キーボード操作

マウスを使わずに、一覧の移動・選択・メニュー・タブの切り替え・フォルダの中身の確認ができます（エクスプローラーと同じキー）。キーの一覧は F1 か Ctrl + / でいつでも出せます。

- **現在の項目（カーソル）**：一覧ごと（タブごと）に、キーで動かす「現在の項目」があります。キーで動かしたときだけ、その項目に点線の枠が出ます（マウスのボタンを押すと枠は消えますが、位置は残ります）。クリック・Ctrl + クリック・Shift + クリック・範囲選択でもカーソルはその項目に移るので、続けてキーで操作できます。Esc や空いているところのクリックで選択を外しても、カーソルの位置は残ります。並べ替え・絞り込み・検索・自動更新のあとも、その項目が表示されている間は残ります（見つからない・応答がない項目の上でも）。別のフォルダへ移動すると消えます。
- **移動**：↑ ↓ ← → で隣の項目へ（カード表示は見えている並びのとおり。← → は行をまたいで進み、一覧の両端で止まります。最後の行が短くて真下に項目がないときの ↓ は、最後の項目へ）。Home / End で先頭 / 末尾、PageUp / PageDown で 1 画面分（同じ列のまま。行き過ぎるときはその列の端で止まり、すでに列の端にいれば一覧の先頭 / 末尾へ）。カーソルがまだないときは、End は末尾、ほかのキーは先頭から始まります。移ると画面の外の項目もスクロールして見せます。
  - 修飾キーなしは移った項目だけを選び、Shift は起点からの範囲を選び、Ctrl は選択を変えずにカーソルだけ動かし、Ctrl + Shift は起点からの範囲を選択に足します。
  - 見つからない・応答がない項目にもカーソルは止まりますが、選択には入りません（修飾キーなしで移ると、選択は空になります。Enter や Delete が離れた項目に効かないように）。範囲選択でも飛ばします。
  - カスケードが開いているときの ↑ ↓ ← → はカスケードが先に使います（カスケード表示中のキー）。Home / End / PageUp / PageDown はカスケードを閉じてから一覧のカーソルを動かします。Alt + 矢印は今までどおり戻る・進む・1 つ上へ・選んだフォルダの中へです。
- **Space / Ctrl + Space**：Space でカーソルの項目だけを選び、Ctrl + Space で選択に足す・外すを切り替えます。フォルダの上の Space は選ばずに中身の一覧を開きます（下の「キーで開くカスケード」）。ツールバーのボタンなどにフォーカスがあるときは、そのボタンが Space を使います。押し続けても 1 回だけです。 **Ctrl + 移動キーで現在の項目（点線の枠）だけを動かしたあと**は、Space（Ctrl なし）でもその項目を選択に足す・外す（フォルダも一覧を開かずに選ぶ）ので、Ctrl + 矢印と Space で離れた項目を 1 つずつ選べます。普通の移動・クリック・文字キーのジャンプのあとは元の動きに戻ります。
- **文字キー**：名前がその文字で始まる次の項目へ移り、その項目だけを選びます（大文字・小文字は区別しません。末尾まで行ったら先頭へ戻ります）。同じ文字を続けて押すと、その文字で始まる項目を順にたどります（その文字が 2 つ続く名前がないとき）。1 秒以内に続けて打った文字は 1 つの名前として探します（その間の Space も名前の一部になります）。矢印などでの移動・Esc・クリックで、打った名前はリセットされます。日本語入力では、確定した文字で探します（実機では未確認）。
- **キーで開くカスケード**：カーソルがフォルダの上にあるとき、Space（カード表示・詳細表示とも）で、ホバーと同じ中身の一覧を待たずに開きます（カードはオーバーレイ、詳細表示は名前の横の一覧）。もう一度 Space で閉じます。詳細表示では → でも開きます（カード表示の → は横への移動のまま）。 詳細表示では、カーソルが**ファイル**の上にあるときの → で、そのファイルのプレビュー（ホバーと同じもの）を出します（← ・Esc で閉じ、ほかのキーは一覧のキーとして働きます）。
  - 開いても選択は変わりません。最初はどの行も選んでいない状態で、↓ で先頭の行を選び、↑ ↓ で行を選び、Enter でその行を開き、フォルダの行の → でその子の一覧を開き、← で 1 つ前の一覧へ戻ります（1 段目の ← は一覧を閉じます）。Esc はいちばん深い階層を閉じます。行を選ばずに Enter を押したときは、一覧を閉じて選択した項目を開きます（今までどおり）。
  - キーで開いた一覧は、ポインターが外にあっても時間で閉じません。閉じるのは、Esc・← ・もう一度の Space・行を開いたとき・一覧の外でのクリック・スクロール・タブの切り替え・Ctrl / Shift・ほかのアプリへの切り替え・カーソルを動かすキーです。マウスをほかのカード・行の名前へ動かすと、ふだんどおりそちらの一覧に替わります（キーのあとポインターが止まったままなら、スクロールで下に来た項目の一覧は開きません）。
  - 開くものがないフォルダ（見つからない・応答がない、件数が分かっていて空）では、ファイルと同じに Space は選択、→ は移動になります。Ctrl + Space はいつも選択の切り替えで、開きません。
- **メニュー**：Shift + F10・アプリケーション キーで、選択した項目の右クリックメニューを、カーソルの項目（カーソルが選択の外なら選択の先頭）の左下に出します（その項目は先にスクロールして見せます）。選択がないときは表示中のフォルダのメニュー（一覧の空いているところの右クリックと同じ）を一覧の左上に出します。アプリのメニューかエクスプローラーのメニューかは設定の「右クリックのメニュー」に従い、拡張メニューにはなりません。カスケードが開いていれば先に閉じます（メニューはカスケードの行ではなく一覧の項目のもの）。ウィンドウのシステム メニューは開きません（検索欄・アドレス欄・名前の入力欄の中の Shift + F10 は、今までどおり入力欄のメニュー）。
- **プロパティ**：Alt + Enter で、選択した項目のエクスプローラーのプロパティを出します（複数でも 1 つの画面）。選択がないときは表示中のフォルダ、ドライブを 1 つ選んでいるときはそのドライブのプロパティです。ドライブを含む複数の選択では「ドライブのプロパティは 1 つずつ表示してください。」と出ます。最近の履歴・よく使う項目の一覧で何も選んでいないときは何もしません。プロパティを出したあとは、アプリに戻ったときに一覧を読み直します（画面で名前や属性を変えることがあるため）。プロパティを出せなかったときは「プロパティを表示できませんでした」と出ます。
- **別のキー**：Ctrl + D は Delete と同じ（ごみ箱へ。確認あり）、Ctrl + Insert は Ctrl + C、Shift + Insert は Ctrl + V と同じです。Ctrl + E は Ctrl + F・F3 と同じく検索欄を開きます。
- **タブ**：Ctrl + Tab / Ctrl + Shift + Tab で次 / 前のタブへ（端では反対の端へ）、Ctrl + 1〜8 で左から n 番目のタブ（その数のタブがなければ何もしません）、Ctrl + 9 で最後のタブへ移ります（テンキーの数字も同じ）。タブ列のクリックと同じ切り替えです。検索欄・アドレス欄の中でも効き（アドレス欄の入力はやめます）、メニューの表示中は効きません。Ctrl + Tab でツールバーのボタンへフォーカスが移ることはなくなりました（ボタンの間の移動は Tab / Shift + Tab）。 Ctrl + Shift + T で最後に閉じたタブを開き直します（タブがないとき、検索欄・アドレス欄の中でも効きます）。
- **ショートカットの一覧**：F1 か Ctrl + /（テンキーの / も）で、全部のキーを種類ごと（一覧の移動と選択・ファイル操作・表示と移動・タブ・検索とアドレス・カスケード・その他）に並べた画面を出します。Esc・F1・Ctrl + / ・「閉じる」で閉じます。検索欄・アドレス欄の中でも出せます。名前の入力中・範囲選択のドラッグ中・メニューの表示中は出ません。画面の文字の大きさは、ほかのダイアログと同じく設定の「文字の大きさ」に従いません。
- **ツールチップとメニューのキー**：ツールバーのボタンのツールチップに対応するキーを併記します（「1つ上へ（Alt + ↑ / Backspace）」「更新（F5）」、アドレス欄「（Ctrl + L / Alt + D / F4）」、検索語の表示「（Ctrl + F / Ctrl + E / F3）」、表示中のタブの ×「タブを閉じる（Ctrl + W）。中クリックでも閉じます」。表示していないタブの × には Ctrl + W を書きません）。アプリの右クリックメニューでは、キーが同じ項目に効くときだけ項目の右にキーを出します（選択した 1 項目の「開く」Enter・「切り取り」・「コピー」・「削除」Delete・「名前の変更」F2、選択全部のメニューの「切り取り」「コピー」「削除」、空いているところの「貼り付け」「新しいフォルダー」「元に戻す」「やり直し」「最新の情報に更新」。項目のメニューの「貼り付け」は Ctrl + V が表示中のフォルダに貼り付けるので出しません）。エクスプローラーのメニューにはキーを出しません。
- **キーが効かないとき**：検索欄・アドレス欄・名前の入力欄の中（矢印・Space・文字キー・選択のキーは入力欄のもの）、名前の入力中、範囲選択のドラッグ中、メニューの表示中は、一覧のキーは効きません。リストやスライダーなどにフォーカスがあるときは、その部品が矢印を使います。ツールバー・サイドバーのボタンは、クリックしたあともキーボードのフォーカスを持ちますが、一覧（項目・空いているところ・サイドバーの行）を押すか、矢印などで現在の項目を動かしたあとは、Space はそのボタンを押さず一覧で働きます（Tab でボタンへ移ったときは、一覧を操作するまで Space でそのボタンを押せます）。
- 対象外：Shift + Delete（完全な削除はしません）、Ctrl + T・Ctrl + N・F11、表示の切り替えのキー（Ctrl + Shift + 1〜8・Alt + P）、Tab / F6 での領域の移動、サイドバー・タブ列の矢印での操作、スクリーン リーダーへのカーソルの読み上げ。
