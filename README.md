# FolderDeck

登録したフォルダをサイドバーに並べ、マウスを乗せていくだけでサブフォルダの中身を何階層でもたどれる Windows ネイティブアプリです。表示されたファイルはクリックで開けます。

## 主な機能

- サイドバーに「クイック アクセス」（最近の履歴・よく使う項目）、登録フォルダ、PC のドライブを並べ、行に止まると中身の一覧、クリックで新しいタブ
- カードにホバーするとサムネイルの上に中身の一覧が出て、フォルダの行に止まるたびに次の階層が横に開く
- 一覧の行に止まるだけで、画像・PowerPoint・Word・Excel・テキストなどをプレビュー（OneDrive の「オンラインのみ」の画像も、ダウンロードしてプレビュー・サムネイルに表示）
- 最近の履歴・よく使う項目・フォルダのタブを 1 本のタブ列に並べ、閉じる・ドラッグで並べ替え（収まらないときは「◀」「▶」・ホイール・横ホイールでスクロール）
- エクスプローラーのようなアドレス欄：表示中のフォルダのパスをドライブから全部表示（フォルダ名のクリックでそこへ移動、フォルダ名に止まるとサブフォルダの一覧から選んで移動）、パスを直接入力して移動、クリックでパスをコピー、Ctrl + Shift + C で WSL のパス（`/mnt/c/…`）に変換してコピー、`cmd`・`wsl`・`powershell` などと入力して表示中のフォルダでターミナルを開く
- 登録フォルダやタブのフォルダの名前を変えたり移動したりしても、新しい場所に追従（エクスプローラーで変えたときも）
- タブごとの並べ替え（手動／名前／更新日／サイズ／種類）と、位置が動かないピン留め（📌）
- 縦長のカード・正方形のカード・詳細表示（名前・更新日時・種類・サイズの一覧）の切り替え
- 最近の履歴・よく使う項目の絞り込み（すべて／フォルダのみ／ファイルのみ）とドラッグでの並べ替え
- ドラッグ＆ドロップでフォルダへ移動・コピー（同じドライブは移動、別のドライブはコピー。Shift / Ctrl で切り替え。エクスプローラーとの間でも）
- カード・一覧の行・プレビューを、ほかのアプリへドラッグ＆ドロップで渡せる（PowerPoint に画像を落とすと図として挿入）
- 複数選択（空いているところからドラッグして範囲選択も）、Enter で選択した項目を開く、切り取り・コピー・貼り付け（エクスプローラーとの間でも）、名前の変更、新しいフォルダー
- ごみ箱への削除（完全な削除はしない）
- 右クリックからエクスプローラーのメニュー（7-Zip、送る、プログラムから開く、プロパティなど）も使える
- 表示中のフォルダの自動更新（設定で「自動更新なし」か「一定の間隔で更新」（2〜3600 秒）を選ぶ）
- テーマはシステム／ライト／ダーク。サイドバー・カード・一覧の文字の大きさは 100〜150% で調整

## 必要な環境

- Windows 10 22H2 / Windows 11（x64）
- 配布用の exe（`publish.bat` で作る single-file exe）を動かすだけなら、.NET のインストールは不要です（.NET を同梱）
  - `publish.bat framework` で作る小さい exe だけは、使う PC に .NET 10 デスクトップ ランタイム（x64）が必要です
- ソースからビルドするときは .NET SDK 10（`dotnet --list-sdks` で 10.0.x が出ること）

## 動かし方

### ダウンロードして使う

コンパイル済みの exe は [Releases の最新版](https://github.com/falls247/FolderDeck/releases/latest) にあります。インストールは不要で、ダウンロードした exe をそのまま起動できます。

| ファイル | 内容 |
|---|---|
| `FolderDeck-<版>-win-x64.exe` | **迷ったらこれ**（約 65 MB）。.NET を同梱しているので、.NET を入れていない PC でも動く |
| `FolderDeck-<版>-win-x64-uncompressed.exe` | .NET 同梱・圧縮なし（約 145 MB）。起動直後のメモリが少し少ない |
| `FolderDeck-<版>-win-x64-framework-dependent.exe` | .NET を同梱しない小さい exe（約 3.5 MB）。[.NET 10 デスクトップ ランタイム（x64）](https://dotnet.microsoft.com/download/dotnet/10.0) が必要 |

exe には署名をしていないため、初めて開くときに Windows の警告（SmartScreen）が出ることがあります。

### exe を作って使う

リポジトリのフォルダで実行します（エクスプローラーから `publish.bat` をダブルクリックしても同じです）。

```powershell
.\publish.bat
```

`dist\FolderDeck.exe`（約 65 MB）ができます。この 1 ファイルだけで動くので、ダブルクリックで起動します。
新しく作った exe を初めて起動するときは、ウイルス対策ソフトのスキャンで 30〜40 秒ほどかかることがあります（2 回目からは約 1.4 秒）。

### ソースから起動する

Debug ビルドして起動します。

```powershell
.\run.bat
```

`run.bat` を使わずに、dotnet のコマンドで起動することもできます。

```powershell
dotnet run --project src/FolderDeck.App
```

テスト・配布用の exe の種類・本番のデータを汚さずに試す方法などは [開発ガイド](docs/development.md) にあります。

## データの置き場所

設定・登録フォルダ・利用記録・ピン留めなどは `%LOCALAPPDATA%\FolderDeck\` に保存します。ファイルの一覧と中身は [詳細仕様の「データの置き場所」](docs/specification.md#1-データの置き場所) にあります。
