# FolderDeck

登録したフォルダをサイドバーに並べ、マウスを乗せていくだけでサブフォルダの中身を何階層でもたどれる Windows ネイティブアプリです。表示されたファイルはクリックで開けます。

## 主な機能

- サイドバーに「クイック アクセス」（最近の履歴・よく使う項目）、登録フォルダ、PC のドライブを並べ、行に止まると中身の一覧、クリックで新しいタブ
- カードにホバーするとサムネイルの上に中身の一覧が出て、フォルダの行に止まるたびに次の階層が横に開く
- 一覧の行に止まるだけで、画像・PowerPoint・Word・Excel・テキストなどをプレビュー（OneDrive の「オンラインのみ」の画像も、ダウンロードしてプレビュー・サムネイルに表示）
- 最近の履歴・よく使う項目・フォルダのタブを 1 本のタブ列に並べ、閉じる・ドラッグで並べ替え・閉じたタブを開き直す（Ctrl + Shift + T）・タブを複製（収まらないときは「◀」「▶」・ホイール・横ホイールでスクロール）。表示していないタブに止まると、切り替えずにそのタブのフォルダの中身の一覧
- 一覧の場所を左右・上下のペインに分けて、タブを並べて表示・操作（ツールバーのボタン・Ctrl + \ / Ctrl + Shift + \・右クリック。4 つまで。表示していないタブを選ぶと操作中のペインに表示、タブとペインは同じ色で対応。クリック・F6・Alt + Shift + 矢印で操作中のペインを切り替え、仕切りのドラッグで大きさを変更、ペインの間でドラッグしてコピー・移動。並べ方は次の起動でも元どおり）
- エクスプローラーのようなアドレス欄：表示中のフォルダのパスをドライブから全部表示（フォルダ名のクリックでそこへ移動、フォルダ名に止まるとサブフォルダの一覧から選んで移動）、パスを直接入力して移動、クリックでパスをコピー、Ctrl + Shift + C で WSL のパス（`/mnt/c/…`）に変換してコピー、`cmd`・`wsl`・`powershell` などと入力して表示中のフォルダでターミナルを開く
- 登録フォルダやタブのフォルダの名前を変えたり移動したりしても、新しい場所に追従（エクスプローラーで変えたときも）
- タブごとの並べ替え（手動／名前／更新日／サイズ／種類。ツールバーと、一覧の空いているところの右クリックから）と、位置が動かないピン留め（📌）
- 縦長のカード・正方形のカード・詳細表示（名前・更新日時・種類・サイズの一覧。見出しの右クリックで撮影日時・作成者・大きさなどエクスプローラーと同じ列も追加できる）の切り替え（表示と並び方はタブごとに記憶し、新しいタブは直前のタブを引き継ぐ）
- 最近の履歴・よく使う項目の絞り込み（すべて／フォルダのみ／ファイルのみ）とドラッグでの並べ替え
- Ctrl + F で表示中の一覧を名前で検索（入力した語を全部含む項目だけに絞り込む。全角・半角、ひらがな・カタカナは区別しない）。設定でサブフォルダも検索できる（Windows Search のインデックスとフォルダをたどる検索を組み合わせて、見つかった順に表示）
- 右クリックの「ファイル種別選択」で、表示中の一覧のフォルダ・拡張子ごと（.jpg と .jpeg は別）にまとめて選択
- ドラッグ＆ドロップでフォルダへ移動・コピー（同じドライブは移動、別のドライブはコピー。Shift / Ctrl で切り替え。Alt でショートカットを作成。エクスプローラーとの間でも。アドレス欄のフォルダ名へ落として上のフォルダへも。一覧の空いているところへ落とすと表示中のフォルダへ、Ctrl で複製）
- カード・一覧の行・プレビューを、ほかのアプリへドラッグ＆ドロップで渡せる（PowerPoint に画像を落とすと図として挿入）
- 複数選択（空いているところからドラッグして範囲選択も）、Enter で選択した項目を開く、切り取り・コピー・貼り付け（エクスプローラーとの間でも）、名前の変更（複数を選んで「名前 (1)」「名前 (2)」…とまとめても）、新しいフォルダー
- エクスプローラーと同じキーで移動（Alt + ← → で履歴、Alt + ↑・Backspace で 1 つ上へ、Alt + ↓ で選んだフォルダの中へ）
- キーボードだけで操作：矢印・Home / End・PageUp / PageDown で項目を移動して選択（Shift で範囲、Ctrl で移動だけ）、文字キーで名前へジャンプ、フォルダの上の Space（詳細表示は → も。ファイルの → はプレビュー）で中身の一覧、Ctrl + 矢印で動かしたあとの Space で 1 つずつ選択に追加、Shift + F10 でメニュー、Alt + Enter でプロパティ、Ctrl + Tab・Ctrl + 1〜9 でタブの切り替え。F1（Ctrl + /）でショートカットの一覧、ツールバーのツールチップにもキーを表示
- 選択した項目の数と、選んだファイルの合計サイズをツールバーに表示
- ごみ箱への削除（完全な削除はしない）
- Ctrl + Z / Ctrl + Y で、FolderDeck で行った名前の変更・新しいフォルダー・コピー・移動・ごみ箱への削除を元に戻す・やり直す
- 右クリックからエクスプローラーのメニュー（7-Zip、送る、プログラムから開く、プロパティなど）も使える
- 一覧の空いているところや項目の右クリックから、表示中のフォルダ（項目ならそのフォルダ、ファイルならそれがあるフォルダ）をターミナル・PowerShell（どちらも管理者としても）・VS Code・WSL で開ける（Windows ターミナルがなければ cmd。VS Code・WSL は入っているときだけ）
- 隠しファイル・フォルダと、名前が「.」で始まる項目（.vscode、.gitignore など）は設定で表示できる（既定はどちらも表示しない）
- 表示中のフォルダの自動更新（既定は「一定の間隔で更新」（2〜3600 秒、既定 5 秒）。設定で「自動更新なし」にもできる）
- 操作のメッセージ（「～を開きました」など）を出す場所を、上（アドレス欄の下）・下（一覧の下）・表示しない、から選べる
- テーマはシステム／ライト／ダーク。サイドバー・カード・一覧の文字の大きさは 100〜150% で調整
- 常駐モード（設定でオン。既定はオフ）：Windows のログオン時にウィンドウを出さずに起動しておく、閉じても終了せず通知領域に残す。どちらも次のウィンドウの表示がすぐになる

## 必要な環境

- Windows 10 22H2 / Windows 11（x64）
- 配布用の exe（`publish.bat` で作る single-file exe）を動かすだけなら、.NET のインストールは不要です（.NET を同梱）
  - `publish.bat framework` で作る小さい exe だけは、使う PC に .NET 10 デスクトップ ランタイム（x64）が必要です
- ソースからビルドするときは .NET SDK 10（`dotnet --list-sdks` で 10.0.x が出ること）

## 動かし方

### ダウンロードして使う

コンパイル済みの exe は [Releases の最新版](https://github.com/falls247/FolderDeck/releases/latest) にあります。インストールは不要で、ダウンロードした exe をそのまま起動できます。

| ファイル | 内容 |
|---|---|
| `FolderDeck-<版>-win-x64.exe` | **迷ったらこれ**（約 65 MB）。.NET を同梱しているので、.NET を入れていない PC でも動く |
| `FolderDeck-<版>-win-x64-uncompressed.exe` | .NET 同梱・圧縮なし（約 145 MB）。起動直後のメモリが少し少ない |
| `FolderDeck-<版>-win-x64-framework-dependent.exe` | .NET を同梱しない小さい exe（約 3.5 MB）。[.NET 10 デスクトップ ランタイム（x64）](https://dotnet.microsoft.com/download/dotnet/10.0) が必要 |

exe には署名をしていないため、初めて開くときに Windows の警告（SmartScreen）が出ることがあります。

### exe を作って使う

リポジトリのフォルダで実行します（エクスプローラーから `publish.bat` をダブルクリックしても同じです）。

```powershell
.\publish.bat
```

`dist\FolderDeck.exe`（約 65 MB）ができます。この 1 ファイルだけで動くので、ダブルクリックで起動します。
新しく作った exe を初めて起動するときは、ウイルス対策ソフトのスキャンで 30〜40 秒ほどかかることがあります（2 回目からは約 1.4 秒）。

### ソースから起動する

Debug ビルドして起動します。

```powershell
.\run.bat
```

`run.bat` を使わずに、dotnet のコマンドで起動することもできます。

```powershell
dotnet run --project src/FolderDeck.App
```

テスト・配布用の exe の種類・本番のデータを汚さずに試す方法などは [開発ガイド](docs/development.md) にあります。

## データの置き場所

設定・登録フォルダ・利用記録・ピン留めなどは `%LOCALAPPDATA%\FolderDeck\` に保存します。ファイルの一覧と中身は [詳細仕様の「データの置き場所」](docs/specification.md#1-データの置き場所) にあります。
