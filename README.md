# FolderDeck

登録したフォルダをサイドバーに並べ、マウスを乗せていくだけでサブフォルダの中身を何階層でもたどれる Windows ネイティブアプリです。表示されたファイルはクリックで開けます。

- サイドバー：「クイック アクセス」（「最近の履歴」「よく使う項目」の行。クリックでそのタブを開く）と「登録フォルダ」（フォルダ名を 1 行ずつ。幅は境界線のドラッグで調整）、「PC」（ドライブを 1 行ずつ）。それぞれ見出しのクリックで折りたため、サイドバー全体もタブ列の左端のボタンで隠せる。登録フォルダ・ドライブの行に止まると横に中身の一覧、クリックすると新しいタブで開く
- タブ：タブ列は 1 本。「最近の履歴」「よく使う項目」（カード表示の一覧）と、登録フォルダから開いたフォルダのタブ（色違い）が並び、どれも閉じる・ドラッグで並べ替えができる（全部閉じてもよい）
- カードにホバー → サムネイル部分に第1階層の一覧（オーバーレイ）→ フォルダ行に止まると横にフライアウト → さらに次の階層…
- 最近の履歴・よく使う項目は「すべて表示／フォルダのみ表示／ファイルのみ表示」を並べ替えボタンの左で切り替え
- フォルダはアプリ内で移動、ファイルは既定のアプリで開く。右クリックで「エクスプローラーで表示」（フォルダはそのフォルダを開く、ファイルは親フォルダを開いて選択）「パスをコピー」「ピン留め」、フォルダの中の項目は「削除（ごみ箱へ移動）」など（選択した項目は Delete キーでもごみ箱へ。複数をまとめて移せる）
- 一覧の行に止まると、画像・PowerPoint・Word・Excel・テキストなどを横にプレビュー
- カードはタブごとに並べ替え（手動／名前／更新日／サイズ／種類）。最近の履歴・よく使う項目の一覧ではドラッグで順番を入れ替えられる。ピン留めしたカードには左下に 📌（クリックで解除）
- 表示は、縦長のカード（サムネイル 3:4）・正方形のカード（サムネイル 1:1）・詳細表示（名前・更新日時・種類・サイズの一覧）をツールバーのボタンで切り替え（全タブ共通）
- カード・一覧の行・プレビューは、ほかのアプリへドラッグ＆ドロップで渡せる（PowerPoint に画像を落とすと図として挿入、エクスプローラーに落とすとコピー）
- Ctrl / Shift + クリックで複数選択し、切り取り・コピー（Ctrl + X / C）とフォルダへの貼り付け（Ctrl + V）がエクスプローラーとの間でもできる
- 右クリックメニューの「その他のメニュー（Windows）」で、エクスプローラーの右クリックメニュー（7-Zip、送る、プログラムから開く、プロパティなど）を使える。設定を「Windows のメニュー」にすると、項目の右クリックで最初からエクスプローラーのメニューが出て、その上にアプリの項目が並ぶ

## 必要な環境

- Windows 10 22H2 / Windows 11（x64）
- 開発：.NET SDK 10（`dotnet --list-sdks` で 10.0.x が出ること）
- 配布物（`publish.bat` で作る single-file exe）を動かすだけなら .NET のインストールは不要です（self-contained）
  - `publish.bat framework` で作る小さい exe だけは、使う PC に .NET 10 デスクトップ ランタイム（x64）が必要です

## よく使う操作（BAT・ダブルクリック可）

リポジトリのフォルダにある BAT を、エクスプローラーからダブルクリックするか、ターミナルから実行します。

| BAT | 内容 |
|---|---|
| `build.bat [Debug\|Release]` | ソリューションをビルド（既定 Debug） |
| `test.bat [追加の引数]` | Core のテスト（例：`test.bat --filter Ranking`） |
| `run.bat [アプリへの引数]` | Debug ビルドして起動（例：`run.bat --data-dir E:\tmp\data`） |
| `build-test-run.bat [アプリへの引数]` | ソリューションを Debug ビルド → Core のテスト → 起動 を続けて実行。失敗した段階で止まる（引数は `run.bat` と同じ。例：`build-test-run.bat --data-dir E:\tmp\data`） |
| `publish.bat` | 配布用の single-file exe（.NET 同梱・圧縮、約 65 MB）を作り、`dist\FolderDeck.exe` にコピー |
| `publish.bat framework` | .NET を同梱しない single-file exe（約 2 MB）を作り、`dist\framework-dependent\FolderDeck.exe` にコピー。使う PC に .NET 10 デスクトップ ランタイム（x64）が必要（入っていないと起動時にダウンロードを促す画面が出て起動しない） |

- ダブルクリックしたときは、最後に「Enter キーで閉じます」で止まるので結果を読めます（`run.bat` / `build-test-run.bat` が成功したときはアプリが出るので止まりません）。ターミナルから実行したときは止まりません。
- 終了コードを返すので、ほかのスクリプトからも呼べます（成功 0、失敗 1、引数の誤り 2）。
- これから上書きするフォルダ（`bin\Debug`、`bin\Release`、`publish`、コピー先の `dist` または `dist\framework-dependent`）から FolderDeck が起動していると exe がロックされてビルドできないため、「閉じて続けますか？ [Y/n]」と聞いてから普通に閉じます（閉じるときに状態は保存されます）。ほかの場所から起動している FolderDeck には触れません。
  - 入力できない実行（ほかのツールから呼んだときなど）では、閉じずに中止します。確認なしで閉じてよいときは、環境変数 `FOLDERDECK_AUTOCLOSE=1` を設定してください。
- FolderDeck は1つしか起動できません。ほかの場所（`dist\` など）の FolderDeck が起動していると、`run.bat` / `build-test-run.bat` は新しいビルドを起動できない（既存のウィンドウが前に出るだけで `--data-dir` も効かない）ため、ビルドせずにその旨を表示して終了します。そちらを閉じてから実行してください。
- `test.bat` などへの追加の引数は、`-tl:off` や `-p:Name=Value` のような形もそのまま dotnet に渡ります。
- `build-test-run.bat` は、ビルド（Debug・ソリューション全体）→ テスト（1 でビルド済みのものを `--no-build` で実行）→ 起動（`run.bat` と同じ）を一度に行います。途中で失敗するとそこで止まり、「テストで失敗しました。起動はしません。」のように、どの段階で失敗したかを表示します。引数はすべてアプリに渡されます（テストを絞り込みたいときは `test.bat --filter ...` を使ってください）。`tools\dev.ps1` では `all`（別名 `build-test-run`）というタスクです。
- 中身は `tools\dev.ps1` にまとめてあります（BAT はそれを呼ぶだけ）。BAT を英数字だけにしてあるのは、文字コード（コードページ 932 / 65001）が違う環境でも文字化けせずに動かすためです。`tools\dev.ps1` を編集したら UTF-8（BOM 付き）で保存してください。

## ビルド・テスト・起動（コマンドで直接）

リポジトリのフォルダ（このファイルがある場所）で実行します。

```powershell
dotnet build FolderDeck.sln -c Debug
```

```powershell
dotnet test tests/FolderDeck.Core.Tests -c Debug
```

```powershell
dotnet run --project src/FolderDeck.App
```

### 配布用の exe を作る

```powershell
dotnet publish src/FolderDeck.App -c Release -r win-x64 -p:SelfContained=true -p:PublishSingleFile=true
```

出力は `src\FolderDeck.App\bin\Release\net10.0-windows\win-x64\publish\FolderDeck.exe` の **1ファイルだけ**です（約 65 MB）。`publish.bat` を使うと、同じものが `dist\FolderDeck.exe` にもコピーされます。
ReadyToRun（事前コンパイル）を有効にしてあり、起動を速くしています。.NET を同梱する（self-contained）ときは exe の中身を圧縮しています（`EnableCompressionInSingleFile`。圧縮しないと約 150 MB）。

.NET を同梱しない小さい exe（約 2 MB）は `-p:SelfContained=false` で作れます（`publish.bat framework` と同じ）。使う PC に .NET 10 デスクトップ ランタイム（x64）が必要です。

- `--self-contained false` ではなく `-p:SelfContained=false` を使ってください。この環境（.NET SDK 10）では `--self-contained false` を付けても .NET が同梱され、約 150 MB になりました。
- WPF はトリミング（`PublishTrimmed`、使わないコードを削る機能）に対応していないため使っていません。

> 新しくビルドした exe を初めて起動するときは、ウイルス対策ソフトのスキャンで 30〜40 秒ほどかかることがあります（この環境で計測）。2回目からは約 1.4 秒（`publish.bat framework` の exe は約 0.9 秒）で最初の画面が出ます。
> 圧縮した exe は展開した中身をメモリに置くため、起動直後のメモリ（ワーキングセット）が約 200 MB と、圧縮しない場合・`publish.bat framework` の exe（約 130 MB）より約 70 MB 多くなります。

## データの置き場所

`%LOCALAPPDATA%\FolderDeck\`

| ファイル | 内容 |
|---|---|
| `registered_folders.json` | 登録フォルダ（imgtool と同じ形式）。`folders` 配列の順番がサイドバーの並び |
| `history.json` | 利用記録（最近の履歴・よく使う項目の元データ） |
| `pins.json` | ピン留め |
| `excluded.json` | 最近の履歴から外した項目 |
| `card_order.json` | 最近の履歴・よく使う項目をドラッグで並べた順（`{ "version": 1, "recent": [パス…], "frequent": [パス…] }`、各 1000 件まで） |
| `settings.json` | 設定、ウィンドウ位置、開いているタブ（`open_tabs`：タブごとの種類 `kind`（`recent`／`frequent`／`folder`）と表示していた場所 `root`・`path`。フォルダのタブは 50 個まで）と表示していたタブ（`selected_tab`。タブなしは −1）、ファイルの形式の版（`version`：2）、サイドバーの幅（`sidebar_width`、140〜480）、サイドバーを隠しているか（`sidebar_collapsed`）、折りたたんでいる節（`sidebar_collapsed_sections`：`quick`／`registered`／`pc`）、テーマ（`theme`：`system`／`light`／`dark`）、右クリックのメニュー（`item_menu`：`app`／`windows`）、カードサイズ、表示（`card_shape`：カードの形 `portrait`／`square`、詳細表示 `details`）、詳細表示の列の幅（`details_columns`：`modified`／`type`／`size`、48〜600）、タブごとの並び方（`sort_modes`：`recent`／`frequent`／`folder`）、表示する項目（`filter_modes`：`all`／`folders`／`files`） |
| `thumbs\` | 画像サムネイルのキャッシュ（一度表示した画像の縮小版。JPEG、透過のある画像は PNG）。上限は設定の「画像サムネイルのキャッシュ上限」（既定 512 MB）で、超えたら使っていない順に消します。フォルダごと消してもかまいません（次に表示するとき作り直します） |
| `logs\app.log` | ログ（5 MB で `app.log.1` に切り替え） |
| `logs\session.json` | 起動中だけある記録（1 分ごとに更新）。次の起動時に残っていれば「前回は正常に終わらなかった」と判断する |

- 書き込みは一時ファイル経由で置き換えます。壊れた JSON は `<名前>.broken-<UNIX秒>.json` に退避し、空のデータで続けます。
- このアプリがファイルやフォルダを消すのは、右クリックの「削除（ごみ箱へ移動）」か Delete キー（選択した項目）を確認ダイアログで承認したときだけです（ごみ箱へ移すだけで、完全には削除しません。下の「削除（ごみ箱へ移動）」）。それ以外でファイルの削除・移動・上書きはしません（アプリ自身のデータである `thumbs\` の古いキャッシュを除く）。ファイルのコピー・移動は「貼り付け」だけです（下の「選択と切り取り・コピー・貼り付け」）。「その他のメニュー（Windows）」で選んだ項目（設定「Windows のメニュー」で出したエクスプローラーの項目も同じ）は、Windows やその項目を追加したアプリ（7-Zip など）が実行します（下の「エクスプローラーのメニュー」）。

### 勝手に終了したときの調べ方

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\analyze-log.ps1 -Events
```

ログを起動ごとに分けて、いつ起動してどう終わったかを表示します（`-Last 30` で件数、`-LogDir` で `--data-dir` のログも見られます）。
アプリは開始・終了と閉じた理由を `lifecycle:` で始まる行に書きます。

| 終わり方の表示 | 意味 |
|---|---|
| ユーザーが閉じた | × ボタン、Alt+F4、タスクバーから閉じた |
| 別のプログラムが閉じた（WM_CLOSE） | ほかのプログラムがウィンドウを閉じさせた（ビルドスクリプトの `CloseMainWindow`、`/F` なしの `taskkill`、インストーラーなど） |
| Windows のセッション終了で閉じた | サインアウト・シャットダウン・更新（Restart Manager） |
| クラッシュ（未処理の例外） | 例外の内容がログに残っています |
| 異常終了 | 終了処理が走っていない。次の起動時に、イベントログ（Application）の FolderDeck.exe のクラッシュ記録も調べて書き出します。記録がなければ強制終了（`taskkill /F`、タスクマネージャー）か電源断 |

### 開発用オプション

```powershell
dotnet run --project src/FolderDeck.App -- --data-dir E:\tmp\folderdeck-data
```

`--data-dir <フォルダ>` でデータの置き場所を差し替えられます（本番のデータを汚さずに試すため）。

## 検証用フォルダ

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\make-fixture.ps1 -OutputDir E:\tmp\fixture
```

8階層の入れ子、10,000 ファイル、5,000 フォルダ、260 文字を超えるパス、隠し・システム属性、循環ジャンクション、画像あり・なし、`test.bat`、アクセス拒否のフォルダなどを作ります。
出力先がすでにあると何もせずに止まります。アクセス拒否のフォルダを消す前に、スクリプトが表示する `icacls ... /remove:d ...` を実行してください。

## 操作

| 操作 | 動作 |
|---|---|
| サイドバーの登録フォルダ・ドライブ（PC）に止まる（0.3 秒） | 横に中身の一覧（フライアウト）。カードのオーバーレイと同じように、行をたどって何階層でも進める |
| サイドバーの「最近の履歴」「よく使う項目」をクリック | そのタブを開く（開いていれば、そのタブに切り替える。表示中でフォルダの中にいるときは一覧に戻る） |
| サイドバーの登録フォルダ・ドライブ（PC）をクリック | そのフォルダ（ドライブの最上位）を新しいタブで開く（すでに同じフォルダを表示しているフォルダのタブがあれば、そのタブに切り替える）。サイドバーから出した一覧のフォルダ行・見出しをクリックしたときも新しいタブ |
| サイドバーの登録フォルダをドラッグ | 登録フォルダの行の並びの中で離すと順番の入れ替え（入る位置に横線）。ウィンドウの外のアプリで離すと、そのアプリにフォルダを渡す |
| サイドバーとカード一覧の境界線をドラッグ | サイドバーの幅を変更（140〜480。`settings.json` に保存） |
| サイドバーの見出し（「クイック アクセス」「登録フォルダ」「PC」）をクリック | その節を折りたたむ／開く（見出しだけ残る。`settings.json` に保存） |
| サイドバーの「PC」の見出しを右クリック →「エクスプローラーで開く」 | エクスプローラーで PC を開く（設定で新しいタブ） |
| タブ列の左端のボタン（サイドメニューを表示 / 隠す） | サイドバー全体を隠す／戻す（幅は覚えている。`settings.json` に保存） |
| タブをクリック / ×・中クリック・Ctrl + W / 左右にドラッグ | タブを表示 / 閉じる / タブ列の中で並べ替え（「最近の履歴」「よく使う項目」のタブも同じ）。右クリックで「タブを閉じる」「ほかのタブを閉じる」。タブが収まらないときはタブの上でホイールを回すと横にスクロール |
| カードをクリック | フォルダなら中へ移動（表示中のタブの中で移動）、ファイルなら開く。選択は外れる |
| カード・詳細表示の行を Ctrl + クリック / Shift + クリック / Ctrl + Shift + クリック | 選択に加える・外す / 最後に Ctrl + クリックした項目からの範囲を選ぶ / その範囲を選択に足す（開かない。下の「選択と切り取り・コピー・貼り付け」） |
| Ctrl + A / Esc | 表示中の一覧の項目を全部選ぶ / 選択を外す（カスケード表示中の Esc は先に一覧を閉じる） |
| Ctrl + X / Ctrl + C | 選択した項目を切り取る / コピーする（選択がないときは何もしない） |
| Ctrl + V | 表示中のフォルダに貼り付け（最近の履歴・よく使う項目の一覧では貼り付けできない） |
| Delete | 選択した項目をごみ箱へ移動（確認あり。選択がないときは何もしない。Shift + Delete の完全削除はない） |
| 項目の右クリック →「切り取り」「コピー」「貼り付け」 | 切り取り・コピーはその項目（選択した項目の上なら選択全部）、貼り付けはそのフォルダ（フォルダとドライブの行に出る）へ |
| 一覧の空いているところをクリック / 右クリック | 選択を外す / 「貼り付け」「最新の情報に更新」のメニュー（設定に関係なくアプリのメニュー。読み込み中で薄く表示されている間も、項目の上の右クリックはその項目のメニュー） |
| 項目の右クリック →「その他のメニュー（Windows）」 | その項目（選択した項目の上なら選択全部）のエクスプローラーの右クリックメニュー。Shift + 右クリックで開いたときは拡張メニュー（下の「エクスプローラーのメニュー」）。設定の「右クリックのメニュー」が「アプリのメニュー」のとき |
| 項目の右クリック（設定の「右クリックのメニュー」が「Windows のメニュー」） | エクスプローラーの右クリックメニューの上に、アプリの項目（「開く」「エクスプローラーで表示」「パスをコピー」「削除（ごみ箱へ移動）」など）を並べたメニュー。ドライブの行などはアプリのメニュー（下の「エクスプローラーのメニュー」） |
| 右ボタンを押したまま左クリック → 右ボタンを離す | 「エクスプローラーで表示」と同じ（メニューは出ない）。右ボタンを離したときに開く。カード、一覧の行、サイドバーの登録フォルダ・ドライブで使える。対象は左クリックした項目（カードに重なった一覧の行の上なら、その行） |
| カードにホバー（0.3 秒） | 子項目の一覧（オーバーレイ） |
| フォルダ行に止まる（0.15 秒） | 横に次の階層（フライアウト）。何階層でも続く |
| 画像・Office・テキストなどの行に止まる（0.15 秒） | 横にプレビュー（下の「プレビューできるファイル」）。クリックで開く。↑ ↓ で選んでも出る |
| ↑ / Backspace | 1つ上へ（フォルダのタブでは、開いたときのフォルダまで） |
| マウスの戻る・進む / Alt + ← → | 移動の履歴（タブごと） |
| F5 | 更新（キャッシュも読み直す。登録フォルダとドライブも確認し直す） |
| Ctrl + ホイール | カードの大きさ（120〜400。カード表示のとき） |
| カスケード表示中の ↑ ↓ → ← Enter Esc | 行の選択、子を開く、閉じる、開く、いちばん深い階層を閉じる |
| エクスプローラーからフォルダをドロップ | 登録（ウィンドウのどこに落としてもよい。サイドバーに「ドロップして登録」と出る。サイドバーを隠している間は案内なしで登録する） |
| 「登録フォルダ」の見出しの右のフォルダのボタン | フォルダを選んで登録（複数選べる） |
| フォルダを右クリック →「登録フォルダに追加」 | そのフォルダをサイドバーに登録（最近の履歴・よく使う項目のカード、フォルダの中のカード、一覧の行・見出し、サイドバーのドライブ。登録済みのフォルダには出ない） |
| サイドバーの登録フォルダを右クリック →「登録を解除」 | 確認のうえ、サイドバーから外す（フォルダは消えない。開いているタブはそのまま） |
| 最近の履歴・よく使う項目の一覧でカードをドラッグ | 一覧の中で離すと順番の入れ替え（下の「並べ替えとピン留め」）。ウィンドウの外のアプリで離すと、そのアプリにファイル・フォルダを渡す |
| カード（フォルダの中）・一覧の行・プレビューをドラッグ | ほかのアプリにファイル・フォルダを渡す（下の「ほかのアプリへドラッグで渡す」） |
| ツールバーの表示ボタン（並べ替えボタンの左。最近の履歴・よく使う項目の一覧で出る） | すべて表示／フォルダのみ表示／ファイルのみ表示をタブごとに切り替え（下の「表示する項目の切り替え」） |
| ツールバーの並べ替えボタン | 手動／名前／更新日／サイズ／種類（それぞれ昇順・降順）を切り替え（最近の履歴・よく使う項目はタブごと、フォルダのタブは共通） |
| ツールバーのカードの形・詳細表示のボタン（並べ替えボタンの右の 3 つ） | 縦長のカード（サムネイル 3:4）／正方形のカード（サムネイル 1:1）／詳細表示を切り替え。全タブ共通で、`settings.json` に保存（下の「詳細表示」） |
| 詳細表示の列の見出しをクリック | その列で並べ替え（もう一度クリックで逆順） |
| 詳細表示の列の見出しの左の境界線をドラッグ | 更新日時・種類・サイズの列の幅を変更（`settings.json` に保存） |
| 詳細表示でフォルダの名前の列に止まる | 名前の列の右（更新日時の列の上）にそのフォルダの中身の一覧（カードのオーバーレイと同じカスケード） |
| カードの 📌 をクリック | ピン留めを外す |
| フォルダの中のカード・一覧の行を右クリック →「削除（ごみ箱へ移動）」 | 確認のうえ、ごみ箱へ移動（選択した項目の上なら選択全部。下の「削除（ごみ箱へ移動）」） |

実行形式（`.exe .bat .ps1` など）を開く前には確認が出ます（設定で OFF にできます）。

### タブとサイドバー（登録フォルダ）

- サイドバーは上から「クイック アクセス」（「最近の履歴」「よく使う項目」の行）、「登録フォルダ」、「PC」（ドライブ）の 3 つの節に分かれます。見出しをクリックすると、その節は見出しだけに折りたたまれます（もう一度クリックで開く）。「登録フォルダ」の見出しには件数と登録のボタンが付き、折りたたんでいても使えます。
- タブ列の左端のボタンで、サイドバー全体を隠して一覧を広く使えます（もう一度押すと元の幅で戻ります）。節の折りたたみとサイドバーの表示・非表示は `settings.json` に保存し、次の起動でも同じ状態で始まります。
- 「クイック アクセス」の行は、そのタブを表示している間は色が付き、タブ列に開いている間は右端に点が付きます。
- 登録フォルダはウィンドウ左のサイドバーに、フォルダ名だけを 1 行ずつ並べます（パスはツールチップ）。見つからないフォルダ・応答がない（2 秒）フォルダは取り消し線と ⚠ で示し、一覧もタブも開きません（右クリックの「登録を解除」とドラッグでの並べ替えはできます）。F5 で確認し直します。
- 「PC」にはドライブを 1 行ずつ、エクスプローラーと同じ名前（`ラベル (C:)`。ネットワーク ドライブは `共有名 (\\サーバー) (Z:)`）でドライブ文字の順に並べます。登録フォルダの行と同じように、止まると中身の一覧、クリックでドライブの最上位を新しいタブで開きます（タブの名前は `C:\`）。
  - 出るのは固定ディスク、ネットワーク ドライブ、メディアが入っているリムーバブル ディスク（USB メモリー、カード）と光学ドライブです。空のカード リーダーや、ディスクの入っていないドライブは出ません。
  - 接続されていないネットワーク ドライブと、応答がない（2 秒）ドライブは、取り消し線と ⚠ で示し、一覧もタブも開きません。右クリックの「エクスプローラーで表示」は使えます（エクスプローラーが再接続を案内します）。応答を待っている間も、ほかの行と画面は止まりません。
  - 一覧は、起動したとき、USB メモリーやカード・ディスクを抜き差ししたとき、F5 を押したとき、FolderDeck のウィンドウに戻ってきたとき（5 秒に 1 回まで）に読み直します。ネットワーク ドライブの割り当て・切断は、ウィンドウに戻ったときか F5 で反映されます。
  - ドライブの行の右クリックは「開く」「エクスプローラーで表示」「パスをコピー」「登録フォルダに追加」です（ピン留め・削除はありません。設定の「右クリックのメニュー」が「Windows のメニュー」でも、このアプリのメニューです）。「PC」の見出しを右クリックすると「エクスプローラーで開く」が出て、エクスプローラーで PC を開きます（設定の「新しいタブで開く」がオンなら新しいタブ。利用記録には残しません）。ドライブの行はドラッグできず、クリックで開いても「最近の履歴」「よく使う項目」には記録しません（一覧からたどって開いたフォルダは記録します）。「PC」の節は登録フォルダの下にあり、ドライブが多いときはサイドバーの高さの 4 割までで、その中をスクロールします（登録フォルダを折りたたむと、残りの高さを全部使います）。
  - アイコンはドライブの種類ごとの簡単な記号で、エクスプローラーのドライブのアイコンではありません。
- 行に 0.3 秒止まると、行の右に中身の一覧（フライアウト）が出ます。開いている間にほかの行を横切っても、そこで止まらなければ一覧は切り替わりません（一覧へ斜めに移動できるようにするため）。
- 一覧（カードのオーバーレイも同じ）は、FolderDeck のウィンドウが前面でなくても開きます（ほかのアプリで作業中に、横に並べた FolderDeck へポインターだけ動かしたとき）。このときは通過しただけで開かないよう、待ち時間が 0.5 秒になります。前面のウィンドウが替わると閉じ、一覧の中をクリックすると FolderDeck が前面になります。
- タブ列は 1 本で、開いた順に左から並びます。「最近の履歴」「よく使う項目」はサイドバーの「クイック アクセス」の行から開きます（タブ列の右端に追加。すでに開いていればそのタブに切り替わり、表示中でフォルダの中にいるときは一覧に戻ります）。
- 登録フォルダから開いた画面は、カード一覧の上のタブ列に新しいタブとして追加されます。タブの名前は表示中のフォルダ名です。タブの中でフォルダのカードをクリックすると、そのタブの中で移動します（戻る・進むの履歴とスクロール位置はタブごと）。
- フォルダのタブは「最近の履歴」「よく使う項目」と色が違います（緑系。「最近の履歴」「よく使う項目」は青系で、それぞれのアイコンが付きます）。どのタブも × ・中クリック・Ctrl + W で閉じ、左右にドラッグして順番を入れ替えられます。
- 「最近の履歴」「よく使う項目」のタブを閉じてから開き直すと、一覧から始まります（閉じる前にいたフォルダと、戻る・進むの履歴は残りません）。
- タブを全部閉じると、カード一覧の場所に「開いているタブはありません。左のメニューから項目を選んでください。」と「最近の履歴を開く」「よく使う項目を開く」のボタンが出ます。この状態も保存され、次の起動もタブなしで始まります。
- 開いているタブ（並び順と、それぞれが表示していた場所）と選んでいたタブは `settings.json` に保存し、次の起動で元に戻します（フォルダが無くなっていたフォルダのタブは「フォルダが見つかりません」と出るので、「タブを閉じる」で閉じます。「最近の履歴」「よく使う項目」は一覧に戻ります）。登録を解除しても、開いているタブは閉じません。
- 以前の版の `settings.json`（「最近の履歴」「よく使う項目」が常設だった形式）は、最初の起動で新しい形式に変わります（2 つのタブとフォルダのタブを同じ並びで開き、表示していたタブを選びます）。新しい形式のファイルを以前の版で開くと、フォルダの中にいた「最近の履歴」「よく使う項目」はフォルダのタブとして開き、次に新しい版で開いたときに改めて変換されます。
- 以前の「登録フォルダ」タブ（登録フォルダのカード一覧）はなくなりました。登録フォルダの並べ替えは「ドラッグで並べた順」だけです（名前順・更新日順はフォルダのタブの中で使えます）。

### 表示する項目の切り替え

- 最近の履歴・よく使う項目の一覧（タブの最上位）では、ツールバーの並べ替えボタンの左のボタンで「すべて表示」「フォルダのみ表示」「ファイルのみ表示」を選べます。タブごとに `settings.json` に保存します。
- 絞り込み中は件数が「履歴 2 / 4」（表示中 / 全体）のように出ます。
- 絞り込み中にドラッグで並べ替えると、隠れている項目の位置はそのままで、表示中の項目だけが入れ替わります。
- 一覧からフォルダの中へ移動したあと（フォルダの中）と、フォルダのタブでは絞り込みません（ボタンも出ません）。

### 削除（ごみ箱へ移動）

- 右クリックメニューの「削除（ごみ箱へ移動）」は、フォルダの中の項目にだけ出ます：フォルダの中のカード、オーバーレイ・フライアウトの行、行のプレビュー。最近の履歴・よく使う項目の一覧のカード、サイドバーの登録フォルダ、フライアウトの見出しには出ません。見つからない・応答がない項目では選べません。
- 選択した項目の上で右クリックすると、選択全部を対象に「削除（ごみ箱へ移動）」が出ます（選択の全部が削除できる項目のときだけ）。
- **Delete キー**でも、選択した項目をごみ箱へ移します。選択がないときは何もしません（ポインターの下の項目は使いません）。押し続けても確認は 1 回だけで、文字の入力欄の中では効きません。Shift + Delete（エクスプローラーの完全削除）はありません。
- 選ぶと必ず確認ダイアログが出ます（既定のボタンは「キャンセル」で、Enter だけでは削除されません）。複数でも確認は 1 回で、件数と先頭の 5 件のパスが出ます。フォルダは中のファイル・フォルダごとごみ箱へ移します。
- エクスプローラーの Delete と同じ仕組み（`IFileOperation`）でごみ箱へ移すので、ごみ箱から元に戻せます。複数の項目も 1 つの操作として移すので、進行状況の画面は 1 つです。大きなフォルダでは Windows の進行状況の画面が、使用中のファイルなどでは Windows のダイアログが出ます。
- **完全な削除はしません**。ごみ箱に入れられない項目（ネットワーク上のフォルダ、WSL のフォルダなど、Windows がごみ箱に入れずに完全に削除しようとする項目）は、何も消さずに中止し、「ごみ箱に移動できない場所にあるため、削除しませんでした。」と表示します。複数のときは、その項目と残りの項目は消さず、それまでに移した件数と残りの件数を表示します（例：「3 個をごみ箱に移動しました。残りの 2 個はごみ箱に移動できないため、削除しませんでした。」）。Windows のダイアログで中止・スキップした項目も消しません。
- 終わったら、表示中の一覧を読み直します（スクロール位置はそのまま。消えた項目は選択から外れ、残った項目は選択のままです）。削除中にもう一度削除・貼り付けをすると「前の操作が終わってから実行してください」と出ます。ほかのタブは次に開いたときに読み直します。ピン留めや利用記録は消しません（存在しない項目として扱われ、同じ場所にまた現れれば再び表示されます）。

### 選択と切り取り・コピー・貼り付け

- **選択**：カード・詳細表示の行を Ctrl + クリックすると選択に加わり（もう一度で外れる）、Shift + クリックで最後に Ctrl + クリックした項目からの範囲、Ctrl + Shift + クリックでその範囲を足します。選んだ項目はアクセント色の枠と塗りで表示され、ツールバーの件数の右に「n 個を選択」と出ます。Ctrl + A で表示中の一覧の項目を全部、Esc・普通のクリック・一覧の空いているところのクリックで選択を外します。見つからない・応答がない項目は選べません。選択はタブごとで、別のフォルダへ移動すると外れます。
- Ctrl か Shift を押すと、カードのオーバーレイと詳細表示の行の一覧は閉じ、押している間は開きません（隣の項目を選ぶときに一覧が重ならないため）。サイドバーから出した一覧はそのままです。
- **切り取り・コピー**：Ctrl + X / Ctrl + C は選択した項目に効きます（選択がなければ何もしません。ポインターの下の項目は使いません）。右クリックの「切り取り」「コピー」は、選択した項目の上なら選択全部、そうでなければその項目に効きます（選択の外を右クリックすると選択は外れます）。複数を選んでいるときのメニューは「切り取り」「コピー」「パスをコピー」（1 行に 1 つ）と「削除（ごみ箱へ移動）」です。
  - 切り取れるのはフォルダの中の項目だけです（「削除（ごみ箱へ移動）」と同じ範囲）。最近の履歴・よく使う項目の一覧のカード、サイドバーの行、フライアウトの見出しは切り取れません（コピーはできます。Ctrl + X では「この一覧の項目は切り取れません（コピーはできます）」と出ます）。ドライブそのものは切り取りもコピーもできません。
  - クリップボードにはエクスプローラーと同じ形式で入るので、エクスプローラーやほかのアプリに貼り付けられます。切り取った項目は薄く表示され、貼り付けが済む・クリップボードがほかの内容に替わる・エクスプローラーで貼り付けて項目が移動した（ウィンドウに戻ったときに確かめます）と、元に戻ります。
- **貼り付け**：Ctrl + V は表示中のフォルダへ、右クリックの「貼り付け」はそのフォルダ（フォルダのカード・行・見出し、登録フォルダ、ドライブ）へ、一覧の空いているところの右クリックの「貼り付け」は表示中のフォルダへ貼り付けます。最近の履歴・よく使う項目の一覧と、タブがないときは貼り付けできません。エクスプローラーで切り取り・コピーした項目も貼り付けられます。
  - 切り取った項目は移動、コピーした項目はコピーします（ネットワーク上の項目の切り取りも移動です。エクスプローラーと同じ）。削除できない場所（読み取り専用のメディアなど）の項目は、切り取りでもコピーします。同じフォルダへのコピーは「x - コピー」の名前で複製し、同じフォルダへの切り取り・フォルダをそのフォルダ自身の中へ・ドライブそのものは貼り付けません。
  - 同じ名前の項目があるときや大きなコピーでは、Windows のダイアログ・進行状況の画面が出ます（エクスプローラーと同じ仕組み `IFileOperation`）。FolderDeck 自身の確認ダイアログは出ません。終わったら結果（貼り付け先、移動できずにコピーした数）を表示して一覧を読み直し、表示中のフォルダへ貼り付けたときは届いた項目を選択します。
  - 切り取りは、移動が全部済んだときだけクリップボードから消えます。同じ名前のダイアログでスキップした項目などがあると、切り取りは残り（薄いまま）、もう一度貼り付けられます。
  - 貼り付けは一度に 1 つです（実行中にもう一度貼り付けると「前の操作が終わってから実行してください」）。Ctrl + V を押し続けても 1 回だけです。実行中にウィンドウを閉じようとすると「ファイルの移動・コピー・削除が実行中です。終了すると途中で中断されます。」と確認します（既定は「キャンセル」）。
  - FolderDeck の中のコピー・移動は貼り付けだけです（ドラッグでは動かしません）。元に戻す機能はありません。移動した項目のピン留め・利用記録・登録フォルダは元の場所のままで、見つからない項目として表示されます。

### エクスプローラーのメニュー（その他のメニュー（Windows））

- 右クリックメニューのいちばん下の「その他のメニュー（Windows）」を選ぶと、同じ場所にエクスプローラーの右クリックメニューが出ます。インストールしたアプリが追加した項目（7-Zip の圧縮・展開など）、「送る」「プログラムから開く」「プロパティ」などが使えます。Shift を押しながら右クリックしてアプリのメニューを開くと、エクスプローラーで Shift + 右クリックしたときの項目も出ます（カードに重なった一覧と詳細表示の行の横の一覧は、Shift を押すと閉じるため、その中の行では使えません）。
- 出るのは、カード、詳細表示の行、オーバーレイ・フライアウトの行と見出し、行のプレビュー、サイドバーの登録フォルダです。選択した項目の上では、選択全部のメニューになります（別々のフォルダの項目をまとめたとき、たとえば最近の履歴の一覧でも）。見つからない・応答がない項目とドライブそのもの（`C:\` など）では選べません。PC の節のドライブの行には出ません（「フォーマット」などドライブの操作が並ぶため）。
- 設定の「右クリックのメニュー」を「Windows のメニュー」にすると、上の項目を右クリックしたとき、アプリのメニューを経由せずにエクスプローラーのメニューが出ます。いちばん上にアプリの項目（1 項目なら「開く」「エクスプローラーで表示」「パスをコピー」「切り取り」「コピー」「貼り付け」「ピン留めする」「削除（ごみ箱へ移動）」など、アプリのメニューと同じもの。選択全部なら「切り取り」「コピー」「パスをコピー」「削除（ごみ箱へ移動）」）、区切り線の下にエクスプローラーの項目が並びます。
  - 1 項目のメニューでは、アプリの「開く」が太字の既定の項目になり、エクスプローラーの「開く」は出しません（フォルダはアプリの中で開くため）。エクスプローラーの「パスとしてコピー」も、アプリの「パスをコピー」と重なるので出しません。選択全部のメニューでは、エクスプローラーの「開く」が残ります。
  - アプリの項目は文字だけで、アイコンは付きません。メニューの見た目は Windows 標準の（明るい）メニューで、アプリのテーマ（ダーク）には合わせません。
  - Shift を押しながら右クリックすると、エクスプローラーの拡張メニューの項目も出ます（上と同じく、カードに重なった一覧と詳細表示の行の横の一覧の中では使えません）。
  - 次のときは、設定に関係なくアプリのメニューが出ます：ドライブの行、「PC」の見出し、一覧の空いているところ、見つからない・応答がない項目とドライブそのもの。エクスプローラーのメニューが出せなかったとき（取れない、表示する前のエラー）も、同じ位置にアプリのメニューを出します（「その他のメニュー（Windows）」は付きません）。
  - エクスプローラーのメニューを 5 秒以内に用意できなかったときは、「エクスプローラーのメニューが時間内に準備できなかったため、アプリのメニューを出しました。」と表示してアプリのメニューを出します。その項目は 5 分間、右クリックで最初からアプリのメニューになります（毎回 5 秒待たされないため。5 分たつと、もう一度エクスプローラーのメニューを試します）。
  - 右クリックしてからメニューが出るまで、エクスプローラーのメニューの用意にかかる時間だけ待ちます（拡張機能が多いと、アプリのメニューより遅れて出ます）。その間にもう一度右クリックしても、メニューは重ねて出しません。
- エクスプローラーのメニューから、**「削除」「名前の変更」「切り取り」「コピー」「貼り付け」は取り除いて**あります。
  - 削除：エクスプローラーの削除は、ごみ箱に入らない場所では完全に削除します。FolderDeck は完全な削除をしないため、アプリの「削除（ごみ箱へ移動）」だけを使います。
  - 切り取り・コピー・貼り付け：アプリ自身の操作（上の「選択と切り取り・コピー・貼り付け」）にそろえるためです（切り取った項目の薄い表示、貼り付け先の決め方、結果の表示）。
  - 名前の変更：FolderDeck には名前を変える機能がないため、メニューからも出しません。
  - 取り除けずに残った項目（拡張機能がサブメニューの中に置いたなど）も、選んだときに動作の名前（verb）が分かれば実行せずに閉じます。
- メニューを出している間、カスケードの一覧は開いたままで、ポインターがほかのカードに載っても開閉しません。メニューを閉じると一覧はふだんどおりに戻ります（ポインターが一覧の外なら少し待って閉じます）。ほかのウィンドウをクリックしてメニューを閉じたときは、一覧も閉じます。
- 項目を選んで実行したときは、表示中の一覧を読み直し、ウィンドウに戻ったときにもう一度読み直します（7-Zip の展開のように、メニューを閉じた後に別のプログラムが続きを行うことがあるため）。何も選ばずに閉じたときは読み直しません。
- 「その他のメニュー（Windows）」から開いたメニューを 5 秒以内に用意できないとき（応答しない拡張機能など）や、メニューが取れないときは何も出さず、「このメニューは表示できませんでした」と表示します（「Windows のメニュー」の設定では、代わりにアプリのメニューを出します。上の説明）。時間切れのメニューが後から出ることはありません。
- **制約**：Windows 11 の新しい右クリックメニューにだけ出る項目（ストアのアプリなどが追加するもの）は出ません（エクスプローラーの「その他のオプションを確認」で出るメニューと同じ内容です）。拡張機能が応答しなくなってもアプリは止まりませんが、拡張機能が異常終了したときは FolderDeck も一緒に終了することがあります（エクスプローラーと同じ仕組みで、拡張機能をアプリの中で動かすため）。

### 並べ替えとピン留め

- ピン留めした項目のカードには、どのタブでも（フォルダの中のカードも）左下に 📌 が出ます。サムネイルに重なる一覧（オーバーレイ）とは重ならないので、ホバー中も表示されたままです。詳細表示では名前の右に出ます。📌 をクリックするとピン留めを外せます（右クリックの「ピン留めを外す」と同じ。見つからない・応答がない項目は除く）。
- ツールバーの並べ替えボタン（カードの形・詳細表示のボタンの左）で、「手動（ドラッグで並べた順）」と、名前・更新日・サイズ・種類のそれぞれ昇順・降順を選べます。カード表示でも詳細表示でも同じ並び方が効きます。
  - 並び方は「最近の履歴」「よく使う項目」ではタブごとに保存され、そのタブの一覧と、そのタブで開いたフォルダの中の両方に効きます。フォルダのタブは全部で 1 つの並び方を共有します（1 つのタブで変えると、開いているほかのフォルダのタブも同じ並び方になります）。
  - 名前はエクスプローラーと同じ自然順（2 が 10 より前）。更新日が分からない項目（応答がないものなど）は、どちらの向きでも最後です。
  - サイズ順では、フォルダ（サイズを数えません）とサイズの分からないファイルは、どちらの向きでも最後です。同じサイズの項目は名前順です。
  - 種類順は**拡張子の順**です（詳細表示の「種類」の列に出る名前の順ではありません。たとえば `.docx` は「Microsoft Word 文書」と出ますが、d の位置に並びます）。拡張子の大文字・小文字は区別せず、同じ拡張子の項目は名前順です。最近の履歴・よく使う項目の一覧では、フォルダは拡張子なしのファイルと同じ扱いで、昇順なら先頭に来ます。
  - 「手動」のとき、最近の履歴・よく使う項目の一覧はドラッグで並べた順、フォルダの中は既定の順（フォルダ→ファイル、名前順）です。フォルダの中では、どの並び方でもフォルダがファイルより先に来ます。
- **ピン留めした項目は位置が動きません**。名前順・更新日順などにしても、ピン留めしたカードは「手動」の並び（フォルダの中では既定の並び）での位置にとどまり、ピン留めしていないカードだけが空いている位置に順に入ります。
  - 例：手動の並びが [A, B📌, C, D📌, E] のとき「名前（降順）」にすると [E, B📌, C, D📌, A]。
  - 「手動」以外の並び方の一覧（最近の履歴・よく使う項目）でピン留めすると、カードは表示中の位置のまま固定されます（「手動」の並びの中でそのカードだけを表示中の位置へ移し、ほかのピン留めカードの位置やほかのカードの順は変えません）。この移動は、ドラッグで並べたことがある（`card_order.json` に並びがある）ときだけ保存し、そうでなければ次に読み込み直したとき（タブの切り替え、F5 など）にそのカードは元の並びでの位置（よく使う項目では先頭のピン留めの並び）へ移ります。
  - ピン留めを外すと、そのカードは並べ替えた位置へ移ります。
- **ドラッグで並べ替え**：最近の履歴・よく使う項目の一覧でだけ、カードをドラッグして順番を入れ替えられます（フォルダの中と読み込み中はできません。サイドバーの登録フォルダは行のドラッグで入れ替えます）。
  - 入る位置にアクセント色の縦線が出ます（カードの左半分＝その前、右半分＝その後ろ、カードの間の隙間＝縦線の位置、最後のカードより後ろの空き＝末尾）。詳細表示では、行と行の間に横線が出ます（ポインターにいちばん近い境目）。上端・下端に近づけると自動でスクロールします。Esc か、ウィンドウの中の一覧の外（ツールバーなど）で離すと取り消しです。
  - 同じドラッグでウィンドウの外（エクスプローラー、PowerPoint、デスクトップなど）まで運んで離すと、並びは変わらず、そのアプリにファイル・フォルダを渡します（下の「ほかのアプリへドラッグで渡す」）。
  - 「手動」以外の並び方のときにドラッグすると、その時点の表示順のまま「手動」に切り替わり、「並び順を「手動」に切り替えました。」と表示されます。
  - 最近の履歴・よく使う項目で並べたあとに新しく加わった項目は、元の並び（新しい順・よく使う順）で直前にある項目のすぐ後ろに入ります（前に何もなければ先頭）。並べた項目は、開き直しても先頭には移りません。
  - 元の並び（新しい順・よく使う順）に戻したいときは、並べ替えメニューの最後の「手動の並びをリセット」を選びます（最近の履歴・よく使う項目だけ。ドラッグで並べたことがあるときに選べます。確認なしで `card_order.json` からそのタブの並びを消します）。フォルダのタブには出ません（ドラッグで並べる一覧がないため）。

### 詳細表示

ツールバーの並べ替えボタンの右にある 3 つのボタンの右端（横線 3 本）で、カードの代わりに 1 項目 1 行の一覧にできます。どのタブにも効き、`settings.json` に保存します。

- 列は「名前」（アイコンつき。ピン留めした項目は名前の右に 📌）「更新日時」「種類」「サイズ」です。サイズはファイルだけに出て、エクスプローラーと同じく KB 単位の切り上げです。最近の履歴・よく使う項目の一覧では、名前の右に補足（いつ使ったか、どこにあるか）が、行の右端に ×（ポインターを乗せている間）が出ます。
- サムネイルも、フォルダの中身の件数も読み込みません。項目の多いフォルダでも軽く開けます。
- **列の見出しをクリックすると、その列で並べ替えます**（もう一度クリックで逆順。名前・種類は昇順から、更新日時・サイズは新しい順・大きい順から）。並び方はツールバーの並べ替えボタンと同じもので、「手動」に戻すときは並べ替えボタンから選びます。「種類」は拡張子の順です（上の「並べ替えとピン留め」）。
- **列の幅**：更新日時・種類・サイズの列は、見出しの左の境界線をドラッグして変えられます（48〜600。`settings.json` に保存）。**名前の列の幅は直接は変えられません**（ほかの列の残りが名前の幅になります。名前が 120 より狭くなる幅にはできません）。横スクロールはなく、ウィンドウが狭いときはほかの列を一時的に縮めて表示します（保存した幅は変わらず、ウィンドウを広げると戻ります）。
- **フォルダの名前の列にポインターを止めると**、名前の列の右（更新日時の列の上）にそのフォルダの中身の一覧が出ます（カードのオーバーレイに当たるもの。そこから先のフライアウト・プレビュー・クリック・右クリックは同じです）。名前の列のどこに止まっても（名前の右の余白でも）出ます。更新日時・種類・サイズの列では出ません。
- クリック（開く・移動）、右クリックのメニュー、ほかのアプリへのドラッグ、一覧での並べ替えドラッグ、右ボタンを押したままの左クリック（エクスプローラーで表示）は、行のどこでもカードと同じです。
- カードの大きさのスライダーと Ctrl + ホイールは詳細表示では使いません（大きさの設定はそのまま残ります）。
- カード表示と詳細表示を切り替えると、一覧は先頭から表示されます。戻る・進むで前の場所へ戻ったときも、切り替える前のスクロール位置には戻りません（2 つの表示では位置の数え方が違うため）。

### ほかのアプリへドラッグで渡す

カード、一覧（オーバーレイ・フライアウト）の行、プレビュー、サイドバーの登録フォルダをドラッグして、ほかのアプリに落とせます。エクスプローラーからドラッグしたときと同じ形式（ファイルのパスの一覧）で渡します。

- 例：PowerPoint で編集中のスライドに画像のカードや行を落とすと、図として挿入されます。エクスプローラーのフォルダに落とすとコピーされます。
- **コピーかショートカットだけで、移動にはなりません**（同じドライブのエクスプローラーに落としても、Shift を押しながら落としても移動しません。Shift のときは受け付けられません）。ドラッグで元のファイルやフォルダを動かさないためです。ショートカットの作成（リンク）は許可しているので、受け取る側が対応していれば作れます（エクスプローラーでは Alt を押しながら落とす）。
- フォルダもドラッグできます。どう扱うか（コピーする、開く、受け付けない）は受け取る側しだいです。フォルダごとコピーされるので、大きなフォルダをデスクトップなどに落とすとコピーが始まります（エクスプローラーのコピー画面で取り消せます）。
- 選択した項目の 1 つをドラッグすると、選択した項目をまとめて（表示の順に）渡します。選択の外の項目をドラッグすると、その項目だけです（選択はそのまま）。
- 見つからない・応答がないカードはドラッグできません。
- ボタンを押したまま、システムのドラッグ距離（既定 4 ピクセル）より動かすとドラッグになります。ドラッグしたあとはクリックとして扱わない（ファイルを開かない・フォルダに移動しない）ので、手がぶれて少し動いたときはそのまま離しても何も起きません。
- ドラッグを始めると、開いていた一覧（オーバーレイ・フライアウト）とプレビューは消えます（落とす先を隠さないため）。
- FolderDeck のウィンドウの上で離しても何も起きません（フォルダの登録にもなりません）。最近の履歴・よく使う項目の一覧のカードを一覧の中で離したとき、サイドバーの登録フォルダを登録フォルダの行の並びの中で離したときだけ並べ替えになります（見出しや「クイック アクセス」の行の上で離しても何も起きません）。

### プレビューできるファイル

一覧（オーバーレイ・フライアウト）の行に 0.15 秒止まるか ↑ ↓ で選ぶと、横にプレビューが出ます。クリックで開きます。

| 種類 | 表示 |
|---|---|
| 画像 | 画像そのもの（JPEG・PNG・BMP・GIF・TIFF・WebP はアプリが直接読みます。HEIC・AVIF などはシェルのサムネイル） |
| PowerPoint（.pptx .pptm .ppsx .ppsm .potx .potm） | 表紙（シェルのサムネイル、なければファイルに保存された縮小版） |
| Word（.docx .docm .dotx .dotm） | 本文の先頭（最大 40 段落・4,000 文字）。見出し・表題は太字。変更履歴で削除された文字、フィールドコード、テキストボックス、ヘッダー・フッター・脚注・コメントは出しません |
| Excel（.xlsx .xlsm .xltx .xltm） | ブックの並び順で最初の表示中のシートの、左上 30 行 × 12 列（列の A B C… と行番号つき）。数値は一般形式、日付・時刻の書式のセルは yyyy/MM/dd などで表示。通貨・桁区切り・色・罫線・セル結合は再現しません |
| テキスト（.txt .log .md .csv .json .xml .yaml .ini .cs .py .js .ts .ps1 .bat .sql .html .css .xaml など） | 先頭 60 行（最大 64 KB）を等幅フォントで。文字コードは BOM（UTF-8 / UTF-16）→ UTF-8 → Shift_JIS の順に判定。中身がバイナリなら文字では出しません |
| そのほか Windows がサムネイルを作れる形式 | シェルのサムネイル。動画（.mp4 .mov .wmv .avi .mkv .webm など）は常に対象。PDF・SVG・PSD・音楽ファイルなどは、サムネイルを作るアプリが入っていれば対象。画像を作れなかったとき（ジャケット画像のない音楽ファイルなど）は何も出しません |

- 続きがあるときや枠に入りきらないときは、下に「（以下省略）」が出ます。プレビューの中はスクロールしません。
- Word・Excel は本文を読めなかったとき（本文がない、パスワード付きなど）、シェルのサムネイルかファイルに保存された縮小版を出します。旧形式の .doc / .xls / .ppt と .xlsb は中身を読みません。
- 実行ファイル・ショートカット（.exe .dll .lnk .url .msi など）は対象外です。
- OneDrive の「オンラインのみ」のファイルなど、開くとダウンロードが始まるファイルは、Word・Excel・テキストの中身もファイルに保存された縮小版も読みません（ファイル属性だけで判定するので、プレビューのためにダウンロードされることはありません）。ダウンロード済みのファイルは普通にプレビューされます。
- カードのサムネイルも、Word・Excel は PowerPoint と同じく、シェルのサムネイルがなければファイルに保存された縮小版を使います（Word / Excel で「縮小版を保存する」をオンにして保存したファイルだけにあります）。

### 設定

| 項目 | 内容 |
|---|---|
| テーマ（配色） | システム／ライト／ダーク。既定は「システム」で、Windows の設定（アプリのモード）に合わせ、起動中に Windows 側を切り替えても追従します。「ライト」「ダーク」は Windows の設定に関係なく固定します。OK を押すとすぐ切り替わります（`settings.json` の `theme`：`system`／`light`／`dark`） |
| エクスプローラーで表示するとき、開いているエクスプローラーに新しいタブで開く（Windows 11） | 既定はオフ。オンにすると、右クリックの「エクスプローラーで表示」が、いちばん手前のエクスプローラーのウィンドウに新しいタブを追加して開きます（フォルダはそのフォルダを、ファイルは親フォルダを開いて選択）。エクスプローラーが開いていない、別の仮想デスクトップにしかない、Windows 11 22H2（ビルド 22621）より前、などのときは新しいウィンドウで開きます。サイドバーの「PC」の見出しの「エクスプローラーで開く」も同じです |
| 右クリックのメニュー | アプリのメニュー／Windows のメニュー。既定は「アプリのメニュー」で、項目の右クリックでこのアプリのメニューを出し、エクスプローラーのメニューはいちばん下の「その他のメニュー（Windows）」から開きます。「Windows のメニュー」では、項目の右クリックでエクスプローラーのメニュー（7-Zip・送る・プロパティなど）を出し、その上にアプリの項目を並べます（ドライブの行・空いているところ・使えない項目、エクスプローラーのメニューが 5 秒以内に用意できなかったときなどはアプリのメニュー。上の「エクスプローラーのメニュー」）。OK を押すと次の右クリックから切り替わります（`settings.json` の `item_menu`：`app`／`windows`） |
| 画像サムネイルのキャッシュ上限（MB） | 既定は 512（0〜8192）。一度表示した画像のサムネイルをデータフォルダの `thumbs\` に保存し、次からは元の画像を読まずにすぐ表示します。上限を超えると、使っていない順に上限の 8 割まで消します。0 にすると保存しません |

- 画像サムネイルのキャッシュ上限を変えたときは、次回の起動から有効です。0 にすると新しく保存も読み出しもしません（すでにある `thumbs\` は消しません。不要なら「データフォルダを開く」から手で消してください）。
- 新しいタブを開くには、エクスプローラーの公開されていないコマンド（`WM_COMMAND 0xA21B`）を使っています。今後の Windows Update で動かなくなった場合は、約 2 秒待ってから新しいウィンドウで開く動作に戻ります。どちらで開いたかとその理由は `logs\app.log` に記録されます。
- 1 回のクリックでタブとウィンドウの両方が開くことはありません。新しいタブを頼んだのに確認できず、エクスプローラーが応答しない（あとから遅れてタブができるかもしれない）ときは、新しいウィンドウは開かずに「エクスプローラーの新しいタブでフォルダを開けませんでした。」と表示します（このときタブがホームのまま遅れて現れることがあります）。
- 「データフォルダを開く」は設定に関係なく新しいウィンドウで開きます。
- 以前あった「imgtool の登録フォルダを取り込む」は削除しました（`registered_folders.json` の形式は imgtool と同じままです）。

## 実装メモ

- **カードグリッド**：`VirtualizingWrapPanel`（MIT、net10.0-windows 対応を確認済み）は使わず、カードを「列数ぶんの行」にまとめて `VirtualizingStackPanel` で仮想化しています。列数（`max(1, floor((幅 + 12) / (サイズ + 12)))`）とカード幅（`(幅 − 12 × (列数 − 1)) / 列数`）の式をそのまま再現するためです。
- **詳細表示**：WPF の `ListView`（`GridView`）は使わず、見出しの行と、行を仮想化した素の一覧を自分で並べています。`ListView` の選択やマウスのつかみ方が、カードと共通にしているクリック・ドラッグの判定と食い違うためです。その代わり、名前の列の幅の変更と横スクロールはありません（名前の列を広げるには横スクロールが要るため、ほかの 3 列だけを可変にしました）。種類の名前はエクスプローラーと同じもの（シェルの種類名）を拡張子ごとに 1 回だけ問い合わせ、届くまでは「JPG ファイル」のような仮の名前を出します。
- **フライアウトの位置**：WPF の `Popup` を使い、位置は行が載っているモニターの作業領域と拡大率から物理ピクセルで計算して、ウィンドウを直接その位置へ動かしています（拡大率の違うモニターでもずれないようにするため。`CustomPopupPlacementCallback` の代わり）。
- **画像のサムネイル**：JPEG・PNG・BMP・GIF・TIFF・WebP は、シェル（エクスプローラーと同じ仕組み）を通さず、アプリが WIC（Windows Imaging Component）で直接サムネイルの大きさにデコードします。JPEG はデコードしながら 1/2・1/4・1/8 に縮小できるので元の大きさで展開するより数倍速く、CPU のコア数 − 1 本（2〜8 本）のスレッドで並行して作ります。向き（EXIF の Orientation）も反映します。作ったサムネイルはメモリと、データフォルダの `thumbs\` に保存し、次からは元の画像を読まずに表示します（保存するのは作るのに 4 ms 以上かかったものだけ。パス・更新日時・サイズ・要求サイズから名前を付けるので、画像を書き換えれば作り直します）。アプリが読めなかった画像、「オンラインのみ」のファイル、HEIC / AVIF・動画・Office・フォルダなどは、これまでどおりシェルのサムネイル（Windows のサムネイルキャッシュ）を使います。
- **サムネイルの待ち時間**：1 件 5 秒の制限は、作り始めてから数えます。以前は順番待ちの時間も含めていたため、大きな画像の多いフォルダでは後ろのカードが時間切れになり、サムネイルの代わりにアイコンが出ることがありました。
- **フォルダのサムネイル**：シェルのフォルダサムネイルの一部は「非乗算済みアルファ」の画像として返るため、色とアルファから判定して正しく透過表示しています。四隅が不透明な（四角い背景つきの）画像はアイコン表示に切り替えます。
- **シェル画像の上下**：シェルが返すビットマップは、サムネイルは上から、アイコンは下から並んでいるのに、どちらも「下から」と報告されます。そのため `GetDIBits` に上から並べ直させて読みます（報告を信じて反転すると、サムネイルが上下逆になる）。
- **PowerPoint の表紙**：シェルのサムネイル（Office が入っていれば出る）がなければ、ファイルの中に保存されている表紙のサムネイル（`docProps/thumbnail.jpeg`、PowerPoint は既定で保存する）を使います。これがないファイル（ほかのツールで作ったものなど）はアイコンのままです。横長なので、カードでは切り抜かずに全体を収めます。
- **メッセージ行**：壊れたデータファイルを退避したときの通知用に「警告」（エラーと同じく次の操作まで残る）を追加しました。
- **長いパス**：シェル API で開けないときは 8.3 形式の短いパスでも試します。
- **キーボード**：カスケードが開いているあいだの ↑ ↓ → ← Enter Esc に対応しています。カードにフォーカスを置いてキーボードだけでオーバーレイを開く機能（任意）は未対応です。
- **Office・テキストのプレビュー**：Office をインストールしていなくても読めるよう、ファイル（zip）の中の XML を必要な部分だけ読んで文字や表にしています。共有モードで開くので Office で編集中でも読めます。展開は 1 回 32 MB まで（zip 爆弾対策）、DTD は禁止、シートは 30 行目を読んだら止め、共有文字列は必要な番号までしか読みません。読み取りは裏のスレッドで行い 5 秒で打ち切り、直近 32 件は覚えておきます。「Windows がサムネイルを作れるか」は拡張子ごとに一度だけ問い合わせます（`AssocQueryString` で IThumbnailProvider の登録を確認）。
- **並べ替え**：「ピン留めは位置を固定」「新しく加わった項目は元の並びで直前の項目の後ろ」の規則は Core（`Ordering/`）の純粋な関数にしてテストしています。最上位の更新日とファイルのサイズは、存在確認と同じ 1 回の呼び出しで取得しています（タイムアウトも同じ）。種類順のキーを拡張子にしたのは、種類の名前がシェルから後で届くためです（名前で並べると、読み込みの途中で行が動きます）。
- **ほかのアプリへのドラッグ**：`DragDrop.DoDragDrop` で `DataFormats.FileDrop`（パスの配列。エクスプローラーと同じ CF_HDROP）を渡し、許可する効果は Copy | Link だけです（Move は渡さない）。260 文字以上のパスは 8.3 形式の短いパスにして渡します（短いパスが作れないボリュームでは長いまま）。
  - 最上位のカードは、1 回のドラッグに並べ替え用の内部形式（`FolderDeck.CardReorder`）と FileDrop の両方を載せます。グリッドの上では並べ替えとして Copy を返し、カーソルは普通の矢印に差し替えます（コピーの「＋」を出さないため）。
  - アプリ自身が始めたドラッグには内部形式 `FolderDeck.DragSource` を載せ、ドラッグ中のフラグも立てます。ウィンドウのフォルダ登録（`MainViewModel.RegisterDroppedAsync`）はそのどちらかがあれば受け付けません。
  - クリックとの区別は `SystemParameters.MinimumHorizontalDragDistance` / `MinimumVerticalDragDistance` を「超えたら」ドラッグ（カード・行・プレビュー共通、Core の `FileDrag.IsDragGesture`）。ドラッグを始めたら押下の記録を消すので、離してもクリックになりません。ダブルクリックの 2 回目の押下を無視する既存の処理はそのままです。
  - **カスケードは「開始時に消す」**：開いていた一覧とプレビューはドラッグ開始と同時に見えなくし、ホバーのタイマー（open / exit / grace / preview など）はすべて止めます。理由は、(1) フライアウトとプレビューは最前面のポップアップなので、残すと落とす先（スライドやフォルダ）を隠す、(2) タイマーは DoDragDrop のモーダルループの中でも動くのに、判定に使うポインター位置（IsMouseOver、ホバー中の行）は更新されないため、ドラッグ中に勝手に開閉してしまう、の 2 点です。ただしポップアップのウィンドウは中身を非表示にする（透明になり、ポインターもドロップも通り抜ける）だけで、破棄はドラッグが終わってからです。ボタンを押したポップアップをボタンを押したまま破棄すると、DoDragDrop がボタンを離したことに気づかず、次にクリックするまでドラッグが続いてしまうことを実機で確認したためです。同じ理由で、ドラッグ中に届いた「全部閉じる」（ウィンドウの非アクティブ化、自動スクロールなど）は無視し、終わったときにまとめて閉じます。ドラッグ元（DoDragDrop に渡す要素）はメインウィンドウか、並べ替えのときはカードグリッドで、どちらもドラッグ中に破棄されません。渡すパスは開始前に取り出しておきます。
  - ドラッグ中のサムネイル表示（`IDragSourceHelper`）は見送りました。ドラッグ画像はヘルパーがデータオブジェクトに独自の形式を書き込む（COM の `SetData`）仕組みで、アプリが作った WPF の `DataObject` はこれを受け付けない見込みのため（未検証）、独自の COM `IDataObject` の実装（HGLOBAL の複製・解放の管理を含む）が必要になり、受け渡しの形式や自分のウィンドウでの判定（並べ替え・登録の除外）も作り直しになるためです。今はシステムの標準カーソル（コピー・リンク・禁止）だけが出ます。
  - **既知の制約**：権限レベルが違うアプリの間（UIPI。例：管理者として実行したアプリと通常の FolderDeck）ではドロップできません。画像以外のファイルを PowerPoint などに落としたときの扱い（オブジェクトとして埋め込む、リンクする、受け付けないなど）は受け取る側しだいです。
  - ドラッグの結果は `logs\app.log` に `drag-out: <ドラッグ元>, effect <効果> (<ミリ秒> ms)` として記録します（パスは書きません）。
- **未対応（P2・任意）**：フォルダの中でのドラッグによる並べ替え、フォルダへのショートカットの展開、安全三角形、Recent フォルダの監視。「プログラムから開く」は「その他のメニュー（Windows）」から使えます。
